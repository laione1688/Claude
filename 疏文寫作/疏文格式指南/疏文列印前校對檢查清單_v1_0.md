# 疏文列印前校對檢查清單 v1.0

> 本文件為疏文合併列印前的**最終校對 SOP**，
> 確保每一期疏文在列印前經過系統性檢查，避免疏失送出。
> 
> **適用時機：** 所有疏文已轉換完成、合併為單一 docx 檔案後，列印前執行。

---

## 使用方式

1. 將合併完成的 `.docx` 檔案交由 AI 檢查
2. 指示：「請依照疏文列印前校對檢查清單，檢查這份疏文」
3. AI 會逐項核對以下所有項目，並產出校對報告

---

## 一、生辰資料檢查（最高優先）

### 1.1 生辰欄位是否已填寫 🔴
- [ ] 所有疏文的「生辰」欄位都有實際資料（非空白模板）
- [ ] 不存在 `____年____月____日` 等未填寫的佔位符
- **常見錯誤：** 模板格式未替換為實際資料

### 1.2 天干地支與民國年對照 🔴
- [ ] 每篇疏文的天干地支年份與民國年對照正確
- [ ] 驗證公式：西元年 = 民國年 + 1911，再對照六十甲子表
- **常見錯誤：** 天干地支年與民國年不匹配

### 1.3 生辰格式一致性 🟡
- [ ] 格式統一為：`農曆 ○○年︵民○○年︶○月○○日 ○時`
- [ ] 「︵民○○年︶」民國年對照不缺漏
- [ ] 「民」字不遺漏（如「︵75年︶」應為「︵民75年︶」）
- [ ] 月日使用中文（非阿拉伯數字）
- [ ] 日期與時辰之間有空格（如「初四日 午時」而非「初四日午時」）
- **常見錯誤：** 缺少民國年對照、數字格式混用、日期時辰無空格

---

## 二、稱謂檢查

### 2.1 信士/信女稱謂正確性 🔴
- [ ] 男性使用「信士」，女性使用「信女」
- [ ] 疏文開頭稱謂與結尾署名稱謂一致
- [ ] 祈願段落中的稱謂與開頭一致（如「信士虔心供養」vs「信女虔心供養」）

### 2.2 多人疏文稱謂 🟡
- [ ] 夫婦聯名：兩人稱謂皆正確
- [ ] 代為祈願：具疏人與被祈願者稱謂區分清楚
- [ ] 團體供養：各人稱謂逐一確認

---

## 三、住址檢查

### 3.1 行政區正確性 🔴
- [ ] 縣市名稱完整（「新北市」非「北市」，「台北市」非「北市」）
- [ ] 區/鄉/鎮名稱與實際行政區劃一致
- **常見錯誤：** 「北市板橋區」→ 板橋區屬「新北市」

### 3.2 住址格式 🟡
- [ ] 使用實際居住地址（非郵局信箱）
- [ ] 同一人多篇疏文的住址寫法一致
- [ ] 數字已轉為中文（如「269號」→「二百六十九號」）

---

## 四、備獻香品檢查

### 4.1 香品欄位完整性 🔴
- [ ] 所有疏文的「備獻香品」欄位皆已填寫
- [ ] 香品種類與斤兩數量明確

### 4.2 香品格式一致性 🟡
- [ ] 數量格式統一（如「二．五 斤」「五 斤」「一十 斤」）
- [ ] 粗體標示一致

---

## 五、日期與編號檢查

### 5.1 敬書日期 🟡
- [ ] 所有疏文結尾的「中華民國 ○○○ 年 ○ 月 ○○ 日 敬書」格式一致
- [ ] 日期按時間順序排列
- [ ] 日期在合理範圍內（活動日期之前）

### 5.2 疏文編號 🟡
- [ ] 編號連續無跳號（1, 2, 3... N）
- [ ] 總數與預期一致

---

## 六、結構與用語檢查

### 6.1 疏文結構完整性 🔴
每篇疏文必須包含以下段落：
- [ ] 標題：「馨香喜獻文疏」
- [ ] 開頭：「伏以 香煙繚繞…」
- [ ] 廟宇與神明名稱
- [ ] 個人資料區（稱謂、生辰、住址、備獻香品）
- [ ] 祈願段落
- [ ] 結尾：「謹此」+ 結語 + 署名 + 日期

### 6.2 神明稱謂一致性 🟡
- [ ] 廟宇名稱統一（如「板橋接雲寺」）
- [ ] 主祀神明全銜統一
- [ ] 祈願段落中的神明稱謂與廟宇主祀一致
- **常見錯誤：** 接雲寺主祀觀世音菩薩，不應用「佛祖」

### 6.3 通用版 vs 個人化版一致性 🟢
- [ ] 通用版（一般供養）結語：「福德增長…利益眾生」
- [ ] 個人化版（特定祈願）結語：「庇佑所願成就…所求皆應」
- [ ] 兩種版本不混用

---

## 七、特殊情況檢查

### 7.1 同一人多篇疏文 🟡
- [ ] 個人資料一致（姓名、生辰、住址）
- [ ] 若住址不同，確認是否為當事人提供的不同版本

### 7.2 代為祈願/還願 🟡
- [ ] 被祈願者的生辰資料完整
- [ ] 關係說明清楚
- [ ] 還願內容與前次祈願對應

---

## 校對報告格式

完成檢查後，產出以下格式的報告：

```
## 校對報告

**檔案名稱：** [檔名]
**疏文總數：** [N] 篇
**檢查日期：** [日期]

### 🔴 嚴重問題（必須修正）
[逐一列出]

### 🟡 中度問題（建議修正）
[逐一列出]

### 🟢 輕度問題（格式一致性）
[逐一列出]

### ✅ 已通過項目
- 天干地支年份對照：全部正確
- 備獻香品：全部已填
- ...

### 📊 統計
| 項目 | 結果 |
|------|------|
| 嚴重 | X 件 |
| 中度 | X 件 |
| 輕度 | X 件 |
```

---

## 嚴重度分級說明

| 等級 | 符號 | 說明 | 處理方式 |
|------|------|------|---------|
| 嚴重 | 🔴 | 資料錯誤或缺漏，送出會造成失禮 | **必須修正後才能列印** |
| 中度 | 🟡 | 格式不一致或可能錯誤 | **建議修正** |
| 輕度 | 🟢 | 格式美觀或一致性問題 | **視情況修正** |
