# 疏文調整指南｜地藏王菩薩 v1.2

> 本文件為「神明疏文調整指南」專案中,**專屬於地藏王菩薩**之調整規範說明檔。  
> 本檔案不作為疏文使用,而是用於**指引疏文調整、判斷、對外溝通與內部一致性**。

---

## 一、使用定位(請先閱讀)

本指南適用於以下情境:

- 已收到供養者文字祈願內容
- 需要依「地藏王菩薩信仰脈絡」進行疏文用詞與結構調整
- 目標為:  
  **不越界、不代祈、不擅加、不預設結果**

本指南 **不取代** 疏文母版,僅作為調整與判斷依據。

---

## 二、地藏王菩薩疏文的兩種型態(重要)

地藏王菩薩疏文 **僅分為兩種**,不可混用:

### 1️⃣ 結緣供養疏文(無具體祈願)

- 用途:結緣、月供養、長期供養、未提出明確所求
- 特性:
  - 不出現「今就所願」
  - 不出現「依其所求」「如願成就」
  - 不書寫任何個人願望內容
- 對應母版:
  - 《【結緣供養】地藏王菩薩疏文標準格式_v1.1.md》

👉 **此格式已定稿,不得自行改寫內容,只能填入具疏人資訊**

---

### 2️⃣ 祈願供養疏文(有明確所願)

- 用途:供養者已清楚提出祈願內容
- 特性:
  - 必須出現「今就所願,虔誠奉陳」
  - 中段承接供養者原始祈願(僅作語感與邏輯調整)
  - 結尾使用「依其所求,如願成就」
- 對應母版:
  - 《【祈願供養】地藏王菩薩疏文標準格式_v1.0.md》

👉 **此格式為地藏王菩薩既定版本,不可變動結構**

---

## 三、調整時的核心原則(務必遵守)

### 1. 不代祈

- 不替供養者新增未提及的祈願
- 不主動補寫「冤親債主」「祖先」等內容(除非原文已有)

### 2. 不預設結果

- 不將「尚未發生的狀態」寫成既定事實
- 尤其避免:
  - 病未癒卻寫「病已痊癒」
  - 尚在治療卻寫「不再受苦」

### 3. 只做「語感與邏輯」調整

可調整項目包含:
- 白話 → 疏文語感
- 句型不順 → 四字韻律
- 願望混亂 → 邏輯順序整理

不可調整:
- 祈願本質
- 對象指向
- 願望大小與範圍

---

## 四、地藏王菩薩的祈願職能判斷

### ✅ 適合向地藏王菩薩提出的方向

- 超度亡者、祖先超拔
- 冤親債主化解
- 嬰靈相關之超度與安置
- 業障消除、冤業化解
- 重病相關之「病苦減輕」「身心安泰」
- 修行、願行、道心堅固

### ⚠️ 職能不相符時的處理方式

- 不直接否定供養者
- 保留原意,轉為較中性的疏文語彙
- 並於【建議】中溫和提醒更合適的神明

## 五、困境陳述原則(新增條款)

### 地藏王菩薩特性

地藏王菩薩的信仰核心是「幽冥教主、業障化解、超度亡靈」,  
因此在疏文中**可以陳述業障困境**,以利菩薩了解苦難所在。

### ✅ 可以陳述的困境類型

**業障相關:**
```
範例:
- 累世業障纏身,身心不安
- 冤親債主糾纏,諸事不順
- 宿世因果未了,影響今生
```

**病苦相關:**
```
範例:
- 慈母於民國一一二年九月六日腦幹出血,昏迷至今,病苦纏身
- 身患重症肌無力,病體沉重
- 久病不癒,身心俱疲
```

**亡者相關:**
```
範例:
- 先父於民國○○年往生,至今未安
- 嬰靈未得安置,心中不安
- 祖先牌位未立,後代不寧
```

### 陳述困境的正確方式

**原則:**
- 如實說明困境,但用詞溫和
- 不過度渲染痛苦
- 不使用恐懼性語言

**範例對照:**

| 供養者原文 | ❌ 不當處理 | ✅ 適當處理 |
|-----------|------------|-----------|
| 我病得很痛苦 | 痛不欲生,生不如死 | 病苦纏身,身心不適 |
| 被人害了 | 遭人陷害,冤屈難伸 | 願冤業化解,解冤釋結 |
| 癌症末期 | 癌症末期,命不久矣 | 病體沉重,願離苦得樂 |

### 困境陳述後必須接正向祈願

**格式:**
```
[陳述困境] + [祈願菩薩慈悲] + [正向祈願]
```

**範例:**
```
累世業障纏身,身心不安,
祈請地藏王菩薩慈悲庇佑,
願業障消除,因果化解,身心安泰。
```

## 六、多人祈願處理原則(新增條款)

### 情境一:為單一他人祈願

**基本格式:**
```
具疏人:信士/信女○○○
被祈願者:依關係註明
```

**範例一:為母親祈願**
```
信女○○○為慈母○○○祈願,
慈母於民國一一二年九月六日腦幹出血,昏迷至今,
祈請地藏王菩薩慈悲超拔,
願慈母病苦減輕,離苦得樂。
```

**範例二:為亡父超度**
```
信士○○○為先父○○○祈請超度,
先父於民國○○年○月○日往生,
祈請地藏王菩薩慈悲接引,
願先父業障消除,往生淨土。
```

### 情境二:為多人祈願

**原則:**
- 逐一列出被祈願者
- 依關係與性質分段
- 保持邏輯清晰

**範例:為家人祈願**
```
信女○○○為家人祈願,
願慈母○○○早日康復,
願夫君○○○工作順遂,
願子女○○○、○○○學業精進,
祈請地藏王菩薩慈悲庇佑。
```

### 情境三:聯名供養

**原則:**
- 需逐一確認各人稱謂
- 列出所有聯名者

**範例:**
```
信士○○○、信女○○○聯名供養,
為先祖○○○祈請超度...
```

## 八、常見高風險提醒

- 「庇佑」後面只接結果,不接問題本身
- 嬰靈相關用語需極度溫和,不具指責性
- 疏文中不使用編號條列
- 疏文不出現「死亡」「過世」等白話詞
- 超度祈願可陳述困境,但須接正向祈願
