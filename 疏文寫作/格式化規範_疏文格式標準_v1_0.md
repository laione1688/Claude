# 格式化規範｜疏文格式標準 v1.0

> 本文件為「神明疏文調整指南」之**格式化標準規範**,  
> 適用於所有神明疏文之格式調整、數字轉換、標點符號使用等技術性規範。

---

## 一、文件定位

本文件規範:
- 數字與文字轉換標準
- 標點符號使用規則
- 日期與地址格式
- 排版與呈現方式

---

## 二、數字處理規範

### 基本原則
疏文中所有數字應轉換為**中文數字**,以符合傳統疏文格式。

### 轉換對照表

| 阿拉伯數字 | 中文數字 |
|-----------|---------|
| 0 | 〇 |
| 1 | 一 |
| 2 | 二 |
| 3 | 三 |
| 4 | 四 |
| 5 | 五 |
| 6 | 六 |
| 7 | 七 |
| 8 | 八 |
| 9 | 九 |
| 10 | 十 |

### 特殊數字處理

**兩位數:**
- 11 → 十一
- 20 → 二十
- 25 → 二十五
- 99 → 九十九

**三位數:**
- 100 → 一百
- 115 → 一百一十五
- 999 → 九百九十九

**年份:**
- 2023 → 二〇二三
- 2026 → 二〇二六
- 民國112年 → 民國一一二年

### 門牌號碼處理

**基本格式:**
- 478號 → 四七八號
- 478-1號 → 四七八之一號
- 10-2號 → 十之二號

**完整地址範例:**
```
原文: 彰化縣大村鄉中山路二段3-1號
調整: 彰化縣大村鄉中山路二段三之一號
```

### 金額數字處理

**原則:**
- 若涉及具體金額目標,保留數字以示明確
- 數字仍需轉中文

**範例:**
```
原文: 個人業績達成毛利20萬以上
調整: 個人業績毛利達二十萬以上
```

```
原文: 還清500萬債務
調整: 清償五百萬債務
```

### 數量與次數

**範例:**
```
原文: 每天3個以上的合約
調整: 每日簽約達三件以上

原文: 每個月有3個攜碼合約
調整: 每月攜碼合約達三件以上
```

## 三、標點符號規範(直式排版)

### 基本原則
疏文採用**直式排版標點符號**,以符合傳統書寫格式。

### 標點符號對照表

| 橫式標點 | 直式標點 | 說明 |
|---------|---------|------|
| ( ) | ︵ ︶ | 括號 |
| " " | ﹁ ﹂ | 引號 |
| 《 》 | 《 》 | 書名號(不變) |
| 、 | 、 | 頓號(不變) |
| , | , | 逗號(不變) |
| 。 | 。 | 句號(不變) |

### 使用範例

**括號:**
```
原文: (清創及通血管)
調整: ︵清創及通血管︶
```

```
原文: (位於彰化縣大村鄉中山路二段3-1號)
調整: ︵位於彰化縣大村鄉中山路二段三之一號︶
```

**引號:**
```
原文: 向"觀世音菩薩"祈願
調整: 向﹁觀世音菩薩﹂祈願
```

### 特殊標點

**破折號:**
- 橫式:——
- 直式:︱(或保留——)

**省略號:**
- 橫式:......
- 直式:⋯⋯

## 四、日期格式規範

### 完整日期格式

**標準格式:**
```
民國○○○年○○月○○日︵西元○○○○年︶
```

**範例:**
```
原文: 2023年9月6日
調整: 民國一一二年九月六日︵西元二〇二三年︶
```

```
原文: 2026年1月4日
調整: 民國一一五年一月四日︵西元二〇二六年︶
```

### 簡化日期格式

若不需標註西元年,可簡化為:
```
民國一一二年九月六日
```

### 農曆日期

**格式:**
```
農曆甲辰年十一月初五日
```

**注意:**
- 農曆月份:正月、二月、三月...十二月
- 農曆日期:初一、初二...廿九、三十

## 五、地址格式規範

### 完整地址格式

**原則:**
- 保留完整地址資訊
- 數字轉中文
- 使用直式括號

**範例一:**
```
原文: 屏東縣屏東市廣東路478-1號
調整: 屏東縣屏東市廣東路四七八之一號
```

**範例二:**
```
原文: 彰化縣大村鄉中山路二段3-1號
調整: 彰化縣大村鄉中山路二段三之一號
```

### 地址呈現方式

**若需括註:**
```
︵位於屏東縣屏東市廣東路四七八之一號︶
```

**若為正文:**
```
信士現於MG員林所擔任汽車銷售人員︵位於彰化縣大村鄉中山路二段三之一號︶
```

## 六、公司/機構名稱規範

### 基本原則
- 完整保留公司全名
- 英文字母大寫
- 公司類型保留

**範例:**
```
原文: mg員林所
調整: MG員林所

原文: 聯旺交通汽車股份有限公司
調整: 聯旺交通汽車股份有限公司(保持不變)
```

---

## 七、人名處理規範

### 稱謂使用

**家族稱謂:**
- 父親 → 慈父、先父(亡故)
- 母親 → 慈母、先母(亡故)
- 祖父 → 祖父、先祖父(亡故)
- 祖母 → 祖母、先祖母(亡故)

**自稱:**
- 我 → 信士/信女、弟子
- 本人 → 信士/信女

**完整姓名:**
- 保留完整姓名,不使用簡稱
- 範例:「慈母溫富美」而非「慈母溫女士」

## 八、醫療/疾病用語規範

### 可保留的醫療術語

**原則:**
- 具體病名可保留
- 用括號註明說明

**範例:**
```
原文: 腦幹出血昏迷
調整: 腦幹出血,昏迷至今

原文: 重症肌無力
調整: 重症肌無力︵保留原詞︶

原文: 小中風
調整: 小中風︵醫療用語可保留︶
```

### 需轉化的用語

**白話 → 疏文用語:**

| 白話用語 | 疏文用語 |
|---------|---------|
| 死亡 | 往生、辭世 |
| 過世 | 往生 |
| 去世 | 仙逝、往生 |
| 癌症末期 | 病體沉重 |
| 精神分裂 | 心神不寧 |
| 病得很嚴重 | 病體沉重、病苦纏身 |

### 祈願用語處理

**避免預設結果:**
- ❌ 病已痊癒
- ✅ 早日康復、身心安泰

**正確表述:**
- ✅ 病苦減輕
- ✅ 轉危為安
- ✅ 身心安泰
- ✅ 早日康復

## 九、職業描述規範

### 基本原則
- 保留具體職業名稱
- 使用正式職稱

**範例:**
```
汽車銷售 → 汽車銷售人員
外送 → 外送員
老師 → 教師
業務 → 業務人員
```

### 完整職業描述

**格式:**
```
信士現於[公司名稱]擔任[職位]
```

**範例:**
```
信士現於MG員林所擔任汽車銷售人員
信女經營七丹水產宜蘭早市
```

## 十、特殊情境格式

### 醫療處置說明

**用括號註明:**
```
即將就醫治療︵清創及通血管︶
```

### 具體數據目標

**保留數字但需轉中文:**
```
原文: 每天工作日有3個以上的合約
調整: 每個工作日簽約達三件以上

原文: 個人業績達成毛利20萬以上
調整: 個人業績毛利達二十萬以上
```

### 時間期限

**範例:**
```
原文: 明年冬季
調整: 明年冬季(保持不變)

原文: 2026年
調整: 民國一一五年︵西元二〇二六年︶
```
