## 🔍 案例一:「孩子們」不等於「子女」

### 實際對話情境

**供養人原文:**
「孩子們平安」

**初版調整:**
「子女平安,快樂成長...」

**供養人回應:**
「孩子們不一定指子女」

**修正調整:**
「家中孩童平安,快樂成長...」

---

### 📖 規範印證

**適用規範:** 《共通原則_v1.1》第四之二「具疏人稱謂確認原則」

**規範內容:**
```
### 多人祈願處理
**情境一:為他人祈願**
- 具疏人:信士/信女○○○
- 被祈願者:「慈母○○○」「子○○○」等
```

**印證結果:**

| 檢查項目 | 結果 | 說明 |
|---------|------|------|
| 規範是否涵蓋此情境? | ⚠️ 部分涵蓋 | 提到為他人祈願,但未明確說明「孩子」可能的多種關係 |
| 是否提供判斷依據? | ✅ 有 | 需確認被祈願者與具疏人關係 |
| 是否有操作指引? | ⚠️ 不夠明確 | 未列出常見關係類型 |

**改善建議:**

在《共通原則_v1.1》的「多人祈願處理」段落,補充:

```markdown
### 常見關係用語對照

**長輩:**
- 慈父/慈母、祖父/祖母、先父/先母(亡故)

**平輩:**
- 夫君/妻、兄/弟、姊/妹

**晚輩:**
- 子/女(親生子女)
- 孫/孫女(孫輩)
- 姪/姪女(姪輩)
- 家中孩童(不確定關係時的中性用法)

**提醒:**
「孩子們」「小孩」等詞,不要直接改為「子女」,
應詢問具體關係或使用「家中孩童」等中性詞。
```

## 🔍 案例二:複雜層次的多願望祈求

### 實際對話情境

**供養人原文:**
```
小願 供香 小善
中願 叁與照護老人 使其生前體面 離世無痛
大願 用父母名字捐贈一台救護車
中大願是我還清500萬債務有餘力開始一步步起
```

**處理方式:**
- 保留四個願望層次
- 在各領域內細化用詞
- 保留「500萬」具體數字
- 總結四個願望

---

### 📖 規範印證

**適用規範:** 《共通原則_v1.1》第四之一「擴寫邊界與判斷標準」

**規範內容:**
```
### 判斷標準(三步驟檢查法)
檢查一:同領域?
檢查二:同性質?
檢查三:同規模?
```

**印證結果:**

| 檢查項目 | 結果 | 說明 |
|---------|------|------|
| 規範是否涵蓋此情境? | ✅ 完整涵蓋 | 「同領域細化」原則完全適用 |
| 是否提供判斷依據? | ✅ 有 | 三步驟檢查法清晰可用 |
| 是否有操作指引? | ✅ 有 | 明確說明各領域內可如何細化 |

**實際應用:**

| 原文 | 調整 | 判斷 |
|------|------|------|
| 供香小善 | 今以香供小善,累積福德 | ✅ 同領域細化 |
| 照護老人生前體面 | 令其生前安享尊嚴,體面安詳 | ✅ 同領域細化 |
| 還清500萬債務 | 五百萬債早日清償 | ✅ 只轉格式,未擴寫 |

**結論:** ✅ 規範完全適用,無需補充

## 🔍 案例三:多人姓名並列祈願

### 實際對話情境

**供養人原文:**
```
謝謝觀音庇佑 業績近來成長
請庇護張永興小中風找到良醫 醫治痊癒
黃偉敏禮贈品業務年年成長 利潤滾滾
能完成心中的中願望 債務還清
張嘉芩 工作順利 能逢正緣
```

**處理方式:**
- 分段處理各人祈願
- 保留完整姓名
- 各願望獨立陳述

---

### 📖 規範印證

**適用規範:** 《共通原則_v1.1》第四之二「具疏人稱謂確認原則」

**規範內容:**
```
### 特殊情境說明
**為他人代祈:**
- 具疏人:信士/信女○○○
- 被祈願者:依關係註明(慈母、子、夫等)
- 範例:「信女○○○為慈母○○○祈願」
```

**印證結果:**

| 檢查項目 | 結果 | 說明 |
|---------|------|------|
| 規範是否涵蓋此情境? | ⚠️ 部分涵蓋 | 提到為他人代祈,但未涵蓋「多人並列且無關係說明」的情況 |
| 是否提供判斷依據? | ⚠️ 不足 | 未說明張永興、黃偉敏、張嘉芩是什麼關係 |
| 是否有操作指引? | ❌ 缺乏 | 未提供處理方式 |

**改善建議:**

在《共通原則_v1.1》補充:

```markdown
### 情境四:多人並列但無關係說明

**問題:**
供養人列出多個姓名,但未說明關係
範例:「請庇護張永興...黃偉敏...張嘉芩...」

**處理原則:**
1. 主動詢問這些人與具疏人的關係
2. 標準詢問語:「請問張永興、黃偉敏、張嘉芩分別是您的什麼人呢?」
3. 確認後依關係註明:
   - 「為夫君張永興祈願...」
   - 「為友人黃偉敏祈願...」
   - 「為姊張嘉芩祈願...」

**若無法確認關係:**
- 仍需保留完整姓名
- 可使用「庇佑張永興先生...」等中性稱呼
```

## 🔍 案例四:現代靈性用語處理

### 實際對話情境

**供養人原文:**
```
磁場清淨,能量調和,與高靈同頻,智慧開啟,
心性清明,靈性提升,修行精進,福慧增長。
```

**初版處理:**
刪除「磁場、能量、高靈、靈性」等新時代靈性用語,
改為傳統佛教用語「心性清明、智慧開啟、修行精進、福慧增長」

**供養人回應:**
「下面這個不動(指靈性用語部分)」

**最終處理:**
保留供養人的靈性用語,因為那是他的原意

---

### 📖 規範印證

**適用規範:** 《共通原則_v1.1》第二條「四大核心原則」

**規範內容:**
```
### 1. 不代祈  
疏文調整僅為文字與結構之整理,不得替供養者新增、擴大或轉換祈願內容。
```

**印證結果:**

| 檢查項目 | 結果 | 說明 |
|---------|------|------|
| 規範是否涵蓋此情境? | ⚠️ 原則有,細則缺 | 「不代祈」原則適用,但未說明如何處理現代用語 |
| 是否提供判斷依據? | ⚠️ 不明確 | 未說明「轉換用語」是否算「轉換祈願內容」 |
| 是否有操作指引? | ❌ 缺乏 | 未提供處理現代靈性用語的方式 |

**改善建議:**

在《共通原則_v1.1》或《格式化規範_v1.0》補充:

```markdown
## 現代靈性用語處理原則

### 何謂現代靈性用語?

包含但不限於:
- 磁場、能量、氣場、頻率
- 高靈、光體、靈性、揚升
- 顯化、吸引力法則、宇宙能量
- 脈輪、水晶、音叉療癒

### 處理原則

**原則一:尊重供養人原意**
若供養人明確使用這些詞彙,且堅持保留,
則應尊重並保留,這屬於供養人的信仰表達。

**原則二:提供建議但不強制**
可以提醒供養人:
「傳統疏文較少使用『磁場』『能量』等現代用語,
建議可改為『心性清明』『智慧增長』等傳統表述,
但最終仍尊重您的選擇。」

**原則三:不主動轉換**
不可未經供養人同意,就擅自將靈性用語改為傳統用語。
這違反「不代祈」「不擅加」原則。

### 判斷標準

❓ 是否算「轉換祈願內容」?
→ **是的。** 改變用語等於改變表達方式,可能改變願望性質。

範例:
- 「磁場清淨」→「心性清明」
- 看似相近,但前者是新時代概念,後者是佛教概念
- 這是兩種不同的世界觀,不可擅自轉換
```

## 🔍 案例五:執著特定對象的姻緣祈願

### 實際對話情境

**供養人連續兩次祈願:**
第一次:「命中註定女孩 張倩茹早日來到我身邊白頭偕老」
第二次:「希望張倩茹早日來到我身邊,白頭偕老」

**LAI 的顧慮:**
「怕供養人有偏執的情形出現,想在給他觀音的疏文後要寫一段話給他。」

**處理方式:**
提供溫和引導文字,建議改為「祈求觀音菩薩賜予弟子良緣」

---

### 📖 規範印證

**適用規範:** 《共通原則_v1.1》第六條「敏感議題之共通處理原則」

**規範內容:**
```
- 用詞溫和,不具評判性
- 避免造成心理負擔或暗示結果
- 尊重供養者當下處境與情緒狀態
```

**印證結果:**

| 檢查項目 | 結果 | 說明 |
|---------|------|------|
| 規範是否涵蓋此情境? | ✅ 涵蓋原則 | 敏感議題處理原則適用 |
| 是否提供判斷依據? | ⚠️ 不夠具體 | 未說明「執著特定對象」算不算敏感議題 |
| 是否有操作指引? | ❌ 缺乏 | 未提供具體引導話術 |

**改善建議:**

在《共通原則_v1.1》第六條補充:

```markdown
## 敏感議題之共通處理原則

### 常見敏感議題類型

**類型一:執著特定對象**
- 情境:反覆祈求與特定人士的姻緣
- 風險:可能涉及單方面執著、騷擾傾向
- 處理:提供疏文,但附上溫和引導文字

**範例引導文字:**
```
親愛的善信:

感謝您虔誠供養觀世音菩薩。

關於感情姻緣,真正的良緣需要雙方緣分具足、彼此心意相通。
若此緣分是您的正緣,觀音菩薩自會安排;
若另有更好的安排,也請相信菩薩的智慧。

建議您可以將祈願調整為:
「祈求觀音菩薩賜予弟子良緣,遇見真心相愛、適合相伴一生的伴侶」,
如此更能感應菩薩的慈悲加持。

願您早日覓得良緣,幸福美滿!

明心福旺閣 合十
```

**類型二:病情嚴重或生死議題**
- 用詞溫和,避免「命不久矣」等語
- 不預設結果,不寫「必定康復」

**類型三:家庭衝突或冤仇**
- 不評判對錯
- 不加入「懲罰對方」的內容
- 轉為「化解冤結、彼此平安」
```
