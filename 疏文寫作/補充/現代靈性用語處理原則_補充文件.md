## 一、何謂現代靈性用語?

### 定義

「現代靈性用語」(或稱「新時代靈性用語」)指:
- 源自西方新時代運動(New Age Movement)
- 融合東方哲學、量子物理、能量療癒等概念
- 在華人社會約於1990年代後流行
- 與傳統佛道教用語體系不同

### 常見詞彙清單

**能量相關:**
- 磁場、能量場、氣場
- 頻率、振動、共振
- 能量、宇宙能量

**靈性相關:**
- 高靈、光體、靈性
- 揚升、提升維度
- 覺醒、開悟(新時代意義)

**身心相關:**
- 脈輪、氣輪
- 水晶療癒、音叉療癒
- 靈氣、Reiki

**顯化相關:**
- 顯化、吸引力法則
- 豐盛、富足意識
- 正念顯化

## 二、為什麼需要特別處理?

### 問題一:與傳統疏文語系不同

**傳統疏文用語:**
- 佛教:「心性清明、智慧增長、福慧雙修」
- 道教:「元神安泰、三魂穩固、正氣充盈」

**現代靈性用語:**
- 「磁場清淨、能量調和、與高靈同頻」

→ 兩者屬於**不同的世界觀與語言系統**

### 問題二:可能違反「不代祈」原則

若未經供養人同意,擅自將:
```
「磁場清淨」改為「心性清明」
```

等於:
- ❌ 改變了供養人的信仰表達方式
- ❌ 將新時代概念轉換為佛教概念
- ❌ 違反「不得轉換祈願內容」原則

### 問題三:可能造成誤解或衝突

供養人可能:
- 不認同傳統佛教用語
- 堅持使用新時代靈性表述
- 認為改動等於不尊重其信仰

## 三、處理原則

### 核心原則:尊重但可建議

```
1. 不可擅自轉換用語
2. 可以提供建議
3. 最終尊重供養人選擇
```

### 原則一:不可擅自轉換

**禁止行為:**
```
❌ 供養人寫「磁場清淨」
   → 直接改為「心性清明」
   → 未告知供養人就轉換用語
```

**為什麼?**
- 這是改變表達方式
- 等於改變願望性質
- 違反「不代祈」原則

### 原則二:可以溫和建議

**允許行為:**
```
✅ 在【建議】段落溫和提醒:

「您使用的『磁場』『能量』等詞彙,
屬於現代靈性用語,
在傳統疏文中較少見。

傳統疏文多用:
『心性清明』『智慧增長』等佛教用語,
或『元神安泰』『正氣充盈』等道教用語。

您可以考慮調整,
但最終仍尊重您的原意與選擇。」
```

### 原則三:若供養人堅持則保留

**情境:**
供養人明確表示「這個不動」

**處理:**
```
✅ 完全保留原文
✅ 不再提出建議
✅ 不在疏文中做任何修改
```

**理由:**
- 尊重供養人的信仰表達
- 這是他的祈願,他有權決定用語
- 我們只是傳遞者,不是審查者

## 四、標準處理流程

### Step 1: 識別是否含現代靈性用語

**檢查清單:**
- [ ] 是否出現「磁場」「能量」「頻率」?
- [ ] 是否出現「高靈」「光體」「揚升」?
- [ ] 是否出現「脈輪」「水晶」「靈氣」?
- [ ] 是否出現「顯化」「吸引力法則」?

若有任一項勾選 → 進入Step 2

### Step 2: 提供調整建議

在【調整說明】或【建議】段落中,溫和提醒:

**範本一(溫和版):**
```
【建議】
您使用的『磁場』『能量』等詞彙,
在傳統疏文中較少見。
若希望更符合傳統格式,
可考慮改為『心性清明』『智慧增長』等用語,
但最終仍尊重您的選擇。
```

**範本二(詳細版):**
```
【建議】
關於『磁場清淨、能量調和、與高靈同頻』,
這些屬於現代靈性(New Age)用語。

傳統觀音疏文多使用佛教語彙:
- 磁場清淨 → 心性清明
- 能量調和 → 身心安泰
- 與高靈同頻 → 與道相應
- 靈性提升 → 智慧增長

您可以考慮調整為傳統用語,
以更符合疏文格式,
但若您希望保留原意,我們完全尊重。
```

### Step 3: 等待供養人回應

**情境A:供養人同意調整**
→ 依其同意的方向調整

**情境B:供養人堅持保留**
→ 完全保留原文,不做任何修改

**情境C:供養人未回應**
→ 使用原文辦理(不擅自改動)

## 五、實務案例示範

### 案例一:供養人接受建議

**供養人原文:**
```
磁場清淨,能量調和,與高靈同頻,智慧開啟
```

**我們的建議:**
```
【建議】
關於『磁場』『能量』『高靈』等用語,
傳統疏文較少使用。
建議可改為:『心性清明,智慧開啟,修行精進,福慧增長』
```

**供養人回應:**
「好的,請幫我調整」

**最終疏文:**
```
庇佑信士心性清明,智慧開啟,
修行精進,福慧增長。
```

---

### 案例二:供養人堅持保留

**供養人原文:**
```
磁場清淨,能量調和,與高靈同頻,智慧開啟
```

**我們的建議:**
```
【建議】
關於『磁場』『能量』『高靈』等用語,
傳統疏文較少使用...
```

**供養人回應:**
「這個不動」

**最終疏文:**
```
庇佑信士磁場清淨,能量調和,與高靈同頻,智慧開啟。
```

---

### 案例三:供養人混用兩種語系

**供養人原文:**
```
磁場清淨,能量調和,與高靈同頻,智慧開啟,
心性清明,靈性提升,修行精進,福慧增長。
```

**處理方式:**

**選項A:全部保留**
```
庇佑信士磁場清淨,能量調和,與高靈同頻,智慧開啟,
心性清明,靈性提升,修行精進,福慧增長。
```

**選項B:提供建議後依其選擇**
```
【建議】
您同時使用了現代靈性用語(磁場、能量、高靈)
與傳統佛教用語(心性、智慧、福慧)。

若希望統一語系,可考慮:
- 全部改為傳統用語
- 或全部保留現代用語

但若您希望混用,我們也完全尊重。
```

## 六、常見問答

### Q1: 為什麼不能直接改成傳統用語?

**A:** 因為這等於改變供養人的信仰表達方式。

「磁場清淨」和「心性清明」雖然看似相近,
但前者是新時代概念,後者是佛教概念,
屬於兩種不同世界觀,不可擅自轉換。

### Q2: 如果供養人不懂傳統用語怎麼辦?

**A:** 提供建議,但不強迫改變。

我們可以告知傳統疏文的用語習慣,
但最終決定權在供養人手中。

### Q3: 神明會不會看不懂現代靈性用語?

**A:** 這不是我們該判斷的問題。

我們的職責是:
- 尊重供養人的表達方式
- 提供傳統疏文的建議
- 不替神明決定什麼能聽懂、什麼不能

### Q4: 可以在疏文中混用嗎?

**A:** 可以,如果供養人堅持。

雖然語系不統一,但這是供養人的選擇,
我們應該尊重。
