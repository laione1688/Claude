# Instructions 更新指南

## 關於 Instructions 的說明

### 什麼是 Instructions？
Instructions 是 Claude 的核心系統提示詞，由 Anthropic 提供，包含了 Claude 的基本行為規範、功能說明和操作指引。這些內容存在於每次對話的上下文中，但**不是用戶可以直接編輯的文件**。

### 為什麼不能直接修改 Instructions？
- Instructions 是 Claude 的核心配置，由 Anthropic 管理
- 它們在每次對話開始時自動載入
- 用戶無法通過文件系統訪問或修改

---

## 替代方案：使用自定義技能（Custom Skills）

### 什麼是技能（Skills）？
技能是用戶可以上傳到 Claude Projects 的專門知識文件，用於擴展 Claude 的能力。當對話開始時，Claude 會：
1. 查看可用的技能列表
2. 根據任務需求選擇相關技能
3. 使用 `view` 工具讀取技能內容
4. 按照技能中的指引執行任務

## 如何使用這個技能？

### 方法一：上傳到 Claude Project（推薦）

1. **下載技能文件**
   - 文件已保存在：`/mnt/user-data/outputs/HTML文章排版標準.md`
   - 點擊下載連結獲取文件

2. **上傳到您的 Project**
   - 進入您的 Claude Project
   - 點擊「Add content」或「知識庫」
   - 上傳 `HTML文章排版標準.md` 文件
   - 文件類型選擇「Skill」或「知識」

3. **自動生效**
   - 之後每次對話，當您說「請排版」或「做成 HTML」
   - Claude 會自動讀取這個技能文件
   - 按照規範創建符合標準的 HTML 文件

### 方法二：每次對話時提供（臨時方案）

如果不使用 Project，您可以：
- 在對話開始時上傳 `HTML文章排版標準.md`
- 告訴 Claude：「請按照上傳的文件進行 HTML 排版」
- Claude 會讀取並遵循文件中的規範

## 常見問題

### Q: 為什麼不能直接修改 Instructions？
**A:** Instructions 是 Claude 的系統核心配置，由 Anthropic 管理，用戶無法直接編輯。但通過上傳技能文件，可以達到相同甚至更好的效果。

### Q: 技能文件和 Instructions 有什麼區別？
**A:** 
- **Instructions**: Claude 的通用行為規範，適用於所有用戶
- **技能文件**: 您的專屬知識，只在您的 Project 中生效

### Q: 如果我想修改標準怎麼辦？
**A:** 
1. 編輯 `HTML文章排版標準.md` 文件
2. 修改顏色、字體、樣式等任何內容
3. 重新上傳到 Project
4. 新對話中即刻生效

### Q: 技能文件會影響其他功能嗎？
**A:** 不會。技能文件只在相關任務時被調用。當您進行其他對話（如提問、寫作、編程），Claude 不會讀取 HTML 排版技能。

### Q: 我可以創建多個技能文件嗎？
**A:** 可以！您可以為不同的任務創建多個技能文件：
- HTML 文章排版
- SEO 文案撰寫
- 社群媒體貼文
- 儀軌步驟說明
- 等等...
