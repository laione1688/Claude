### 2.3 廣告的真實價值 — 歸因修正

```
GA4 的歸因盲區：

廣告 → 新客首購 $168K（GA4 記為「付費」）✅ 有追蹤
     → 新客成為會員
     → 會員回購 → 直接開網站 → GA4 記為「直接流量」❌ 歸因斷裂

GA4「直接流量」營收 $400K 裡面：
├── 真正的直接訪問（品牌忠誠、老客戶）
└── 廣告帶來的新客回購 ← 這塊被漏算了

所以「直接流量 $400K」有一大部分是廣告的間接貢獻！
```
