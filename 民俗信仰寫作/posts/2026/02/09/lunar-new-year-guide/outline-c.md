## PART 1：過年由來速覽（2 分鐘搞懂）

### 「年」不是怪獸，是豐收
- 甲骨文的「年」= 人背穀物 = 慶豐收
- 年獸傳說是後人編的（古籍裡查不到）
- 過年的本質：感謝天地、祈求來年

### 台灣過年 vs 大陸過年的差異
| 項目 | 台灣 | 大陸 |
|------|------|------|
| 送神 | 送「眾神」 | 主要送灶王爺 |
| 金紙 | 雲馬（甲馬） | 各地不同 |
| 年糕 | 甜粿、發粿、菜頭粿 | 年糕為主 |
| 門飾 | 門簽（五福紙） | 福字、對聯 |

## PART 2：祭祀完全指南（照著做就對了）

### 一、送神日（臘月二十四）

| 項目 | 內容 |
|------|------|
| **日期** | 農曆 12/24 |
| **時間** | 越早越好，最晚中午前 |
| **拜誰** | 家中所有神明（送回天庭） |
| **供品** | 三牲、甜湯圓 3 碗、麥芽糖、發粿、冬瓜糖、四果、鮮花 |
| **金紙** | 雲馬（甲馬）— 神明的交通工具 |
| **重點** | 甜食讓灶神「吃甜甜說好話」 |

> 送神後 → 大掃除（清囤），趁神明不在家打掃神明廳

### 二、除夕拜拜（一天拜四輪）

**拜拜順序：天公 → 神明 → 祖先 → 地基主**

#### 第一輪：拜天公

| 項目 | 內容 |
|------|------|
| **時間** | 除夕夜 23:00 起（子時） |
| **供品** | 三牲、五果、米酒 3 杯、六種糖果 |
| **金紙** | 四色金、天公金 |

#### 第二輪：拜祖先（公媽）

| 項目 | 內容 |
|------|------|
| **時間** | 除夕下午 16:00-17:00（年夜飯前） |
| **供品** | 一鍋飯、一鍋湯、三牲、團圓菜、年糕發糕蘿蔔糕 |
| **碗筷** | 10 副（十全十美），筷頭朝牌位 |
| **金紙** | 公媽金、刈金、大銀 |
| **禁忌** | 不用有籽水果、供品必須全熟熱食 |

#### 第三輪：拜地基主

| 項目 | 內容 |
|------|------|
| **時間** | 中午 12:00-15:00 |
| **供品** | 白飯 1 碗、家常菜、水果（單數） |
| **碗筷** | 2 副（地基主公 + 地基主婆） |
| **方向** | 朝廚房方向拜 |

#### 第四輪：圍爐守歲
- 魚只吃一半（年年有餘）
- 守歲為父母延壽
