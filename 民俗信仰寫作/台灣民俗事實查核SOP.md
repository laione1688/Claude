
# 台灣民俗事實查核 SOP

## 總原則
1. 以證據為基礎、來源公開、可複核、錯誤可更正。
2. 民俗內容分四級：可驗證事實、地方慣例、口述傳說、高風險宣稱。
3. 地域差異要註明，傳說不當史實。
4. 田野倫理：未經同意不公開個人資訊。

## 判定等級
- **綠燈（可發）**：至少2來源支持、無地域誤導、無高風險。
- **黃燈（修後可發）**：來源單一或有版本差異，修註明即可。
- **紅燈（需再查）**：來源不足或有明顯矛盾。
- **黑燈（不建議）**：高風險斷言、無來源支持。

## 20條警示規則
1. 「一定」「絕對」「全台都」→改「常見於」「部分地區」。
2. 神誕日期→查萬年曆與廟方公告。
3. 廟名地址→Google Maps + 官網確認。
4. 儀式順序→對照地方志或田野訪談。
5. 靈驗故事→標「信眾口述」。
6. 禁忌說法→註「地方傳聞，未經證實」。
7. 醫療效果→刪除或改「民間信仰」。
8. 改運保證→黑燈。
9. 災異恐嚇→黑燈。
10. 稱謂失當（如「死了」→「坐化」）→修正。
11. 農曆陽曆漏對照→補上。
12. 來源只用維基→至少加一官方。
13. 未註廟系→補「XX廟系」。
14. 個人祈願公開→匿名或刪。
15. 乩童身分→不公開。
16. 內部科儀→僅公開公開部分。
17. 商業導購→分離知識內容。
18. 過度美化→保持中性。
19. 學術引用→查原書頁碼。
20. 圖片來源→註明出處。

## 來源階層
1. 廟方官網、官方公告。
2. 學術論文、地方志、縣市文史。
3. 媒體報導（蘋果、聯合、TVBS地方版）。
4. 口述訪談（至少3人）。

此 SOP 適用部落格、臉書、印刷品。定期檢討，每季更新規則。
