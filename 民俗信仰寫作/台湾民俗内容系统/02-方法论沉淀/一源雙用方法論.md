# 一源雙用方法論——民俗素材的雙線內容產出

> 建立日期：2026-02-15
> 版本：v1.0
> 核心理念：一份民俗研究素材，產出兩篇不同目的的文章

---

## 為什麼要分兩條線？

一篇文章不可能同時服務兩種完全不同的閱讀動機：

| 動機 | 讀者心態 | 需要的內容 |
|------|----------|-----------|
| 「我要拜，教我怎麼做」 | 急用、工具導向 | 清單、步驟、數量、禁忌 |
| 「這是什麼？跟我有什麼關係？」 | 好奇、文化認同 | 故事、脈絡、意義、情感 |

把兩個動機混在一篇文章裡，標題會尷尬、開頭會分裂、讀者會困惑。

**解法**：素材庫是同一份研究，但拉出兩條產出線，各自服務各自的讀者。

---

## 兩條線的定義

### 🅰️ 線 A：實用懶人包

> 口號：**「照著做就對了」**

| 項目 | 規格 |
|------|------|
| **目的** | 讓要拜的人快速找到「怎麼做」 |
| **受眾** | 有在拜拜的人、第一次準備的人、被長輩叫去買東西的人 |
| **語氣** | 直接、乾脆、清單化、不囉嗦 |
| **結構** | 供品清單 → 步驟流程 → 禁忌提醒 → 常見問題 |
| **標題風格** | 工具型＋SEO 導向（「XX 怎麼拜？供品清單＋流程一次搞懂」） |
| **開頭風格** | 直奔主題（「天公生要拜什麼？這篇整理好了，照著準備不出錯。」） |
| **長度** | 1500-2500 字，精簡 |
| **適合平台** | 官網（攻略類）、小紅書、LINE 社群轉發 |
| **SEO 關鍵字** | 「XX 怎麼拜」「XX 供品」「XX 禁忌」「XX 流程」 |

#### 線 A 文章結構模板

```
標題：[節慶名] 怎麼拜？供品清單＋流程＋禁忌完整攻略

一、拜什麼？（30 秒搞懂）
   - 一句話說明這個節慶是拜誰、什麼時候拜

二、供品準備清單
   - 表格化：品項 / 數量 / 意義
   - 分「完整版」和「簡化版」

三、步驟流程（Step by Step）
   - 時間軸式、編號步驟

四、禁忌提醒
   - 列點式，標注嚴重程度

五、常見問題 Q&A
   - 3-5 個最實際的問題

結尾：一句鼓勵（「準備齊全就好，心誠最重要。」）
底部：連結到線 B 文化篇（「想知道為什麼這樣拜？看這篇 →」）
```

---

### 🅱️ 線 B：文化推廣

> 口號：**「不一定要拜，但身為台灣人，你一定要懂。」**

| 項目 | 規格 |
|------|------|
| **目的** | 讓所有台灣人認識自己的文化，不論信仰 |
| **受眾** | 所有台灣人——有拜的、沒拜的、不同宗教的、好奇的 |
| **語氣** | 敘事、有溫度、像朋友在跟你聊一個有趣的事 |
| **結構** | 場景帶入 → 故事/冷知識 → 文化脈絡 → 象徵意義 → 認同感結尾 |
| **標題風格** | 好奇心＋文化認同（「天公生：那個讓全台灣半夜不睡覺的日子」） |
| **開頭風格** | 畫面感場景（「每年正月初九，台灣有一群人會在半夜起床⋯」） |
| **長度** | 2500-4000 字，可以慢慢讀 |
| **適合平台** | 官網（品牌文化長文）、Facebook、部落格 |
| **SEO 關鍵字** | 「XX 是什麼」「XX 由來」「XX 意義」「台灣民俗」 |

#### 線 B 文章結構模板

```
標題：[引發好奇的敘事型標題]

系列標語：不一定要拜，但身為台灣人，你一定要懂。

一、場景開場（畫面感）
   - 用一個具體畫面拉人進來
   - 不預設讀者有任何信仰背景

二、這是什麼？（故事切入）
   - 用傳說、歷史故事帶出背景
   - 冷知識穿插（「你知道為什麼⋯」）

三、怎麼做的？（文化觀察者視角）
   - 描述儀式過程，但語氣是「帶你看」而非「教你做」
   - 重點放在「為什麼這樣做」而非「該怎麼做」

四、背後的意義
   - 象徵解析（宇宙觀、價值觀、人倫秩序）
   - 連結到台灣人的集體記憶

五、文化認同收尾
   - 回到「不管你拜不拜，這就是我們的文化」
   - 不說教、不勸信、有溫度

結尾金句：「拜不拜是信仰，懂不懂是文化。」
底部：連結到線 A 懶人包（「如果你今年想試著拜，這篇有完整攻略 →」）
```

## 系列定位語（所有文章通用）

| 用途 | 定位語 |
|------|--------|
| **每篇文章標語** | 不一定要拜，但身為台灣人，你一定要懂。 |
| **金句圖卡/社群** | 拜不拜是信仰，懂不懂是文化。 |
| **系列名稱建議** | 「台灣拜什麼」系列 / 「你該懂的台灣」系列 |

## 工作流程：從素材到雙線產出

```
Step 1：研究 & 蒐集
    素材庫/民俗知識庫/[主題].md
    ↓
    （一份完整的知識檔，包含所有素材）

Step 2：事實查核
    驗證正確性，標注查核紀錄
    ↓

Step 3：雙線改寫（同時或先後皆可）
    ├── 🅰️ 懶人包版
    │     讀取素材 → 套用線 A 模板 → 精簡為清單/步驟
    │     輸出：01-内容生产/选题管理/02-制作中/[主題]-懶人包.md
    │
    └── 🅱️ 文化推廣版
          讀取素材 → 套用線 B 模板 → 改寫為敘事/文化觀點
          輸出：01-内容生产/选题管理/02-制作中/[主題]-文化推廣.md

Step 4：標題優化
    各自依照目標受眾產出 3-5 個標題選項

Step 5：互相連結
    A 篇底部連結 B 篇，B 篇底部連結 A 篇
    形成「想做的人看 A，想懂的人看 B」的閱讀閉環

Step 6：發布
    依平台特性選擇發布版本
```

## 同一個主題，兩條線的差異示範

以「天公生」為例：

### 標題對比

| | 線 A（懶人包） | 線 B（文化推廣） |
|--|--|--|
| **標題** | 天公生怎麼拜才對？頂桌下桌供品、流程、禁忌完整指南 | 天公生：那個讓全台灣半夜不睡覺的日子，到底在忙什麼？ |
| **搜尋意圖** | 「天公生怎麼拜」「天公生供品」 | 「天公生是什麼」「天公生由來」 |

### 開頭對比

**線 A 開頭**：
> 正月初九天公生，是玉皇大帝的生日，也是一年中規格最高的祭拜。
>
> 不確定怎麼準備？這篇整理好了——供品清單、頂桌下桌怎麼擺、拜拜流程、禁忌事項，照著做就不出錯。

**線 B 開頭**：
> 每年農曆正月初九，台灣有一群人會在半夜起床，甚至徹夜不眠。
>
> 他們在家門口搬出兩張桌子——一張墊得高高的，一張正常高度；高的那張只放素菜和水果，矮的那張才有雞有魚。甘蔗要連根帶葉立在兩側，黃色的鋸齒紙錢綁在上面隨風飄。
>
> 你可能拜過，可能沒拜過，也可能根本不知道為什麼阿公阿嬤要這麼忙。但無論你的信仰是什麼，這件事已經在台灣流傳了好幾百年。它是台灣文化的一部分，不一定要照做，但值得認識。

### 同一段知識的不同寫法

**知識點**：頂桌全素、下桌有葷

**線 A 寫法**：
> ⚠️ 頂桌全素（拜天公本尊），下桌可葷（拜天兵天將）。紅龜粿放下桌（龜形屬動物造型）。

**線 B 寫法**：
> 頂桌和下桌用「幾張桌子、放多高、擺什麼」來呈現宇宙秩序：天公在最高位置，用最清淨的供品，象徵尊天重德；下桌的葷食和豐盛菜餚，像請功、領賞，感謝天兵天將在各處守護人間。

## 適用範圍

此方法論適用於所有民俗主題：

| 主題 | 線 A 方向 | 線 B 方向 |
|------|----------|----------|
| 天公生 | 怎麼拜、供品清單 | 半夜不睡覺的文化故事 |
| 中元普渡 | 普渡供品＋流程＋禁忌 | 台灣人和「好兄弟」的獨特關係 |
| 媽祖繞境 | 跟香裝備清單＋路線攻略 | 為什麼百萬人願意走九天八夜 |
| 清明掃墓 | 掃墓供品＋培墓流程 | 台灣人的慎終追遠怎麼一回事 |
| 尾牙 | 尾牙拜拜流程＋頭牙尾牙差別 | 從尾牙看台灣老闆和員工的關係 |
