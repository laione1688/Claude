## 核心指令

### 1. 记录选题
**触发词**: "记录选题"、"新选题"、"有个想法"

**行为**:
1. 询问选题内容
2. 自动添加到 `01-内容生产/选题管理/00-选题记录.md`
3. 标记日期和初步分类

**示例**:
```
用户: 记录选题：妈祖绕境的冷知识
AI: 已记录到选题库，分类：节庆活动 > 妈祖信仰
```

---

### 2. 深化选题
**触发词**: "深化选题"、"写这个"、"展开这个选题"

**行为**:
1. 检索 `素材库/民俗知识库/` 寻找相关知识
2. 检索 `素材库/金句库/` 寻找可复用表达
3. 检索 `03-已发布/` 看是否有相关内容可参考
4. 生成文稿草稿
5. 保存到 `01-待深化的选题/`

---

### 3. 生成小红书内容
**触发词**: "生成小红书"、"小红书版本"

**行为**:
1. 读取 `02-方法论沉淀/小红书标题方法论.md`
2. 生成 3 个标题选项
3. 生成封面文字建议
4. 生成正文（适配小红书风格：emoji + 分段 + 金句结尾）
5. 生成话题标签

---

### 4. 生成抖音脚本
**触发词**: "生成抖音脚本"、"短视频版本"

**行为**:
1. 读取 `02-方法论沉淀/抖音开头方法论.md`
2. 生成 3 个开头 hook 选项
3. 生成完整脚本（控制在 60 秒内）
4. 标注画面建议

---

### 5. 数据复盘
**触发词**: "复盘数据"、"分析爆款"

**行为**:
1. 记录内容表现数据到 `03-内容数据统计/`
2. 分析高表现内容的共性
3. 更新方法论文件

## 内容风格指南

### 台湾民俗内容调性
- **专业但不学究**: 用通俗语言讲专业知识
- **故事感**: 用故事/案例带出知识点
- **接地气**: 结合现代生活场景
- **尊重传统**: 对信仰和仪式保持敬意

### 小红书风格
- 标题要有"冷知识感"或"实用感"
- 正文多用 emoji 分段
- 结尾要有金句或互动引导
- 图片要精美、有氛围感

### 抖音风格
- 开头 3 秒必须有 hook
- 节奏紧凑，信息密度高
- 口语化表达
- 结尾引导关注/评论

## 工作流程图

```
碎片想法
    ↓
[记录选题] → 00-选题记录.md
    ↓
[深化选题] → 检索素材库 + Notion 数据库 → 生成文稿 → 01-待深化的选题/
    ↓
[事实查核] → 验证正确性，标注查核纪录
    ↓
[一源双用产出]  ← 参考 02-方法论沉淀/一源雙用方法論.md
    ├── 🅰️ 实用懒人包 → 清单/步骤/禁忌（服务「要拜的人」）
    ├── 🅱️ 文化推广长文 → 叙事/冷知识/文化认同（服务「所有台湾人」）
    ├── 小红书 → 标题+封面+正文
    └── 抖音 → hook+脚本+画面
    ↓
[互相连结] → A 篇底部连 B 篇，B 篇底部连 A 篇
    ↓
[发布] → 04-发布记录/ + Notion DB_媒體內容
    ↓
[数据复盘] → 03-内容数据统计/ → 更新方法论
```

### 系列核心理念

> **不一定要拜，但身为台湾人，你一定要懂。**

民俗内容系列的定位：无论读者的宗教信仰为何，这些民俗已在台湾流传数百年，是台湾文化的一部分。你可以因宗教而不去信或执行，但你不能不认识——因为你是台湾人。

### Notion 相关指令

#### 6. 搜索 Notion 素材
**触发词**: "搜索素材"、"找参考资料"、"Notion 里有什么"

**行为**:
1. 使用 `mcp__notion__notion-search` 搜索关键词
2. 从「影片收集資料庫」查找相关影片
3. 返回相关素材列表

**示例**:
```
用户: 搜索素材：妈祖
AI: 在 Notion 中找到以下相关素材：
    - [影片] 妈祖绕境全纪录
    - [文章] 2024 大甲妈祖遶境攻略
    ...
```

#### 7. 创建内容到 Notion
**触发词**: "记录到 Notion"、"保存到媒体库"

**行为**:
1. 使用 `mcp__notion__notion-create-pages` 创建新页面
2. 填入内容信息到「DB_媒體內容」
3. 关联相关分类

**示例**:
```
用户: 把这篇中元普渡的内容记录到 Notion
AI: 已创建到 DB_媒體內容：
    - 名称：中元普渡完整攻略
```
