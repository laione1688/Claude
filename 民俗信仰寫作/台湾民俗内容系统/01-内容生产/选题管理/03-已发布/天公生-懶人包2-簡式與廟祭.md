# 天公生怎麼拜(下篇)？簡式供桌與到廟祭祀完整指南

---

拜天公不是只有一種方法。

有人家裡有大院子，能擺出完整的頂桌下桌；有人住大樓，空間有限；有人工作忙，沒辦法準備那麼多供品。

沒關係——天公本來就說「唯誠不破」。誠意到了，方式可以彈性。

---

## 拜天公的三種方式

| | 傳統頂下桌 | 簡式供桌 | 到廟祭祀 |
|--|-----------|---------|---------|
| 誠意象徵 | 無上誠意 | 誠意至上 | 唯誠不破 |
| 準備難度 | 高 | 中 | 低 |
| 空間需求 | 大（需擺兩張桌） | 中（一張桌即可） | 無 |
| 葷素規定 | 頂桌全素／下桌可葷 | **全部純素** | 依廟方規定 |
| 最適合 | 有空間、重傳統的家庭 | 大樓族、第一次拜 | 沒空間、外出族、想跟廟方一起拜 |

## 一、祭拜天公的四個時點

正月初九是天公聖誕（天公生），但祭拜天公不只這一天。以下四個時間點都是重要的祭拜時機：

| 時機 | 說明 |
|------|------|
| 農曆除夕「辭歲」或正月初一「賀正」 | 歲末或新年向天公致意（依地區習慣選一） |
| **正月初九「天公生」** | 玉皇大帝聖誕，一年中規格最高的祭祀 |
| 七夕「做十六歲」 | 子女成年禮，感謝天公護佑長大 |
| 結婚「謝天公」 | 婚禮中對天公的感恩祭拜 |

> 本篇流程與祝禱詞以正月初九天公生為例。其他時點祭拜，調整祝禱詞「今日是……」的開頭即可。

## 二、簡式供桌（誠意至上）

### 適合對象
住大樓、空間不足、第一次準備，或想以誠心為主、不追求繁複形式的家庭。

### 祭拜時辰
農曆正月初九，**子時（初八晚上 11:00）** 開始，最遲初九中午前。

### 祭拜地點
家門前、門前空地、佛堂前、陽台或頂樓——**見天即可**。

---

### 供品清單（全部純素）

| 品項 | 數量 / 說明 |
|------|-----------|
| 茶杯 | **9 個小紙杯**，斟清茶 |
| 壽麵（麵線） | 3 小束 |
| 壽桃 | 3 盤 |
| 山珍海味 | 薑、鹽、紅豆（或黑豆）、糖，各一小包或小盤 |
| 水果 | 隨意搭配，以奇數盤為佳 |
| 鮮花 | 一對 |
| 燈具 | 一對（電燈或紅色大蠟燭） |
| 香爐 | **另備一個**，不取家中佛堂的爐 |

> ⚠️ 簡式供桌**供品千萬不能有葷食**，一定要全素。

---

### 供桌排列

```
[面向外/天空方向]

┌──────────────────────────────┐
│  9個茶杯（排最外一列）         │
│  壇香爐（正中央）              │
│  神燈 ── 香爐 ── 神燈          │
│  鮮花 ── 香爐兩側 ── 鮮花      │
│  壽麵、壽桃、山珍海味（主體）   │
│  水果（任意擺設）              │
└──────────────────────────────┘
桌腳四角各墊壽金
```

**設置要點：**
- 桌子放在門口無遮蔽處，朝外祭拜
- 桌腳下用壽金墊高（象徵托起對天公的敬意）
- 9 個茶杯排在桌子外緣最前列
- 壇香爐（靜香爐）擺正中央，兩側放神燈，再外側放鮮花

---

### 金紙

| 金紙 | 數量建議 |
|------|----------|
| 天金、尺金 | 各適量 |
| 壽金 | **至少 3 大支**（此為基本） |
| 太極金或財寶金 | 依個人意願加 |

> 各地風俗不同，金紙配方以當地宮廟或金紙行建議為準。

---

### 拜拜流程

**📅 初八下午——採買備料**
- 購齊供品、金紙、蠟燭或電燈、香

**🏗️ 初八傍晚——設置供桌**
- 桌腳墊壽金，朝門外擺放
- 9 個茶杯排最前列
- 香爐置中，神燈兩側，鮮花再外

**🍽️ 初八晚上 10:30——擺放供品**
- 壽麵、壽桃、山珍海味、水果依序擺好
- 倒入清茶

**🙏 晚上 11:00（子時）——正式祭拜**

1. 點蠟燭（或開電燈）
2. 每人點三炷香
3. 由內往外，站著拜三次
4. 跪下（主祭者必跪，其餘隨意；最好全家跪）
5. 先行九拜
6. 主祭者誦讀祝禱詞（見第四節）
7. 起身，將香插入香爐
8. 回到原位，行九個磕頭禮
9. 獻茶

**第一柱香燒至一半** → 上第二柱香，重複步驟 3-9

**第二柱香燒至一半** → 上第三柱香，重複步驟 3-4

**第三柱香燒至一半** → 雙手捧持金紙，向神明稟告

🔥 **燒金紙** → **放鞭炮**（視環境，可省略）

## 三、到廟祭祀（唯誠不破）

### 適合對象
沒有空間在家設壇、外出工作族，或想和更多信眾一起祭拜天公、感受廟裡的氛圍。

---

### 祭拜地點

**選項一：家附近的宮廟**

有供奉玉皇大帝的宮廟皆可。祭拜方式以各廟規定為準——有的子時就開始拜壽，有的正月初九白天才舉行活動。

> 建議提前打電話詢問廟方拜壽時間。

**選項二：天公廟**

全台知名天公廟：台南天壇（俗稱天公廟）、台南開基玉皇宮、各地天公廟。

正月初九子時（初八晚上 11:00）起開始正式拜壽，人潮從深夜延續到天亮。

---

### 祭拜供品

| 品項 | 說明 |
|------|------|
| 五果 | 5 種水果 |
| 壽桃 | 象徵祝壽 |
| 壽麵 | 象徵長壽 |
| 其他 | 依個人心意自由搭配 |

> 部分廟宇有提供固定供品組合可直接購買。

### 金紙
廟中通常有販售，現場購買即可。

### 拜拜流程
**依廟方人員的指引進行**。

到廟拜天公，廟方自有完整的祭拜流程，跟著廟方引導走就好。若不確定如何進行，向服務人員詢問即可，廟方人員都很樂意幫忙。

---

## 四、祝禱詞（三種方式通用）

三種祭拜方式，祝禱詞都一樣。說出自己的姓名和心意，天公都能聽到。

---

**正式祝禱詞：**

> 【敬請、奉請、拜請 玉皇大天尊聖駕】（唸三次）
>
> 今天欣逢 玉皇大天尊聖誕千秋，蟻民○○○，帶我全家大小，誠心誠意【恭祝 玉皇大天尊，聖壽無疆、萬壽聖壽】（唸三次）
>
> 蟻民備有壽麵、壽桃、山珍海味、鮮花、茶水及水果，以略表敬意，懇請【玉皇大天尊】能以笑納。
>
> 於此蟻民懇請【玉皇大天尊】能恩賜天下眾生眾靈，無災無難；能開恩赦免天下眾生眾靈無知冒犯之罪。
>
> 再請【玉皇大天尊】能恩賜蟻民○○○全家平安健康、家庭美滿、萬事如意、事業順利，兒女們學業進步。

**使用說明：**

| 項目 | 替換方式 |
|------|----------|
| ○○○ | 填入自己的名字 |
| 到廟拜時 | 姓名後加上「住址○○○」 |
| 男性自稱 | 「蟻民」 |
| 女性自稱 | 「蟻女」 |

## 五、常見問題

**Q：簡式供桌一定要 9 個杯子嗎？**
9 是陽數之極，對應天公的地位。但數字是心意的外在形式，沒有準備那麼多杯子，以 3 杯清茶代替也可以。

**Q：到廟拜有必要帶自己的供品嗎？**
不一定。很多廟宇有統一的供品安排，也有些讓信眾自備。建議先問廟方，依廟方建議為準。

**Q：簡式供桌和頂下桌哪個比較「有效」？**
天公本身就說「唯誠不破」。三種方式的差別在形式，不在誠意。能準備頂下桌當然好，但條件不允許時，一杯清茶一個心意，天公一樣收得到。

**Q：祝禱詞一定要唸那麼長嗎？**
不一定。祝禱詞是引導架構，讓你有依據表達心意。但最重要的是真誠說出自己想說的，可以根據自己的情況加入祈求的事項。
