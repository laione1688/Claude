# 天公生怎麼拜才對(上篇)？頂桌下桌供品、流程、禁忌完整指南

---

正月初九天公生，是玉皇大帝的生日，也是台灣一年中規格最高的祭拜。

不確定怎麼準備？這篇整理好了——供品清單、頂桌下桌怎麼擺、拜拜流程、禁忌事項，照著做就不出錯。

## 拜天公有三種方式

| 方式 | 特色 | 適合對象 |
|------|------|----------|
| ● **傳統頂下桌**（本篇） | 規格最完整、誠意最高 | 有空間、重傳統的家庭 |
| ● 簡式供桌 | 全素一桌，彈性方便 | 大樓族、第一次拜 |

## 一、30 秒搞懂天公生

- **拜誰**：玉皇大帝（民間稱「天公」），民間信仰中最高階的神明
- **什麼時候拜**：農曆正月初九。最佳時間是初八晚上 11 點（子時），最晚初九中午前
- **在哪拜**：家門口、陽台、頂樓——面向天空
- **最大特色**：要擺「頂桌」和「下桌」，兩張桌子、兩種規格
- **為什麼是初九**：「九」是陽數之極，正月是一年之首，初九就是最大月份配最大數字——給最高的神明。明初《蠡海集》：「陽數始於一，而極於九，原始要終也。」

---

## 📖 天公生的由來（簡要版）

拜天公這件事，不是從來就有的。

最早的「祭天」是皇帝的專利，老百姓根本不能拜。後來道教把抽象的「天」變成了有名有姓的「玉皇大帝」，給了他天庭、部屬、還有生日。再後來，閩南人把這套傳統帶到台灣，發展出了我們今天熟悉的頂桌下桌、甘蔗天門、半夜子時開拜。

而那兩根甘蔗？背後藏著一段閩南人躲進甘蔗林逃過劫難的故事。「甘蔗」閩南語近似「感謝」——每年立在供桌旁，是對天公救命之恩的感激。

**從天子獨拜到家家戶戶門口的天公生，走了兩千多年。** 這段故事比你想的更精彩。

## 二、頂桌下桌怎麼擺？

天公生獨有的雙層祭壇，記住一句話：**上桌清素敬天公，下桌豐盛謝部屬。**

```
[面向外/天空方向]

  🎋 甘蔗（帶葉）          🎋 甘蔗（帶葉）
     ╲  ──── 篙錢 ────  ╱
      ╲                ╱
┌──────────────────────────┐
│       頂 桌（高）         │  ← 板凳或金紙箱墊高，鋪紅布
│      拜天公本尊           │     全素供品 + 清茶
│    （壽金墊底）           │
├──────────────────────────┤
│       下 桌（低）         │  ← 一般高度
│     拜天公部屬神明        │     三牲/五牲 + 酒
└──────────────────────────┘

[面向內/家中方向]
```

**設置要點：**
- 頂桌用板凳或金紙箱墊高，鋪上紅布，前方繫桌圍
- 頂桌底部以壽金墊底
- 兩側各立一根**連根帶葉的甘蔗**，頂端用紅繩綁成拱門（甘蔗天門）
- 甘蔗上綁**篙錢**（黃色鋸齒狀長條紙錢）

## 三、供品清單

### 頂桌（全素）——拜天公本尊

| 品項 | 數量 | 意義 |
|------|------|------|
| 清茶 | 3 杯 | 敬天 |
| 壽麵（麵線） | 3 束或 5 束，紮紅紙 | 為天公祝壽 |
| 水果 | 5 種各一盤 | 五福臨門 |
| 齋菜 | 傳統 12 碗或 24 碗；簡化版 5-6 道 | 素淨敬天 |
| 發粿 | 一疊 | 發財興旺 |
| 年糕 | 一疊 | 年年高升 |
| 素餅/糕點 | 各式甜糕、紅圓 | 甜蜜圓滿 |
| 紅棗、桂圓、糖果 | 各一碟 | 吉祥 |
| 山珍海味 | 薑一盤（山）、紅豆一盤（珍）、鹽一盤（海）、糖一盤（味） | 四字對四物，象徵山海珍品 |
| 鮮花 | 一對 | 敬獻 |
| 紅蠟燭 | 一對 | 光明 |

**適合的水果**：柑橘、蘋果、鳳梨、柳丁、香蕉、香瓜、柿子

**⚠️ 不能用的水果**：番茄、芭樂（籽多不潔）、釋迦（似佛頭）、李子（犯太上老君名諱）

### 下桌（可葷）——拜天兵天將

| 品項 | 說明 |
|------|------|
| 三牲或五牲 | 豬肉、全雞（閹公雞，禁鳳頭雞/白毛雞/母雞）、全魚（五牲加鴨和其他） |
| 酒 | 3 杯或 5 杯 |
| 水果 | 2-3 種 |
| 紅龜粿 | 放下桌（龜形屬動物造型，不宜放頂桌） |
| 糕餅點心 | 米荖、餅乾、糖果 |

### 快速對照表

| | 頂桌 | 下桌 |
|--|------|------|
| 拜誰 | 天公 | 天兵天將 |
| 高度 | 墊高 | 一般 |
| 葷素 | **全素** | 可葷 |
| 喝的 | 清茶 | 酒 |

## 四、簡化版（大樓族 / 第一次拜 / 空間有限）

空間不夠或第一次準備，抓住這些重點就好：

**頂桌最低限度：**
- 供桌墊高一個區域，鋪紅布
- 蠟燭一對、香、香爐
- 三杯清茶
- 3-5 種水果
- 壽麵一份
- 幾道素菜（家常即可）
- 天公金幾疊

**下桌最低限度：**
- 一兩道葷食（熟食、外帶菜也行）
- 一兩樣水果
- 餅乾或糖果
- 幾疊一般金紙

甘蔗天門、篙錢、燈座等可以慢慢加，不用一次到位。

**住大樓怎麼辦？**
- 陽台面向外：窗戶打開，擺頂下桌
- 窗戶旁：空間不足就在最大窗戶邊擺簡易供桌
- 頂樓：協調社區使用
- 最簡單：去天公廟拜

## 五、拜拜流程（Step by Step）

### 📅 初八下午——採買備料
- 購齊供品、金紙、紅蠟燭、香
- 三牲烹煮
- 水果洗淨

### 🏗️ 初八傍晚——設置供桌
- 面向天空處擺桌
- 墊高頂桌，鋪紅布，繫桌圍
- 立甘蔗，綁篙錢
- 壽金墊底

### 🍽️ 初八晚上 10:00-10:30——擺放供品
- 頂桌：素供品、倒清茶
- 下桌：三牲/五牲、倒酒
- 金紙放旁邊

### 🙏 晚上 11:00（子時）——正式祭拜
1. 點紅蠟燭
2. 點三柱香（可每人三柱，以三的倍數為原則）
3. 面向天空，雙手持香
4. 誠心禱告（見下方）
5. 香插入頂桌香爐
6. 下桌也上三柱香
7. 全家依序上香

### ⏳ 等候 30-40 分鐘
- 香燒過三分之二，擲筊請示是否享用完畢
- 聖筊 → 下一步
- 沒聖筊 → 再等一下重擲

### 🔥 燒金紙
- **先燒頂桌**：天公金 → 大壽金 → 壽金
- **再燒下桌**：壽金 → 刈金 → 土地公金
- 最後投入天公座，象徵送天公回天庭

### 🧹 撤供
- 金紙燒完收拾供品
- 放鞭炮（視環境，可省略）

（男性自稱「弟子」，女性自稱「信女」）

## 七、金紙怎麼燒？

| 金紙 | 用途 | 數量建議 |
|------|------|----------|
| 天公金（天尺金） | 專拜玉皇大帝 | 1-3 疊 |
| 大壽金 | 天公祝壽專用 | 1-3 疊 |
| 壽金 | 天公及眾神通用 | 3-5 疊 |
| 刈金 | 天兵天將 | 適量 |
| 土地公金 | 附帶敬拜土地公 | 1 疊 |
| 天公座（紙糊） | 送天公回天庭 | 1 座 |

**順序**：頂桌金紙先燒完 → 下桌金紙 → 天公座

## 八、禁忌提醒

### ⚠️ 供品禁忌
- ❌ 番茄、芭樂（籽多不潔）
- ❌ 釋迦（似佛頭）
- ❌ 李子（犯太上老君名諱）
- ❌ 頂桌不放葷食（紅龜粿也放下桌）
- ❌ 供品掉地上要更換

### ⚠️ 行為禁忌
- ❌ 初八晚到初九全天不曬女性內衣褲
- ❌ 不可口出穢言（民間相信恐影響整年運勢）
- ❌ 不可說「死」字（大吉之日避不吉利字眼）
- ❌ 不可隨意發毒誓（天公生日發的誓最靈驗）
- ❌ 不可用手指天（天公在天上巡視，指天為不敬）
- ❌ 祭拜時不嬉鬧
- ❌ 不在頂樓/陽台晾曬不潔之物
- ❌ 初九不宜殺生

### 🐔 下桌雞的規矩
- ✅ 用**閹公雞**
- ❌ 禁鳳頭雞、白毛雞、母雞

### 🛁 祭前準備
- ✅ 沐浴淨身、穿著整齊端莊
- ✅ 紅色或喜氣顏色佳
- ❌ 避免黑色、過於暴露、破舊衣物
- ❌ 不赤腳、不穿拖鞋

## 九、常見問題

**Q：錯過子時怎麼辦？**
初九清晨（5:00-7:00）補拜；最遲正月十五前擇日。但初九最正統。

**Q：可以不拜嗎？**
不拜不會被處罰。但在傳統家庭這是一年最重要的祭祀。

**Q：素食者下桌怎麼辦？**
用「素三牲」替代（素雞、素魚、素肉），市面有現成組合。酒可用素酒或清茶代替。

**Q：除夕拜天公和初九天公生有什麼不同？**
除夕是歲末感恩、規格可簡化；初九是天公生日，最高規格，要完整頂下桌。

**Q：山珍海味是什麼？要擺真的海鮮嗎？**
不用。四個字各對一物——薑（山）、紅豆（珍）、鹽（海）、糖（味）。糖還有「苦盡甘來」的寓意。這是古早農村的象徵做法，不必擺高價海鮮。
