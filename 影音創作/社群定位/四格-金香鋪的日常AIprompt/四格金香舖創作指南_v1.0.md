# 四格—金香鋪的日常｜創作指南 v1.0
版本：2025.01  
風格定調：日常 × 人味 × 微療癒 × 留白哲思  

## 🎯 一、創作的最終目的（靈魂）
> 用最日常的小事，在讀者心裡打開三種感受之一：
> 「被療癒了、被提醒了、我懂了。」
> 不是教人，而是陪人把心放一點下來。

本系列不是宗教故事、不是心靈雞湯、不是心理學文章。
它是一間金香舖裡的日常人情味，
在淡淡的生活對話中，
給人心裡一個「阿～」的瞬間。

## 🎯 二、三大核心心效（每篇至少對到一個）
### 1｜療癒（心鬆一點）
- 語氣溫柔、不煽情、不強說教  
- 讓讀者覺得「原來不是只有我這樣」  
- 透過被理解、被看到而療癒  

例：
「不是不感謝，是沒力氣說。」

### 2｜領悟（啊～原來我少了這個）
- 不是教，而是點醒  
- 提供生活盲點的溫柔提醒  
- 大師兄一句話，就是整篇的亮點  

例：
「運不是等來的，是穩出來的。」

### 3｜理解（啊～我懂了）
- 把模糊的生活情緒說清楚  
- 讓讀者覺得事情落地、心也落地  
- 帶來「喔～原來這樣」的感覺  

例：
「善意給出去，回來一句，兩邊都暖。」

## 🎯 三、四格結構（固定節奏、不能破壞）
| 頁 | 功能 | 對應心效 |
|----|------|-----------|
| 第一頁｜hook | 一句情緒入口，吸引人滑下去 | 領悟／理解／療癒 |
| 第二頁｜事件 | 真實日常小事，不戲劇化 | 理解 |
| 第三頁｜觀點 | 大師兄／美麗姐的一句生活智慧 | 領悟／療癒 |
| 第四頁｜金句收尾 | 餘韻、留白、落地感 | 三者之一 |

第一頁不是摘要，是「情緒引導」。  
第四頁不是總結，是「心效落地」。

## 🎯 四、語氣原則
### 1. 一切都要日常台灣口氣
### 2. 情緒要淡（淡才療癒）
### 3. 永遠保留空氣（留白＝療癒）
### 4. 一切都要真（像生活會發生的話）

## 🎯 五、角色功能
- 阿姨＝反映讀者的累、痛、沉默  
- 美麗姐＝人情味、庶民感  
- 大師兄＝生活智慧的一句  
- 學徒＝讀者的觀察視角  

故事是容器，金句才是核心。

## 🎯 六、金句規範
金句必須：
- 短  
- 生活化  
- 不說教  
- 留白  
- 讓讀者心裡有「阿～」的瞬間  

## 🎯 七、金香舖式療癒的定義
不是治療  
不是成長學  
不是心靈雞湯  

是：
生活裡被理解、被看到、被托住的一瞬間。

## 🎯 八、整體作品氛圍
- 暖  
- 淡  
- 留白  
- 微光  
- 不大聲  
- 有人味  
- 有庶民感  
- 有生活的智慧
