# 香供養專題紀實撰寫指引

## 一、核心寫作原則

### 1. 真實性優於修辭
- **第一人稱紀實**：以參與者視角記錄，強調「我看到」「我感受到」
- **具體細節**：記錄實際發生的事物（香煙升起、誦經聲響、參與者表情）
- **避免過度美化**：不使用浮誇詞彙，保持樸實真誠的語氣
- **情感真實**：記錄真實的感動時刻，而非刻意煽情

### 2. 文化尊重與準確性
- **正確使用宗教術語**：觀世音菩薩、福德正神、香供養（非捐香）
- **儀式細節準確**：按實際流程記錄（插香→獻供→誦讀文疏→祈願→焚化）
- **避免商業化語言**：不使用「產品」「服務」等詞，改用「陪伴」「傳遞」
- **保持謙卑定位**：明心福旺閣是「陪伴者」「傳遞者」，非「主辦方」「服務提供商」

### 3. 敘事結構
- **時間線清晰**：按儀式實際進行順序記錄
- **畫面感強烈**：讓讀者如同親臨現場
- **情感層次遞進**：從準備→進行→高潮（誦經或祈願）→收尾
- **結尾留白**：以香煙升起、願望傳達等意象收尾，不過度解釋

## 二、必須記錄的要素

### 基本資訊
- [ ] 日期（國曆+農曆）
- [ ] 地點（寺廟全名+地理位置）
- [ ] 主祀神明（正確稱呼）
- [ ] 參與人數或供養數量
- [ ] 天氣狀況（如對氛圍有影響）

### 儀式流程
- [ ] 香品進廟畫面
- [ ] 供品擺設細節
- [ ] 插香時刻
- [ ] 誦讀文疏（可摘錄關鍵段落）
- [ ] 祈願引導
- [ ] 焚化文疏
- [ ] 展示感謝狀

### 感官細節
- [ ] 視覺：香煙升起、供品擺設、廟宇莊嚴
- [ ] 聽覺：誦經聲、鐘鼓聲、蟲鳴鳥叫
- [ ] 嗅覺：香氣、供花香氣
- [ ] 觸覺：晨風、香品質感
- [ ] 氛圍：寧靜、莊嚴、溫暖

### 人物互動
- [ ] 工作團隊準備過程
- [ ] 主持人儀態與誠意
- [ ] 參與者反饋（如有）
- [ ] 廟方人員互動

## 三、禁止事項

### 語言風格禁止
❌ 「我們很榮幸」「我們很高興」等官方腔調
❌ 「本次活動」「服務項目」等商業用語
❌ 「圓滿成功」「取得良好效果」等報告式語言
❌ 過度使用感嘆號和表情符號

### 內容禁止
❌ 誇大功德效果（如「必定財運亨通」）
❌ 承諾特定結果（如「願望一定實現」）
❌ 比較或貶低其他方式（如「比捐香更有效」）
❌ 揭露參與者個人隱私資訊

### 立場禁止
❌ 以主辦者姿態講述
❌ 以教導者姿態說明
❌ 以銷售者姿態推廣
✅ 以陪伴者、見證者、傳遞者姿態記錄

## 四、寫作框架模版

### 開場段（營造情境）
```
[時間] + [地點] + [天氣/氛圍描述]
例：「2024年6月23日清晨，農曆五月廿八日，竹林山觀音寺籠罩在一片寧靜的晨霧中。」
```

### 準備段（儀式前準備）
```
[團隊到達] + [供品準備] + [心情描述]
例：「我們在早晨七點半就抵達寺廟，小心翼翼地將每一份香品從車上搬下，每一束香都貼著供養者的名條。」
```

### 進行段（儀式核心）
```
[插香] + [獻供] + [誦讀文疏] + [感官細節]
例：「當主持人開始誦讀敬告文疏時，晨風輕輕拂過，香煙裊裊升起，彷彿真的將每個人的心願帶往天際。」
```

### 高潮段（最動人時刻）
```
[關鍵儀式] + [情感共鳴] + [畫面定格]
例：「『南無觀世音菩薩』三聲誦念後，現場陷入靜謐，只有香煙無聲地向上飄散，那一刻，時間彷彿靜止了。」
```

### 收尾段（儀式結束）
```
[焚化文疏] + [整理供品] + [感謝與祝福]
例：「文疏在火焰中化為灰燼，隨著輕煙消散，我們相信，每一份心願都已傳達。」
```

### 後記段（活動後感想）
```
[回顧意義] + [參與者反饋] + [未來展望]
例：「離開寺廟時，回頭望著那依然裊裊升起的香煙，心中滿是感恩。這不只是一場儀式，而是信仰的真實傳遞。」
```

## 六、範例分析

### 優秀範例特徵
```
✅ 「清晨的竹林山，霧氣還未散去，我們已經開始為今日的香供養做準備。」
   → 第一人稱、具體時間、真實場景

✅ 「當主持人將文疏焚化時,火光映照在每個人臉上,那一刻,我感受到信仰的重量。」
   → 畫面感、情感真實、不過度詮釋

✅ 「香煙裊裊升起,我們靜靜地看著,不需要多說什麼,心意已傳達。」
   → 留白、意境、尊重信仰
```

### 需改進範例
```
❌ 「本次活動圓滿成功,參與者紛紛表示非常滿意。」
   → 改為：「離開時,幾位參與者向我們點頭致意,眼中滿是感謝。」

❌ 「我們提供專業的香供養服務,確保每個環節都精準執行。」
   → 改為：「我們用心準備每個細節,希望能準確傳達每份心意。」

❌ 「通過本次香供養,大家一定能獲得菩薩庇佑,財運亨通!」
   → 改為：「我們誠心祈願,希望每份心意都能上達天聽。」
```

## 七、不同平台調整建議

### Facebook 長文
- 字數：1000-1500字
- 加入分段標題（用表情符號區隔）
- 可加入3-5張現場照片
- 結尾附上聯繫方式

### Instagram 貼文
- 字數：600-800字
- 分段更短促
- 前3行要吸引人（會被折疊）
- 多用表情符號營造視覺節奏

### 網站文章
- 字數：1500-2500字
- 可加入更多背景說明
- 加入小標題便於閱讀
- 可附上完整照片集

### LINE@ 訊息
- 字數：300-500字
- 重點摘要式呈現
- 溫暖問候開場
- 加入照片連結

## 九、常見問題 Q&A

### Q1: 如何平衡真實性與文學性?
A: 真實性優先,文學性為輔。先記錄事實（時間、地點、流程）,再用文學手法描繪感官細節（香煙、光線、聲音）,但絕不虛構未發生的事。

### Q2: 如何避免寫成流水帳?
A: 抓住2-3個「定格畫面」深入描寫,而非平鋪直敘所有流程。例如重點描寫「香煙初升那刻」「誦讀文疏時的靜謐」,其他流程簡單帶過。

### Q3: 如何處理參與者個人隱私?
A: 只記錄群體感受,不記錄個人身份資訊。可寫「一位年輕母親」「幾位長者」,但不寫全名或具體身份。

### Q4: 如何寫出感動而不煽情?
A: 用畫面和細節說話,而非形容詞堆砌。例如:
- 煽情:「大家都非常感動,熱淚盈眶」
- 感動:「一位阿姨安靜地拭去眼角的淚,對著菩薩深深一拜」

### Q5: 如何體現明心福旺閣的角色?
A: 使用「我們陪伴」「我們見證」「我們傳遞」,而非「我們舉辦」「我們提供」「我們主辦」。

## 十、持續優化方向

### 收集反饋
- 記錄讀者留言中的關鍵詞
- 觀察哪類描述引起共鳴
- 統計不同平台的互動數據

### 建立素材庫
- 收集不同寺廟的特色描述
- 整理各神明的典型儀式細節
- 累積不同天氣、時段的氛圍描寫

### 團隊共識
- 定期檢視已發布文章
- 討論哪些表述需要調整
- 統一品牌語調和立場

---

**最後提醒**

每一篇紀實,都是對信仰的尊重、對參與者的負責、對文化的傳承。
寫作時請時刻問自己:
- 這樣寫,是否真實?
- 這樣寫,是否尊重?
- 這樣寫,是否謙卑?

如果三個答案都是「是」,那就是一篇好的紀實。
