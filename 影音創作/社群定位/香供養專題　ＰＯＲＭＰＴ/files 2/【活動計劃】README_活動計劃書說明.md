# 📋 活動計劃書說明

## 📁 這個分類包含什麼

此分類的檔案用於存放各場香供養活動的完整計劃文件，包括：
- 活動流程稿
- 主持人稿
- 疏文範本
- 攝影指引

## 💡 使用方式

### 規劃新活動時

1. **選擇對應神明的範本**
   - 觀音 → 參考觀音流程稿
   - 土地公 → 參考福德正神流程稿
   - 財神 → 可參考現有流程稿調整

2. **複製範本並調整**
   - 時間、地點
   - 供品清單
   - 特殊儀式

3. **準備配套文件**
   - 主持人稿
   - 疏文
   - 攝影指引

---

## 📌 注意事項

- 不同神明的流程可能有差異
- 直播活動需要特別的主持人稿
- 疏文格式要遵循傳統規範
