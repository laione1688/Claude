## 📋 5種任務類型

### 1️⃣ 撰寫活動紀實
- **觸發詞：** "寫紀實" "記錄活動"
- **使用檔案：** 紀實模版 + 參考文案
- **規則：** 嚴格執行（見證者角度）

### 2️⃣ 撰寫行銷文案
- **觸發詞：** "寫FB文案" "IG貼文"
- **使用檔案：** 品牌設定
- **規則：** 彈性（但保持品牌語調）

### 3️⃣ 編寫疏文
- **觸發詞：** "寫疏文" "敬告文疏"
- **使用檔案：** 疏文範本
- **規則：** 嚴謹遵守格式

### 4️⃣ 規劃活動流程
- **觸發詞：** "規劃活動" "設計流程"
- **使用檔案：** 活動計劃書範本
- **規則：** 參考但可調整

### 5️⃣ 客服回覆
- **觸發詞：** "客服" "回覆訊息"
- **使用檔案：** 品牌設定
- **規則：** 溫暖專業

## 🎨 三種神明的寫作差異

| 神明 | 核心特質 | 觀察點方向 | 語調特色 |
|---|---|---|---|
| **觀音** | 溫柔、慈悲、撫慰 | 心靈層面、被包容 | 柔和、細膩、感性 |
| **土地公** | 實在、考驗、成長 | 生活層面、挑戰 | 接地氣、直接、務實 |
| **財神** | 明確、直接、回應 | 財運、具體效果 | 理性、明快、清晰 |

## 📌 品牌核心原則（適用所有內容）

### ✅ 我們是什麼
- 陪伴者（不是主辦方）
- 傳遞者（不是詮釋者）
- 服務者（不是推銷者）

### ❌ 我們不是什麼
- 不替神明說話或詮釋神意
- 不保證效果或承諾結果
- 不製造焦慮或販賣恐懼
- 不過度推銷或強迫推廣

### 🎯 語調特色
- 真誠、溫暖、專業
- 尊重傳統但不說教
- 陪伴但不越界
- 務實但不功利

## 🔄 工作流程

### 撰寫新紀實時

```
1. 收集素材
   ├─ 活動資訊（時間、地點、神明、人數）
   ├─ 觀察點（3-5個具體畫面）
   └─ 參考文案（同神明過往紀實）

2. 填寫模版
   ├─ 打開：AI_Prompt模版.md
   ├─ 填寫所有【必填】欄位
   └─ 貼上參考文案內容

3. 提交給 AI
   ├─ 複製整份模版
   ├─ 貼到 Claude 對話中
   └─ AI 自動參考專案檔案產出

4. 檢查修正
   ├─ 用5個檢查問題驗證
   ├─ 必要時要求修正
   └─ 確認通過後定稿

5. 存檔發布
   ├─ 存到 4_產出文章/對應資料夾
   ├─ 發布到各平台
   └─ 優質文章加入參考文案庫
```

## 💡 常見問題

**Q1: 第一次使用從哪裡開始？**
A: 先讀「使用說明書」，了解7步驟流程

**Q2: 寫觀音紀實和財神紀實有什麼不同？**
A: 語調不同，參考「Custom Instructions」中的神明對比表

**Q3: 可以修改模版嗎？**
A: 可以，但建議保留核心規則

**Q4: 產出的文章要存在哪裡？**
A: 存在「4_產出文章」，好的文章可加入「2_參考文案庫」

**Q5: 需要把所有檔案都上傳到 Claude 專案嗎？**
A: 不用，只上傳 1、2、5 資料夾的檔案即可
