# 📖 香供養紀實 AI Prompt 模版使用說明書

## 🎯 這份文件是什麼？

這是一個**AI寫作模版**，用來指導AI（如Claude、ChatGPT）撰寫高品質的香供養活動紀實文章。

**不是**：
- ❌ 不是給人看的文章範本
- ❌ 不是一般的寫作指南
- ❌ 不是直接複製貼上就能用的文案

**是**：
- ✅ 給AI的完整指令集
- ✅ 填空後貼給AI使用
- ✅ AI會根據你填的內容產出文章

---

## 📋 完整使用流程（7步驟）

### 步驟1️⃣：準備素材（活動前/後）

在使用模版前，你需要先準備這些資料：

```
□ 活動基本資訊
  - 日期（國曆+農曆）
  - 地點（寺廟全名）
  - 主祀神明（全稱）
  - 供養人數、香品重量

□ 活動流程文件
  - 找到對應的「活動計劃書」檔案名稱
  （例如：「1140713-0714福德正神香供養流程稿.docx」）

□ 參考文案（至少2篇）
  - 同一個神明的過往紀實
  - 類似場景的紀實
  （從過往發布的文章中挑選）

□ 觀察點（3-5個）
  - 活動中你注意到的特別畫面
  - 令你印象深刻的時刻
  - 特殊狀況或感受
```

---

### 步驟2️⃣：開啟模版檔案

**檔案位置：**
- 檔名：`香供養紀實_AI_Prompt模版.md`
- 路徑：專案資料夾 > 香供養專題

**開啟方式：**
1. 用任何文字編輯器打開（記事本、Word、VSCode都可以）
2. 建議用Markdown編輯器（可以看到格式）
3. 或直接在Claude.ai的專案中查看

---

### 步驟3️⃣：填寫模版（最重要）

依序填寫每個區塊的內容：

#### 📝 1️⃣ 基本資訊【必填】

```
找到這個區塊：
【日期】
國曆：________年____月____日
農曆：________年____月____日

填入實際資訊：
【日期】
國曆：2024年7月14日
農曆：甲辰年六月二十日
```

**填寫重點：**
- 神明全稱：不要只寫「土地公」，要寫「福德正神」
- 地理特徵：1句話客觀描述，例如「位於新店烘爐地山腰」
- 天氣：如實寫，可以是「悶熱」「小雨」「起霧」

---

#### 📝 2️⃣ 儀式流程參考【必填】

```
找到這個區塊：
【流程參考來源】
本次儀式流程與方式，請參考專案中的活動計劃書：
「_________________________________」

填入檔案名稱：
【流程參考來源】
本次儀式流程與方式，請參考專案中的活動計劃書：
「1140713-0714福德正神香供養流程稿.docx」
```

**填寫重點：**
- 寫完整的檔案名稱（含日期、神明、文件類型）
- 這樣AI可以在專案檔案中找到參考

---

#### 📝 3️⃣ 風格參考文案【必填】

```
找到這個區塊：
【同神明紀實】（必填）
網址或內容：_____________________

填入方式有兩種：

方式A：貼網址
【同神明紀實】（必填）
網址：https://www.facebook.com/xxxxx

方式B：貼完整內容
【同神明紀實】（必填）
內容：
「2024年6月23日，農曆五月廿八日。
清晨的竹林山還籠罩在薄霧中...（完整貼上）」
```

**填寫重點：**
- 至少提供2個參考文案（同神明+類似場景）
- 如果文章很長，可以只貼關鍵段落（開場+中段+結尾）
- 告訴AI要注意哪些特點（例如「注意土地公的親民語調」）

---

#### 📝 4️⃣ 本次觀察點【必填】

```
找到這個區塊：
【觀察點1】
_____________________

填入實際觀察：
【觀察點1】
插香時主持人手有點抖，可能是第一次在鏡頭前主持，
但每一炷香都插得很穩，沒有歪掉的。

【觀察點2】
誦讀文疏時，一位阿姨站在香案旁全程跟著合掌，
動作很慢很慢，每個姿勢都停留很久。

【觀察點3】
焚化文疏時突然飄起小雨，我們手忙腳亂拿傘護火，
最後文疏還是燒完了。
```

**填寫重點：**
- 用「我看到」「我注意到」的方式描述
- 記錄具體畫面，不要寫結論（不要寫「很感動」）
- 可以包含天氣變化、參與者反應、突發狀況
- 至少3個，最多5-6個

---

#### 📝 5️⃣ 神明微調參數【選填】

```
找到這個區塊：
本篇神明：_______________________

填入神明名稱：
本篇神明：福德正神

本篇特別限制（如有）：
避免「奇蹟轉運」「立刻見效」的寫法
```

**填寫重點：**
- 如果不確定，可以不填
- 如果過去AI常寫歪，可以在這裡特別提醒

---

#### 📝 1️⃣1️⃣ 輸出要求【必填】

```
找到這個區塊：
【主文】
字數：_____ 字
平台：_______

填入需求：
【主文】
字數：1200-1500字
平台：網站文章

【附加版本】
☑ Facebook短版：800字
☑ Instagram版：600字
□ LINE@版：不需要
```

**填寫重點：**
- 明確寫出字數範圍
- 勾選需要的版本

---

### 步驟4️⃣：複製整份模版

**重要：是複製「整份」，不是只複製你填的內容**

1. 全選整個文件（Ctrl+A 或 Command+A）
2. 複製（Ctrl+C 或 Command+C）
3. 準備貼給AI

---

### 步驟5️⃣：貼給AI

#### 如果使用 Claude.ai：

**方式A：在專案對話中**
1. 打開「香供養專題」專案
2. 開啟新對話
3. 直接貼上整份已填寫的模版
4. 按Enter送出

**方式B：一般對話**
1. 開啟新對話
2. 貼上整份模版
3. 可能需要額外上傳參考文件

#### 如果使用 ChatGPT：

1. 開啟新對話
2. 貼上整份模版
3. 如果有參考文件，需要額外上傳

---

### 步驟6️⃣：檢查AI輸出

AI產出文章後，用模版最後的「自我檢查」區塊驗證：

```
□ 1. 拿掉神明名字，文章還成立嗎？
□ 2. 這篇是在記錄「人」，還是在解釋「信仰」？
□ 3. 有沒有一句話，其實是在幫神明說話？
□ 4. 敘事段落是否出現編號／條列？
□ 5. 結尾會不會讓人想報名或了解更多？
```

**如果有任何一題不通過：**
- 複製問題段落
- 告訴AI：「第X題沒通過，請修正這段：（貼上問題段落）」

---

### 步驟7️⃣：微調與定稿

**常見需要微調的情況：**

| 問題 | 解決方式 |
|---|---|
| 太像報告，不像紀實 | 要求AI：「請改寫成第一人稱見證者角度，加入更多當下的感受和畫面」|
| 出現「觀察一」「1.」編號 | 要求AI：「請移除所有編號，改為自然敘事串接」|
| 結尾太像廣告 | 要求AI：「請重寫結尾，用畫面收束，不要總結或呼籲」|
| 替神明說話 | 指出具體句子：「這句『菩薩告訴我們』要刪除改寫」|
| 字數不符 | 要求AI：「請擴寫/精簡至XXX字」|

## 💡 實戰範例演示

### 完整範例：從零到完成

**情境：2024年11月6日，竹林山觀音寺觀音還願香供養**

#### 1️⃣ 準備階段（收集素材）

```
收集到的素材：
✓ 日期：2024/11/6（農曆十月初六）
✓ 地點：竹林山觀音寺
✓ 神明：南無大慈大悲觀世音菩薩
✓ 規模：32位供養者，31.25斤香品
✓ 天氣：早上有霧，後來放晴
✓ 流程文件：1141106-觀音還願香供養流程稿.docx
✓ 參考文案：找到兩篇過去的觀音紀實
✓ 觀察點：
  - 有位媽媽帶著小孩來還願
  - 主持人誦讀文疏時聲音有點哽咽
  - 香煙升起時剛好霧散了
```

#### 2️⃣ 填寫模版

```
打開模版檔案，逐一填寫：

【日期】
國曆：2024年11月6日
農曆：甲辰年十月初六日

【地點】
寺廟全名：新北市林口區竹林山觀音寺
地理特徵：位於林口山區，清晨常有霧氣籠罩

【主祀神明】
神明全稱：南無大慈大悲觀世音菩薩

【供養規模】
供養者數：32位
香品總重：31.25斤

【天氣】
實際天氣：清晨有薄霧，約九點半開始放晴

【流程參考來源】
「1141106-觀音還願香供養流程稿.docx」

【同神明紀實】（貼上完整內容或網址）
（貼上過去觀音香供養的紀實文章）

【類似場景】
（貼上另一篇晨間香供養的紀實）

【觀察點1】
一位年輕媽媽帶著大約三四歲的小男孩，
媽媽教孩子怎麼合掌，孩子學得很認真，
一雙小手努力併攏，一直看著媽媽確認自己有沒有做對。

【觀察點2】
主持人誦讀文疏時，唸到某位供養者為家人祈福的段落，
聲音突然有點哽咽，停頓了一下，深吸一口氣才繼續。

【觀察點3】
香煙剛開始升起時，霧還很濃，看不太清楚，
等到誦讀完文疏，霧突然散開了，陽光照進來，

【神明微調參數】
```

在Claude專案中開新對話，貼上整份已填寫的模版，送出。

（AI會根據模版產出文章）

#### 5️⃣ 檢查與修正

檢查5個問題，發現：

告訴AI：

改為描述香煙升起的畫面，不要詮釋神意。」

## ⚠️ 常見錯誤與解決

### 錯誤1：忘記填寫參考文案

**症狀：**
AI產出的文章風格很陌生，不像過去的寫法

**解決：**
一定要提供至少2篇參考文案，最好貼完整內容

---

### 錯誤2：觀察點寫得太抽象

**錯誤範例：**
```
【觀察點1】
現場很感動
```

**正確範例：**
```
【觀察點1】
一位阿姨在香案前站了很久，
眼眶有點紅，但沒哭出來，
只是一直看著香煙升起。
```

---

### 錯誤3：只複製填寫的部分

**錯誤做法：**
只複製你填的內容貼給AI

**正確做法：**
複製整份模版（包括所有說明、規則、檢查清單）

---

### 錯誤4：沒有檢查就直接使用

**風險：**
可能出現「替神明說話」「報告體」等問題

**正確做法：**
一定要用5個檢查問題驗證

## 🎓 進階使用技巧

### 技巧1：建立自己的參考文案庫

**做法：**
- 把每次產出的優質紀實文章存檔
- 依神明分類（觀音、土地公、財神...）
- 下次直接從庫中調用

### 技巧2：觀察點素材庫

**做法：**
- 活動中隨時用手機記錄觀察點
- 拍照記錄關鍵畫面
- 事後整理成文字描述

### 技巧3：連續對話優化

**做法：**
在同一個對話中持續優化，不要開新對話：
```
第一輪：「請開始寫作」（AI產出初稿）
第二輪：「請改寫結尾，太像廣告了」
第三輪：「請加強描寫香煙升起的畫面」
第四輪：「請產出800字Facebook版本」
```

### 技巧4：同時產出多個版本

**做法：**
在輸出要求中一次勾選多個：
```
【附加版本】
☑ Facebook短版：800字
☑ Instagram版：600字
☑ LINE@版：300字
```

AI會一次產出所有版本

## 🆘 疑難排解

### Q1：AI說找不到參考文件？

**A：** 
- 如果在Claude專案中，確認檔案已上傳到專案
- 或改成直接貼完整內容到模版中

### Q2：AI產出的文章還是很像報告？

**A：**
- 檢查參考文案是否提供夠
- 明確要求：「請改寫成第一人稱見證者視角，像是我親自在場記錄」

### Q3：需要多少參考文案才夠？

**A：**
- 最少2篇（同神明+類似場景）
- 建議3篇（同神明+類似場景+同寺廟）
- 如果文章很長，可以只貼關鍵段落

### Q4：可以修改模版內容嗎？

**A：**
- 可以！模版是給你自己用的
- 但建議保留核心規則（禁止清單、檢查問題）
- 可以調整神明參數、增加觀察點欄位

### Q5：每次都要重新填寫嗎？

**A：**
- 是的，每次活動都要重新填寫
- 但可以保留上次的模版，只修改變動的部分
- 建議每次填完後另存新檔，保留記錄
