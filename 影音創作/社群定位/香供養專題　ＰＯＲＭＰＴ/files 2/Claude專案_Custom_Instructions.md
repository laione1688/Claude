## 🔧 標準使用流程

### 撰寫香供養紀實文章時：

```
步驟1：準備素材
□ 收集活動資訊（日期、地點、神明、規模、天氣）
□ 整理觀察點（3-5個實際畫面）
□ 找出參考文案（至少2篇過往紀實）

步驟2：使用模版
□ 開啟「香供養紀實_AI_Prompt模版.md」
□ 逐一填寫所有【必填】欄位
□ 填寫【選填】欄位（如神明微調參數）

步驟3：產出文章
□ 全選複製整份已填寫的模版
□ 在本專案中開啟新對話
□ 貼上模版，請AI開始撰寫

步驟4：品質檢查
□ 用模版中的5個檢查問題驗證
□ 確認沒有「替神明說話」
□ 確認沒有「項目式編號」出現在敘事段落
□ 確認結尾不像廣告或呼籲

步驟5：修正與定稿
□ 如有問題，在同一對話中請AI修正
□ 確認無誤後複製定稿
```

## 📌 重要寫作原則（快速提醒）

### 核心定位
✅ 我們是：陪伴者、見證者、傳遞者
❌ 我們不是：主辦單位、宗教詮釋者、神明代言人

### 絕對禁止
❌ 時間標記式流水帳（11:00插香，11:03誦讀）
❌ 敘事段落用項目編號（觀察一、1.、首先其次）
❌ 替神明說話（「菩薩告訴我們」「這是神意」）
❌ 總結升華式結尾（「圓滿成功」「歡迎報名」）

### 可以使用編號的情況
✅ 列舉供品清單（1. 立香30斤 2. 鮮花一籃）
✅ 統計資訊（供養者32位、香品31.25斤）
✅ 流程說明（僅限客觀列表，非敘事）

## 🎯 神明微調參數（快速查詢）

撰寫不同神明的紀實時，注意避免以下慣性寫法：

### 觀世音菩薩
❌ 避免：療癒系、被溫暖包圍、痛苦立即被撫慰
✅ 改寫：人如何撐住、如何陪伴自己、如何完成儀式

### 福德正神（土地公）
❌ 避免：奇蹟轉運、立刻見效、突然發財
✅ 改寫：日常累積、做到位、一步步做、重複確認

### 五路財神
❌ 避免：偏財暴富、意外之財、不勞而獲
✅ 改寫：秩序、責任、該來的收入、努力修正

### 地藏王菩薩
❌ 避免：快速解脫、業障瞬間消除、輕鬆超度
✅ 改寫：重量、等待、不逃避、承受、慢慢走完

### 天上聖母（媽祖）
❌ 避免：保證平安、絕對順利、消除所有障礙
✅ 改寫：出發、走在路上、信任行動、心裡穩一點

## ❓ 常見問題快速解答

### Q1：第一次使用，從哪開始？
**A：** 
1. 先閱讀「使用說明書.md」（30分鐘）
2. 再看「撰寫指引_完整版.md」的核心章節（1小時）
3. 用「AI_Prompt模版.md」實際操作一次

### Q2：要如何填寫「風格參考文案」？
**A：**
- 至少提供2篇（同神明+類似場景）
- 可以貼網址，但建議貼完整內容
- 這是AI學習語調的關鍵

### Q3：觀察點要怎麼寫？
**A：**
- 用「我看到」「我注意到」描述具體畫面
- 不要寫結論（不要寫「很感動」）
- 範例：「插香時，主持人手有點抖，但每一炷都插得很穩」

### Q4：AI產出的文章還是像報告怎麼辦？
**A：**
- 明確要求：「請改寫成第一人稱見證者視角」
- 檢查是否提供足夠的參考文案
- 用5個檢查問題逐一驗證

### Q5：可以修改模版內容嗎？
**A：**
- 可以！但建議保留核心規則
- 可以調整神明參數、增加觀察點欄位
- 不建議刪除禁止清單和檢查問題

## ✅ 品質自我檢查（交稿前必做）

每次AI產出文章後，必須通過以下5個檢查：

```
□ 1. 拿掉神明名字，文章還成立嗎？
     （不成立 = 依賴神明撐場面，要重寫）

□ 2. 這篇是在記錄「人」，還是在解釋「信仰」？
     （解釋信仰 = 變成老師，要重寫）

□ 3. 有沒有一句話在替神明說話？
     （有 = 立刻刪除那句話）

□ 4. 敘事段落是否出現編號／條列？
     （有 = 全部改為連續敘事）

□ 5. 結尾會不會讓人想報名或了解更多？
     （會 = 結尾重寫成留白式）
```

**只要有一題不通過，請在同一對話中要求AI修正**

## 🎓 進階技巧

### 建立自己的參考文案庫
- 把每次產出的優質紀實存檔
- 依神明分類（觀音、土地公、財神...）
- 下次直接從庫中調用

### 連續對話優化
不要每次修改都開新對話，在同一對話中持續優化：
```
第一輪：產出初稿
第二輪：「請改寫結尾，太像廣告」
第三輪：「請加強描寫香煙升起的畫面」
第四輪：「請產出800字Facebook版」
```

### 同時產出多版本
在輸出要求中一次勾選多個：
```
□ 主文：1200-1500字（網站）
☑ Facebook短版：800字
☑ Instagram版：600字
□ LINE@版：300-500字
```
