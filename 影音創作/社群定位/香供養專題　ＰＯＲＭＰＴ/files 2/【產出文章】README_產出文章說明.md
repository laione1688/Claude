# 📝 產出文章資料夾使用說明

## 🎯 這個資料夾的用途

此資料夾用於存放「已產出的香供養紀實文章」，包含不同平台的各種版本。

---

## 📁 建議的整理方式

### 方案A：依時間分類

```
4_產出文章/
├── 2024年/
│   ├── 01月/
│   ├── 02月/
│   ├── 06月-觀音/
│   │   ├── 0623_竹林山觀音_網站版.md
│   │   ├── 0623_竹林山觀音_FB版.md
│   │   └── 0623_竹林山觀音_IG版.md
│   ├── 07月-土地公/
│   └── 11月-觀音/
└── 2025年/
```

### 方案B：依神明分類

```
4_產出文章/
├── 觀音紀實/
│   ├── 2024/
│   │   ├── 0623_竹林山/
│   │   └── 1106_竹林山還願/
│   └── 2025/
├── 土地公紀實/

```

### 方案C：平面命名（簡單）

```
4_產出文章/
├── 20240623_觀音_竹林山_網站版.md
├── 20240623_觀音_竹林山_FB版.md
├── 20240623_觀音_竹林山_IG版.md
├── 20240714_土地公_烘爐地_網站版.md
└── ...
```

**建議：剛開始用方案C，文章多了再改用方案A或B**

---

## 📋 檔案命名規則

### 標準格式

```
YYYYMMDD_神明_地點_平台版本.md

範例：
✓ 20240623_觀音_竹林山_網站版.md
✓ 20240623_觀音_竹林山_FB短版800字.md
✓ 20240714_土地公_烘爐地_IG版600字.md
```

### 命名要點

- **日期**：用8位數字（YYYYMMDD）方便排序
- **神明**：用簡稱（觀音、土地公、財神）
- **地點**：寺廟簡稱（竹林山、烘爐地）
- **版本**：平台+字數（網站版、FB版800字）

---

## 📱 不同平台版本說明

### 網站版（主文）

```
字數：1200-1500字
格式：完整紀實，含所有細節
用途：官網、部落格發布
特點：最完整的版本
```

### Facebook版

```
字數：800-1000字
格式：精簡版，保留核心畫面
用途：FB貼文
特點：適合社群閱讀，配合圖片
```

### Instagram版

```
字數：600-800字
格式：更精簡，前3行要吸引人
用途：IG貼文或限時動態
特點：快速閱讀，視覺導向
```

### LINE@版

```
字數：300-500字
格式：重點摘要
用途：LINE訊息推播
特點：訊息通知用，引導到完整版
```

## ✅ 如何管理產出文章

### 每次產出後

1. **存檔所有版本**
   ```
   □ 網站主文版
   □ FB版（如有）
   □ IG版（如有）
   □ LINE@版（如有）
   ```

2. **加上元資料（可選）**
   - 在檔案開頭註明：
   - 產出日期
   - 實際活動日期
   - 使用的參考文案
   - 特殊修改記錄

3. **評估品質**
   - 如果品質很好，複製一份到「參考文案庫」

## 🎯 與參考文案庫的關係

### 區別

```
產出文章：所有產出都存
參考文案庫：只存優質的

產出文章 → 評估品質 → 優質的 → 複製到參考文案庫
```

### 流程

```
1. 產出紀實文章
2. 存到「產出文章」資料夾
3. 發布並收集反饋
4. 如果品質好、反應佳
5. 複製到「參考文案庫」供未來參考
```

## ⚠️ 注意事項

### 備份

- 定期備份所有文章
- 可以上傳雲端（Google Drive、Dropbox）
- 避免遺失重要內容

### 隱私

- 如文章中有供養者真實姓名，注意保護隱私
- 發布前檢查敏感資訊

### 版本管理

- 如果文章有修改，建議保留版本記錄
- 例如：檔名_v1.md、檔名_v2.md

## 💡 實際使用範例


```
1. 找到對應檔案

3. 調整日期或部分內容
4. 另存新版本
```
