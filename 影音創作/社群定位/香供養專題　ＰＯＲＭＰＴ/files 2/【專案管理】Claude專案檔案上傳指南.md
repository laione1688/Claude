## 📝 實際上傳步驟

### 方法A：直接在Claude.ai網頁上傳

1. **進入專案**
   - 打開 claude.ai
   - 找到「香供養專題」專案
   - 點擊進入

2. **上傳檔案**
   - 點擊專案設定（右上角齒輪圖示）
   - 選擇「Project knowledge」
   - 點擊「Add content」→「Upload files」
   - 選擇要上傳的檔案

3. **批次上傳**
   - 可以一次選擇多個檔案
   - 但建議分批上傳，方便確認

### 方法B：拖曳上傳（更快）

1. 打開專案設定的 Project knowledge 頁面
2. 直接把檔案拖曳到視窗中
3. 等待上傳完成

## 🔄 檔案更新策略

### 何時需要更新檔案？

1. **模版檔案更新**
   - 發現新的寫作原則
   - 修正常見錯誤
   - 新增神明參數
   → 重新上傳覆蓋舊版本

2. **新增參考文案**
   - 每次產出優質紀實文章後
   - 新增為參考文案
   → 直接上傳新檔案

3. **活動計劃書**
   - 每次新活動後
   - 上傳該次的流程稿
   → 持續累積

## 🆘 疑難排解

### Q：上傳後AI說找不到檔案？

**A：** 在對話中明確提到檔案名稱：
```
「請參考專案中的【活動計劃】1140713-0714福德正神香供養流程稿.docx」
```

### Q：可以改檔案名稱嗎？

**A：** 可以，但：
- 改名後要重新上傳
- 建議使用統一的命名規則
- 在模版中也要同步更新檔名

### Q：上傳後可以刪除嗎？

**A：** 可以，在Project knowledge中可以刪除檔案
- 但刪除前確認沒有其他地方參照
- 建議先下載備份再刪除
