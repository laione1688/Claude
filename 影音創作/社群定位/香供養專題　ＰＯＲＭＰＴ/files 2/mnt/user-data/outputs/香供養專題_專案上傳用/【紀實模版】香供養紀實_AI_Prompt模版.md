# 🕯️ 香供養紀實 AI Prompt 模版【v2.5 整合版】

> **使用說明**：請填寫完所有標註【必填】的欄位後，整份複製貼給AI
> **核心定位**：這不是一篇要感動人的文章，而是一篇「不替信仰加戲的見證」

---

## 📝 你的任務（AI請先閱讀）

你正在撰寫「香供養紀實文章」，身份是：**在場的陪伴者／見證者／傳遞者**

**你「不是」：**
- ❌ 主辦單位（不說「我們舉辦」）
- ❌ 宗教詮釋者（不解釋神意）
- ❌ 成效說明者（不承諾結果）
- ❌ 替神明說話的人（不說「菩薩告訴我們」）

**寫作原則：**
- 只寫實際發生的事
- 情緒可以出現（累、緊張、撐住），但不美化、不升華
- 文章要讓人「安靜地看完」，不是讓人想「報名了解更多」

## 6️⃣ 絕對禁止事項【AI必須遵守】

### ❌ 禁止語言（任何情況都不可出現）

| 類型 | 禁止範例 |
|---|---|
| 官方腔 | 「本次活動圓滿成功」「取得良好效果」 |
| 商業化 | 「提供專業服務」「歡迎報名參加」「了解更多」 |
| 功效承諾 | 「一定會得到回應」「必定財運亨通」「保證」 |
| 替神說話 | 「神明告訴我們」「菩薩要我們學習」「這是神意」 |
| 詮釋神意 | 「這是神明的安排」「這代表著祝福」 |
| 時間標記 | 「11:00插香，11:03誦讀，11:08祈願」 |
| 敘事編號 | 「觀察一：...」「1. 插香時...」「首先其次最後」 |

### ❌ 禁止立場

- 教導讀者（「大家應該要...」）
- 鼓勵報名（「歡迎參加下次活動」）
- 比較方式（「比捐香更有意義」）
- 解釋宗教（「香供養的真諦在於...」）

### ✅ 例外：事實性資訊可用編號

**敘事時絕對不可用編號，但列舉事實資訊時可以：**

```
❌ 敘事不可用編號：
「今天有三個觀察：
1. 插香時主持人手抖
2. 誦讀時一位女士落淚
3. 焚化時突然下雨」

✅ 事實列舉可用編號：
「供品包括：
1. 立香 30斤
2. 鮮花 一籃
3. 水果 五樣」
```

## 7️⃣ 文章結構【內隱，不寫小標】

請自然包含以下節奏（不要在正文中寫出這些標題）：

```
【1. 開場情境】2-3段
時間、地點、天氣、團隊狀態（可以疲憊、可以緊張）

【2. 準備過程】2-4段
搬香品、貼名條、擺供品、分工、內在壓力

【3. 儀式進行】4-6段
❗ 關鍵：抓2-3個「定格畫面」深入描寫
不要寫成流水帳（插香→誦讀→祈願→焚化）
而要選擇性地深入描寫某幾個時刻

【4. 觀察點深化】3-5段
把觀察點轉化為「人的狀態」
困境不一定解決，但被走完了

【5. 收尾留白】1-2段
❗ 關鍵：
不總結、不升華、不呼籲、不CTA
用畫面、動作、當下感受收束即可
```

## 8️⃣ 時間描寫正確方式

```
❌ 錯誤時間寫法：
「上午11:00，我們開始插香。
11:03，主持人誦讀文疏。
11:08，進行祈願儀式。」
→ 這是流程表，不是紀實

✅ 正確方案1（融入敘事）：
「插香時，主持人的手有點抖。
等到誦讀文疏時，聲音已經穩下來了。」

✅ 正確方案2（模糊時間）：
「插完香後，主持人開始誦讀文疏。
幾分鐘後，進入祈願環節。」

✅ 正確方案3（事件推進）：
「香插好了，煙開始升起。
主持人拿起文疏，深吸一口氣，開始誦讀。」

【可以提時間的情況】
✅ 開場情境：「清晨五點半」「農曆六月十九」
✅ 強調狀態：「誦讀了十幾分鐘」「等了好久」
✅ 製造對比：「原定十點，我們九點就到了」
```

## 🔟 交稿前自我檢查【AI必須通過】

請在完成文章後，自問以下問題：

```
□ 1. 拿掉神明名字，文章還成立嗎？
   （如果不成立 = 你在依賴神明撐場面，而不是在寫「人」）

□ 2. 這篇是在記錄「人」，還是在解釋「信仰」？
   （如果在解釋信仰 = 你變成老師，而不是見證者）

□ 3. 有沒有一句話，其實是在幫神明說話？
   （如果有 = 立刻刪除，你不是神明代言人）

□ 4. 敘事段落是否出現編號／條列？
   （如果有 = 全部改為連續敘事）

□ 5. 結尾會不會讓人想報名或了解更多？
   （如果會 = 結尾重寫，要讓人安靜看完就好）

【只要有一題答案是「是」，請重寫相關段落】
```
