# 📚 參考文案庫使用說明

## 🎯 這個資料夾的用途

此資料夾用於存放「過往優質的香供養紀實文章」，作為未來撰寫新紀實時的風格參考。

---

## 📁 資料夾結構

```
2_參考文案庫/
├── 觀音紀實/        - 觀世音菩薩相關紀實
├── 土地公紀實/      - 福德正神相關紀實  
├── 財神紀實/        - 五路財神相關紀實
└── 其他神明/        - 其他神明（可自行新增）
```

---

## 📝 如何使用參考文案

### 撰寫新紀實時

1. **找出同神明的過往紀實**
   - 例如要寫觀音紀實，就到「觀音紀實/」資料夾找

2. **挑選2-3篇參考文案**
   - 最好是近期的、品質好的
   - 至少要有「同神明」的紀實

3. **在AI Prompt模版中填入**
   - 可以貼網址（如果有發布連結）
   - 或直接貼完整內容

---

## 📋 檔案命名規則

建議使用以下格式：

```
[神明]_YYYYMMDD_寺廟_簡述.md

範例：
- [觀音]_20240623_竹林山_香供養紀實.md
- [土地公]_20240714_烘爐地_香供養紀實.md
- [財神]_20240815_金山_五路財神香供養.md
```

---

## ✅ 如何新增參考文案

### 當產出一篇優質紀實後：

1. **評估品質**
   ```
   □ 通過5個檢查問題
   □ 符合品牌語調
   □ 沒有常見錯誤
   □ 用戶滿意
   ```

2. **存入對應資料夾**
   - 依神明分類
   - 使用標準命名格式
   - 可以加上註解（這篇的特色）

3. **建立索引（選做）**
   - 在資料夾中建立README.md
   - 列出所有文案和特色

## 🎯 參考文案的價值

### 為什麼需要參考文案？

**指引提供「原則」，參考文案提供「語感」**

```
指引告訴你：
❌ 不能替神明說話
❌ 不能用時間標記
❌ 不能在敘事中用編號

參考文案告訴你：
✅ 具體怎麼寫開場
✅ 具體怎麼描述畫面
✅ 具體怎麼處理節奏
✅ 具體怎麼收尾
```

### 三種神明的語調差異

| 特質 | 觀音紀實 | 土地公紀實 | 財神紀實 |
|---|---|---|---|
| **核心感受** | 被溫柔包容 | 被考驗中成長 | 被具體回應 |
| **層面** | 心靈 | 生活 | 財運 |
| **神蹟呈現** | 雨停的溫柔 | 大晴天的直接 | 還願的見證 |
| **語調** | 柔和、細膩 | 接地氣、直接 | 明快、清晰 |
| **觀察點** | 情感流動 | 實際挑戰 | 具體效果 |

**使用建議：**
- 寫觀音紀實時，學習溫柔細膩的情感描寫
- 寫土地公紀實時，學習接地氣的實在表達
- 寫財神紀實時，學習明確直接的敘事方式

## 💡 實際使用範例

### 場景：要寫新的觀音紀實

```
步驟1：打開「觀音紀實/」資料夾
步驟2：找到2篇過往紀實
步驟3：複製內容
步驟4：在AI Prompt模版的「風格參考文案」欄位貼上
步驟5：AI就會學習這些文案的語調和節奏
```

## ⚠️ 注意事項

1. **不要存放草稿或未定稿**
   - 只存放最終版、已發布的版本

2. **保持更新**
   - 新的優質紀實要記得存檔
   - 舊的過時紀實要定期清理

3. **標註特色**
   - 可以在檔名或內容中註明特色
   - 例如「情感描寫細膩」「畫面感強」

4. **尊重版權**
   - 只存放自己產出的內容
   - 不要存放他人的文章
