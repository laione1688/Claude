# 📝 產出文章資料夾

此資料夾用於存放 AI 產出的紀實文章成品，按神明和平台分類。

## 💡 命名規則

**格式：**
```
YYYY-MM-DD_地點神明_平台版本.md
```

**範例：**
- `2024-11-06_竹林山觀音還願_網站版.md`
- `2024-11-06_竹林山觀音還願_FB版.md`
- `2024-11-06_竹林山觀音還願_IG版.md`

---

## 🔄 與「參考文案庫」的差異

### 📚 參考文案庫（2_參考文案庫）
- **用途：** 給 AI 學習的優質範例
- **精選：** 只放最好的、最有代表性的
- **數量：** 每種神明 2-3 篇即可
- **命名：** `[神明]_YYYYMMDD_地點_期數.md`

### 📝 產出文章（4_產出文章）
- **用途：** 實際發布的文章存檔
- **完整：** 所有產出的版本都存
- **數量：** 累積增長，完整記錄
- **命名：** `YYYY-MM-DD_地點神明_平台.md`

---

## 📌 使用建議

### 產出文章後

1. **存檔**
   - 將 AI 產出的文章存到此資料夾
   - 按神明分類
   - 依平台分別存檔

2. **評估**
   - 發布後觀察效果
   - 好的文章可以考慮加入「參考文案庫」

3. **備份**
   - 定期備份此資料夾
   - 建立版本記錄

---
