# 《AI 協作快速指南》

## 🚀 給團隊成員的快速上手說明

- 第一次使用 AI 協助香供養專案內容

6. `香供養專案_對外內容_AI標準System_Prompt_v1_0.md`

**選擇性上傳：**
- `Video_Lab_腳本母模板_v1_0.md`（若需要結構參考）

---

### 給 AI 的標準提示語

```
我需要製作一支 [15/30/60] 秒的短影音腳本，主題是「[主題]」。

請依照以下步驟：
1. 確認符合品牌核心立場（brand_core.md）
2. 確認概念定義正確（拜拜×信仰×香供養內部共識）
3. 避免使用黑名單用語
4. 套用溫暖、不說教的語氣（tone_reference.md）
5. 使用 Video Lab 五段式結構
6. 通過最終檢核（AI標準System Prompt）

目標受眾：[新手/已有信仰/已參與供養]
平台：[IG/TikTok/YouTube/FB]
```

---

### 輸出檢核清單

產出後，確認以下項目：

**結構檢查：**
- [ ] 包含開場鉤子（0-3秒）
- [ ] 包含破除錯誤理解（3-10秒）
- [ ] 包含正確定義（10-30秒）
- [ ] 包含情緒回收（30-45秒）
- [ ] 包含延伸連結（45-60秒）

**立場檢查：**
- [ ] 回到心念為本
- [ ] 無保證結果
- [ ] 無交易暗示
- [ ] 保留人生主體性
- [ ] 無製造焦慮

**語氣檢查：**
- [ ] 溫暖不說教
- [ ] 無命令式語氣
- [ ] 無黑名單用語
- [ ] 符合陪伴者角色

**技術檢查：**
- [ ] 無民俗禁忌畫面
- [ ] 句子短、易朗讀
- [ ] 適合字幕拆行

## 🚨 當 AI 輸出有問題時

### 常見問題快速診斷

**問題1：語氣太說教**
→ 重新提示：「請改為陪伴式、邀請式語氣，參考 tone_reference.md」

**問題2：暗示保證結果**
→ 重新提示：「請移除任何結果承諾或暗示，只描述實際作為」

**問題3：出現黑名單用語**
→ 重新提示：「請檢視影音內容用語黑名單，移除禁止用語」

**問題4：不符合使用情境**
→ 重新提示：「這是[情境]，請參考對外內容目的與使用情境表調整」

**問題5：AI 自行補充超出範圍的內容**
→ 重新提示：「請只根據上傳文件的內容，不要自行補充未經確認的概念」

## 🎯 最後提醒

### 三個核心原則（永遠記住）

1. **心念為本** - 所有內容回到這個核心
2. **不保證結果** - 永遠不承諾靈驗或改命
3. **陪伴不說教** - 溫暖但克制的語氣

### 三個禁止事項（絕對不可）

1. ❌ 不製造焦慮或恐懼
2. ❌ 不把人生外包給神明
3. ❌ 不使用交易式語言

### 遇到不確定時

**停止 → 檢查 → 詢問**

不要猜測、不要合理化、不要自行補完。
