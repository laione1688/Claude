# 明心福旺閣｜神明系列專案總覽

## 專案目的
為明心福旺閣（香供養服務品牌）建立完整的社群內容系統，
透過佛教菩薩與道教神明兩套系列，
幫助溫柔的人建立不會傷害自己的信仰理解方式。

## 核心定位
替溫柔的人，建立一套不會把信仰變成第二個壓力源的系統。

## 兩套系列差異

### 佛教菩薩系列
- **重點：** 心性、覺察、修行
- **適合問題：** 我為什麼會這樣累？
- **定位：** 整理心念
- **核心邏輯：** 特質類比（你像菩薩）

### 道教神明系列
- **重點：** 職責、位置、分工
- **適合問題：** 我現在卡在哪一關？
- **定位：** 站回人生位置
- **核心邏輯：** 角色錯位（你扛了不該扛的）
