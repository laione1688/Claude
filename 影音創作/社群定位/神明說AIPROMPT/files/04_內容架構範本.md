# 內容架構範本

## 🏗️ 三種靈活架構詳解

根據痛點類型和內容目標，選擇最適合的架構。

---

## 架構 A：哲理深省型

### 適用場景
- 痛點：失控感、執著感
- 目標：引發深度思考、價值觀共鳴
- 特色：金句密集、節奏感強、適合轉發

### 結構圖
```
【標題】從 XX 的「象徵」看...
    ↓
【開場金句】點題（1-2 行）
    ↓
【痛點描述】具體場景（2-3 行）
    ↓
【神明象徵】重新定義（3-4 行）
    ↓
【🔸列點】3 個洞見強化
    ↓
【反問句】製造對話感
    ↓
【核心金句】可傳播的洞見
    ↓
【收尾】帶出希望與轉念
    ↓
【標註】💭 這是我們從「XX 信仰象徵」中讀到的啟發
```

### 完整範例：城隍爺（失控感）

```
《從城隍爺的「因果」象徵，看見覺醒的時刻》

有些報應，不在地獄，而在人心
當你夜不能寐、心有愧意的那一刻
審判已經開始

在台灣民間信仰中
城隍爺被視為善惡審判、因果分明的象徵
這個「因果」的文化意涵提醒我們：
每一個選擇，都會回到自己身上

城隍爺不是恐懼的象徵
而是提醒我們學會覺察

🔸 有些人再次出現，不是偶然，是未完的功課
🔸 有些痛苦重演，不是命運懲罰，而是靈魂修正
🔸 有些別離，是還債，也是解脫

你問：「為什麼老天不幫我？」

其實，神明早在幫你
只是用「現實」的樣子提醒你
讓你看見自己的選擇

因果不是報應，是覺醒
當你懂了，就自由了

💭 這是我們從「城隍爺因果與覺醒」的信仰象徵中
   讀到的啟發
```

### 關鍵技巧
1. **開場要有畫面感**：「當你夜不能寐...」
2. **🔸列點要對仗**：結構相似，節奏一致
3. **反問要打到痛點**：「為什麼老天不幫我？」
4. **金句要可獨立傳播**：「因果不是報應，是覺醒」

## 架構 B：主題教學型

### 適用場景
- 痛點：孤獨感、關係議題、需要具體方法
- 目標：提供實用建議、深度教學
- 特色：分段清晰、循序漸進、適合收藏

### 結構圖
```
【標題】從 XX 的「象徵」學習...
    ↓
【開場】為什麼需要這個主題（3-4 行）
    ↓
【主題 1】
  - 小標題
  - 概念解釋
  - 具體案例或場景
  - 金句收尾
    ↓
【主題 2】
  - 小標題
  - 概念解釋
  - 具體案例或場景
  - 金句收尾
    ↓
【主題 3】
  - 小標題
  - 概念解釋
  - 具體案例或場景
  - 金句收尾
    ↓
【主題 4】（選配）
  - 小標題
  - 概念解釋
  - 具體案例或場景
  - 金句收尾
    ↓
【總結】整合 + 行動引導
    ↓
【標註】💭 這是我們從「XX 信仰象徵」中讀到的啟發
```

### 完整範例：觀音（孤獨感）

```
《從觀音的「慈悲」象徵，學習人際關係的智慧》

在台灣民間信仰中
觀音菩薩被視為慈悲的化身、救苦救難
這個「慈悲」的象徵讓我們思考：
真正的力量，來自柔軟而非強硬

當你越成長
越會發現「好的人際關係」不是靠討好來的
而是靠理解、界線與真誠的溫柔

---

學會「看見」他人
善意的眼光，是一種修行

有時我們並非不懂愛
而是太急著批判

從觀音的慈悲視角來看：
看見對方的努力
看見他還願意學習、改變的心
這份「看見」，就是愛的起點

---

學會「傾聽」
不是沉默，真正的聽是放下自己的聲音

當你願意停下來聽
你會發現對方只是想被理解、被接納

試著用心聽，不急著反應
讓人際間的能量回歸平和

---

學會「柔軟」
不是退讓，柔軟是強者的選擇

從慈悲的文化意涵理解：
柔軟不是委屈
而是選擇不讓恨長大

當你願意放下對錯，選擇圓融
你其實是在成就更深的力量

退一步會贏得更多尊重與和諧

---

學會「自愛」
才能愛人，關係的平衡從自我疼惜開始

你不是一直要給的那個人
當你懂得回到自己、滋養自己
你會發現人際也開始回應你溫柔的能量

你太習慣照顧別人，卻忘了照顧自己
當你開始為自己設定界線
關係會變得更真實也更穩定

---

✨ 從今天開始
練習用「感謝的眼」去看世界
會發現更多溫暖的連結
試著用心聽，不急著反應

💭 這是我們從「觀音慈悲與柔軟」的信仰象徵中
   讀到的啟發
```

### 關鍵技巧
1. **每個主題都要獨立完整**：可以單獨拿出來傳播
2. **用「學會」開頭統一**：製造節奏感
3. **概念要具體化**：不只說「要柔軟」，要解釋「柔軟是什麼」
4. **加入真實感場景**：「你太習慣照顧別人...」

## 架構 C：痛點解方型

### 適用場景
- 痛點：焦慮感、迷茫感
- 目標：破除迷思、提供新思維
- 特色：對比強烈、邏輯清晰、實用性強

### 結構圖
```
【標題】從 XX 的「象徵」理解...
    ↓
【痛點開場】具體場景描述（3-4 行）
    ↓
【錯誤思維 1】+ 為什麼會這樣想
    ↓
【正確理解 1】+ 神明智慧提醒
    ↓
【錯誤思維 2】+ 為什麼會這樣想
    ↓
【正確理解 2】+ 神明智慧提醒
    ↓
【錯誤思維 3】+ 為什麼會這樣想
    ↓
【正確理解 3】+ 神明智慧提醒
    ↓
【案例故事】真實感案例增加說服力
    ↓
【收尾轉念】+ 核心金句
    ↓
【標註】💭 這是我們從「XX 信仰象徵」中讀到的啟發
```

### 完整範例：五路財神（焦慮感 + 迷茫感）

```
《從五路財神的「通路」象徵，找到你的致富方向》

可能比別人更努力
但財運為什麼總跟不上？

在台灣民間信仰中
五路財神被視為財富通路、能量流動的象徵
這個「通路」的文化意涵提醒我們：
每個人的致富路徑都不一樣

原因不是你不夠努力
而是你的能量方向還沒對上你的財路

---

❌ 錯誤思維：比較別人的財運

「為什麼他很有錢，我就沒有？」
這種想法只會浪費能量

從五路財神的象徵來看：
別人的致富路可能是投資、創業、貴人相助
你的方式可能完全不同
焦慮只會消耗能量

✅ 正確理解：向內求，找到屬於你的方式

財神不喜歡盲目模仿
停止比較，財神才會靠近

---

❌ 錯誤思維：盲目努力就會有錢

很多人以為只要夠努力就會成功
但如果方向錯了，越努力越遠

從「通路」的意涵來看：
一套賺錢公式，不適用每個人
結局肯定完全不同

✅ 正確理解：先認識自己，財神才會認識你

財運與你的個性、能量有關
你是創意型、守財型、行動型還是貴人型？
不同特質對應不同的致富方法

了解自己，財神才會知道怎麼幫助你

---

❌ 錯誤思維：努力就夠了

很多人只知道埋頭苦幹
卻忘了停下來看方向對不對

✅ 正確理解：調整思維，比努力更重要

能量對了，財路自然暢通
停止抱怨、停止焦慮
把心力放在適合自己的財路上

你會發現
財富慢慢從意想不到的方向湧來
努力是標配，用對方法才是致富的密碼

---

有個朋友一直很努力工作
但總覺得賺不到錢

直到有天他停下來問自己：
「我到底是什麼類型的人？」

他發現自己其實是貴人型
不適合單打獨鬥
當他開始經營人脈、建立連結
財運就慢慢打開了

---

✨ 今天起，問自己：
我是什麼類型的人？
我的能量方向對了嗎？

找到屬於你的方式
財神才會靠近

💭 這是我們從「五路財神通路與方向」的信仰象徵中
   讀到的啟發
```

### 關鍵技巧
1. **用 ❌ ✅ 製造視覺對比**：一看就懂
2. **錯誤思維要具體**：不只說「錯了」，要說「為什麼錯」
3. **正確理解要有洞見**：打破慣性思維
4. **案例要真實感**：「有個朋友...」

## 🎯 架構選擇快速指南

| 痛點類型 | 推薦架構 | 理由 |
|---------|---------|------|
| 失控感 | 架構 A | 需要金句震撼，引發覺醒 |
| 焦慮感 | 架構 C | 需要破除迷思，提供方向 |
| 執著感 | 架構 A | 需要哲理深度，情感共鳴 |
| 孤獨感 | 架構 B | 需要具體方法，實用建議 |
| 迷茫感 | 架構 C | 需要清晰邏輯，找到方向 |

## 💡 架構混搭技巧

不一定要完全遵守某個架構，可以靈活組合：

### 混搭範例 1：A + B
```
開場用架構 A 的金句點題
中間用架構 B 的主題分段
結尾用架構 A 的哲理收尾
```

### 混搭範例 2：C + 故事
```
開場用架構 C 的痛點描述
中間穿插多個真實故事
結尾用對比式的認知重構
```

### 混搭範例 3：B 簡化版
```
只用 2-3 個主題（而非 4 個）
每個主題更精簡（3-4 行）
適合快速閱讀的限時動態
```

## ✅ 架構品質檢查表

無論選擇哪種架構，都要確認：

- [ ] 開場 5 秒內抓住注意力
- [ ] 神明象徵有明確說明
- [ ] 至少有 2-3 個可獨立傳播的金句
- [ ] 每段 3-5 行，節奏流暢
- [ ] 有情感共鳴點（讓人點頭）
- [ ] 有認知重構點（讓人驚訝）
- [ ] 收尾帶出希望或行動
- [ ] 結尾有來源標註
