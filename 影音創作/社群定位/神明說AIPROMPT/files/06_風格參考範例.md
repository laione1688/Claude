# 風格參考範例

## 📖 實際範例分析

## 範例 1：城隍爺（哲理深省型）

### 完整內容

```
《城隍爺的告誡》

有些報應，不在地獄，而在人心
當你夜不能寐、心有愧意的那一刻
審判已經開始

城隍爺不是恐懼的象徵
而是提醒我們
「每一個選擇，都會回到自己身上。」

🔸 有些人再次出現，不是偶然，是未完的功課
🔸 有些痛苦重演，不是命運懲罰，而是靈魂修正
🔸 有些別離，是還債，也是解脫

你問：「為什麼老天不幫我?」
其實，神明早在幫你，只是用「現實」的樣子提醒你

因果不是報應，是覺醒
懂了，就自由了
```

### 架構分析

| 模組 | 內容 |
|------|------|
| 開場金句 | 有些報應，不在地獄，而在人心 |
| 痛點場景 | 當你夜不能寐、心有愧意的那一刻 |
| 神明重新定義 | 城隍爺不是恐懼的象徵，而是提醒... |
| 🔸列點 | 3 個並列洞見 |
| 反問對話 | 你問：為什麼老天不幫我？ |
| 核心金句 | 因果不是報應，是覺醒 |
| 收尾 | 懂了，就自由了 |

### 風格特色

✅ **節奏感強**
- 每段 2-4 行
- 短句為主
- 有呼吸感

✅ **金句密集**
- 「有些報應，不在地獄，而在人心」
- 「因果不是報應，是覺醒」
- 「懂了，就自由了」

✅ **對話感**
- 用「你問」製造互動
- 預測讀者疑問

✅ **視覺化**
- 🔸列點製造停頓
- 分段清晰

### 適用痛點
失控感（覺得被命運擺佈）

### 分享動機
自我投射、價值認同

## 範例 2：福德正神（主題教學型）

### 完整內容

```
福德正神說：
那些錢不會教你的道理

財氣來之前，先學會安靜 
急的人，錢不會靠近

有個每天拜財神，求中樂透卻從沒中過
直到有天他靜下心、開始專注做自己擅長的事
客戶就都主動找上門了

財氣喜靜不喜亂，你越焦慮，福氣越走遠

---

感恩的嘴，最會招財
說「謝謝」是最強的開運法

一位攤販阿姨，每收一張鈔票都笑著說
「謝謝喔～福報給你一半」
結果她的生意永遠是最旺的那一攤

福德正神說：「感恩的心，最容易生出福氣。」

---

有德，錢才留得住
別比別人賺多少，先看自己守得住多少

有個人努力工作卻老覺得錢不夠用
後來他發現自己常抱怨、常算計
當他改變態度願意幫助別人
財運真的開始穩起來

福德正神：財若無德聚也散 德若有根貧也安

---

捨得，才有得
越懂得分享的人，越容易發財

一位老闆，每次賺錢都會拿部分做公益
有人問他為什麼？
他說：「我是在換能量，不是損失。」

福德正神說：錢是福的僕人，不是主人
```

### 架構分析

| 結構 | 內容 |
|------|------|
| 主題 1 | 財氣來之前，先學會安靜 |
| 故事 1 | 拜財神的人 |
| 金句 1 | 財氣喜靜不喜亂 |
| 主題 2 | 感恩的嘴，最會招財 |
| 故事 2 | 攤販阿姨 |
| 金句 2 | 感恩的心，最容易生出福氣 |
| 主題 3 | 有德，錢才留得住 |
| 故事 3 | 努力工作的人 |
| 金句 3 | 財若無德聚也散 |
| 主題 4 | 捨得，才有得 |
| 故事 4 | 做公益的老闆 |
| 金句 4 | 錢是福的僕人 |

### 風格特色

✅ **主題清晰**
- 4 個獨立主題
- 每個都能單獨傳播

✅ **故事豐富**
- 每個主題配一個故事
- 增加真實感和說服力

✅ **金句收尾**
- 每段都有可傳播的金句
- 節奏穩定

✅ **實用性強**
- 給出具體方法（說謝謝、做公益）
- 不只是哲理

### 適用痛點
焦慮感（擔心錢不夠）

### 分享動機
價值認同、身份建構

## 範例 3：地藏王（痛點解方型）

### 完整內容

```
地藏王菩薩說：
地獄不在地底，而在人心

為錢忙，卻忘了為心安
有人終日追著業績、訂單、數字跑
賺到錢後卻夜夜失眠，怕明天會沒了
地藏王說：「若心不安，錢越多越苦。」
因為焦慮不是窮人的專利，而是執著的結果

---

情的執著 放不下的心
愛他太深，也愛得太苦
失戀的人總說：「我放不下他。」
但放不下的，其實不是愛，而是習慣
地藏王說：「你抓得太緊，手就會流血。」
真正的愛，是在祝福裡放手

---

名的競逐 比較的陷阱
怕被看不見，卻忘了看自己
每天滑著社群 看著別人的好 卻覺得自己糟
你的焦慮不是來自別人 而是來自比較
地藏王說：「名是幻影，心才是真。」
當你學會欣賞自己 才會找到真正的自由

---

地獄的出口
原諒 是放自己自由

有些人心裡住著一場舊恨
反覆著
地藏王說：「怨，是最深的監牢
你不放手，誰都出不去。」

當你願意不再恨、不再怕、不再比較
那一刻，你已經走出自己的地獄

最苦的地獄，不在地下 而在心裡
真正的解脫是從「心」開始
```

### 架構分析

| 結構 | 內容 |
|------|------|
| 開場 | 地獄不在地底，而在人心 |
| 主題 1 | 為錢忙（財的執著） |
| 主題 2 | 放不下的心（情的執著） |
| 主題 3 | 比較的陷阱（名的競逐） |
| 主題 4 | 地獄的出口（原諒） |
| 收尾 | 真正的解脫是從「心」開始 |

### 風格特色

✅ **層層遞進**
- 從財 → 情 → 名 → 出口
- 邏輯清晰

✅ **每段有金句**
- 「若心不安，錢越多越苦」
- 「你抓得太緊，手就會流血」
- 「怨，是最深的監牢」

✅ **詩意與哲理**
- 語言優美但不晦澀
- 有畫面感

✅ **給出出口**
- 不只說問題
- 指出解脫之道

### 適用痛點
執著感（放不下、困在情緒）

### 分享動機
自我投射、關係溝通

## 範例 4：觀音（主題教學型 + 人際關係）

### 完整內容

```
觀音佛祖說：

學會「看見」他人
善意的眼光，是一種修行
有時我們並非不懂愛，而是太急著批判
佛祖提醒你：看見對方的努力
看見他還願意學習、改變的心
這份「看見」，就是愛的起點

---

學會「傾聽」
不是沉默真正的聽，是放下自己的聲音
當你願意停下來聽
你會發現對方只是想被理解、被接納
試著用心聽，不急著反應
讓人際間的能量回歸平和

---

學會「柔軟」
不是退讓柔軟，是強者的選擇
佛祖說：「慈悲不是委屈
而是選擇不讓恨長大」
當你願意放下對錯，選擇圓融
你其實是在成就更深的力量 
練習「慢下來」
退一步會贏得更多尊重與和諧

---

學會「自愛」
才能愛人關係的平衡，從自我疼惜開始
你不是一直要給的那個人
當你懂得回到自己、滋養自己
你會發現人際也開始回應你溫柔的能量
你太習慣照顧別人，卻忘了照顧自己
當你開始為自己設定界線
關係會變得更真實也更穩定

---

修一段柔軟的人際關係
練習用「感謝的眼」去看世界
會發現更多溫暖的連結
試著用心聽，不急著反應
```

### 架構分析

| 結構 | 內容 |
|------|------|
| 主題 1 | 學會「看見」他人 |
| 主題 2 | 學會「傾聽」 |
| 主題 3 | 學會「柔軟」 |
| 主題 4 | 學會「自愛」 |
| 總結 | 修一段柔軟的人際關係 |

### 風格特色

✅ **統一開頭**
- 都用「學會」開頭
- 製造節奏感

✅ **實用建議**
- 不只說概念
- 給出具體練習

✅ **溫柔語氣**
- 沒有說教感
- 像朋友提醒

✅ **循序漸進**
- 從對外（看見他人）
- 到對內（自愛）
- 邏輯自然

### 適用痛點
孤獨感（人際關係疲憊）

### 分享動機
身份建構、價值認同

## 範例 5：五路財神（痛點解方型）

### 完整內容

```
五路財神：
每個人的致富路徑都不一樣

可能比別人更努力，但財運為什麼總跟不上
原因不是你不夠努力，
而是你的能量方向還沒對上你的財路
每個人的致富路徑都不一樣。

比較別人的財運，只會浪費能量
財神不喜歡盲目模仿。
別人的致富路可能是投資、創業、貴人相助或積累資產。
你的方式可能完全不同，焦慮只會消耗能量。
不要有：「為什麼他很有錢，我就沒有」的想法，那都不是重點，
找到屬於你的方式，向內求，財神才會靠近。

---

先認識自己，財神才會認識妳
財運與你的個性、能量有關，
你是創意型、守財型、行動型還是貴人型？
不同特質對應不同的致富方法，
一套賺錢公式，不適用每個人，結局肯定完全不同，
了解自己，財神才會知道怎麼幫助你。

---

調整思維，比努力更重要
能量對了，財路自然暢通，
停止抱怨、停止焦慮，把心力放在適合自己的財路上。
你會發現，財富慢慢從意想不到的方向湧來，
努力是標配，用對方法才是致富的密碼。
```

### 架構分析

| 結構 | 內容 |
|------|------|
| 痛點開場 | 為什麼努力卻沒財運 |
| 錯誤思維 1 | 比較別人的財運 |
| 正確理解 1 | 找到屬於你的方式 |
| 錯誤思維 2 | 盲目模仿 |
| 正確理解 2 | 先認識自己 |
| 核心洞見 | 調整思維比努力重要 |
| 收尾金句 | 用對方法才是密碼 |

### 風格特色

✅ **破除迷思**
- 指出常見錯誤思維
- 提供新視角

✅ **給出方法**
- 不只說問題
- 教你怎麼做

✅ **邏輯清晰**
- 問題 → 原因 → 解方
- 容易理解

✅ **實用性強**
- 可以立刻思考自己的類型
- 有行動感

### 適用痛點
焦慮感 + 迷茫感（努力沒回報）

### 分享動機
價值認同、自我投射

## 💡 創作時如何參考這些範例

### 1. 找到相似痛點
先確定要解決什麼痛點，找對應範例

### 2. 學習結構
看範例用什麼架構、什麼模組組合

### 3. 學習節奏
注意每段多少行、句式怎麼安排

### 4. 學習金句
看金句如何製造對比、反轉、洞見

### 5. 創造自己的版本
不要照抄，而是學習精神後創造新內容
