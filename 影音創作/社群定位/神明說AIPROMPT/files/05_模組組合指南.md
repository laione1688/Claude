# 模組組合指南

## 🧩 內容模組化系統

把內容創作像組裝樂高一樣，用不同模組靈活組合。

---

## 必備模組（每篇都要有）

### ✅ 模組 0：開場點題

**功能：** 用一句話抓住注意力，點出主題

**格式：**
```
從 [神明名稱] 的「[核心象徵]」[動詞]...
```

**動詞選擇：**
- 看見
- 理解
- 學習
- 思考
- 找到

**範例：**
```
✅ 從玉皇大帝的「主宰」象徵，看見選擇的力量
✅ 從觀音的「慈悲」象徵，學習人際關係的智慧
✅ 從福德正神的「踏實」象徵，理解財富的真相
```

**避免：**
```
❌ 玉皇大帝說...
❌ 觀音告訴你...
❌ 福德正神教你...
```

---

### ✅ 模組 1：神明文化定位（開場說明）

**功能：** 建立詮釋的正當性，說明這是文化象徵

**固定格式：**
```
在台灣民間信仰中
[神明名稱] 被視為 [角色定位]
這個「[核心象徵]」的文化意涵，讓我們思考：
[核心洞見一句話]
```

**範例：**
```
在台灣民間信仰中
地藏王菩薩被視為度化眾生、不捨一人的象徵
這個「願力」的文化意涵，讓我們思考：
最苦的地獄不在地下，而在心裡
```

**重要：**
- 這段必須在開場出現
- 建立「我們在詮釋象徵」的框架
- 避免讀者誤以為是神明說的話

---

### ✅ 模組 2：核心洞見（金句）

**功能：** 可獨立傳播的智慧語錄，打破慣性思維

**數量：** 每篇至少 2-3 個，最多 5 個

**特徵：**
- 簡短有力（8-20 字）
- 對比或反轉
- 可以單獨作為限時動態

**範例：**
```
✅ 因果不是報應，是覺醒
✅ 財若無德聚也散，德若有根貧也安
✅ 你抓得太緊，手就會流血
✅ 方向比努力更重要
✅ 感恩的嘴，最會招財
```

**創作技巧：**
1. **對比式**：A 不是 B，是 C
   - 「因果不是報應，是覺醒」
2. **因果式**：如果 A，就 B
   - 「你越焦慮，福氣越走遠」
3. **比喻式**：A 就像 B
   - 「怨是最深的監牢」
4. **條件式**：有 A 才有 B
   - 「有德，錢才留得住」

---

### ✅ 模組 3：收尾昇華

**功能：** 帶出希望、轉念或祝福，讓讀者帶著正能量離開

**格式選擇：**

**1. 金句式：**
```
懂了，就自由了
```

**2. 祝福式：**
```
願你如觀音般安然，不懼風浪
```

**3. 轉念式：**
```
當你願意不再恨、不再怕、不再比較
那一刻，你已經走出自己的地獄
```

**4. 行動式：**
```
✨ 今天起，試著對自己說：
「這是我的選擇，我負責」
```

---

### ✅ 模組 4：來源標註

**功能：** 明確這是我們的詮釋，不是神諭

**固定格式：**
```
💭 這是我們從「[神明名稱] + [核心特質]」的信仰象徵中
   讀到的啟發
```

**範例：**
```
💭 這是我們從「玉皇大帝主宰與秩序」的信仰象徵中
   讀到的啟發

💭 這是我們從「觀音慈悲與柔軟」的信仰象徵中
   讀到的啟發

💭 這是我們從「福德正神踏實與感恩」的信仰象徵中
   讀到的啟發
```

**重要：**
- 每篇結尾必須有
- 位置：在最後一段
- 不能省略

## 選配模組（根據需求添加）

### 📦 模組 A：痛點場景描述

**功能：** 製造情緒共鳴，讓讀者覺得「這說的就是我」

**使用時機：**
- 開場需要快速抓住注意力
- 目標是情緒共鳴

**寫作技巧：**
1. **具體場景**：不要抽象，要有畫面
2. **第二人稱**：用「你」製造代入感
3. **感官細節**：加入感受、動作、時間

**範例：**

❌ 抽象版：
```
很多人都覺得很焦慮
```

✅ 具體版：
```
每天加班到深夜
看著帳戶數字還是不夠
你開始懷疑：是不是我不夠努力？
```

❌ 抽象版：
```
有些人放不下過去
```

✅ 具體版：
```
當你夜不能寐、心有愧意的那一刻
反覆想著那些說不出口的對不起
審判已經開始
```

---

### 📦 模組 B：真實故事案例

**功能：** 增加說服力，讓抽象概念具體化

**使用時機：**
- 需要證明洞見是對的
- 讀者需要具體方法

**故事來源：**
1. **真實但匿名**：「有個朋友...」
2. **民間故事**：「一位攤販阿姨...」
3. **假設但真實感**：「有個每天拜財神的人...」

**故事結構：**
```
【困境】有個人遇到 XX 問題
【轉折】直到有天他...
【結果】結果...
【洞見】從 XX 象徵來看：...
```

**範例：**
```
有個每天拜財神求中樂透的人
卻從來沒中過

直到有天他靜下心
開始專注做自己擅長的事
客戶就都主動找上門了

從福德正神的「踏實」象徵來看：
財氣喜靜不喜亂
你越焦慮，福氣越走遠
```

**注意：**
- 故事要短（3-5 行）
- 不要太複雜
- 結尾要連結回洞見

---

### 📦 模組 C：🔸列點強化

**功能：** 用視覺化方式加深印象，製造節奏感

**使用時機：**
- 有多個並列的洞見
- 需要製造停頓感
- 適合架構 A（哲理深省型）

**寫作技巧：**
1. **數量：** 通常 3 個（符合認知習慣）
2. **對仗：** 結構相似，節奏一致
3. **遞進：** 從淺到深，或從外到內

**範例：**

✅ 結構對仗：
```
🔸 有些人再次出現，不是偶然，是未完的功課
🔸 有些痛苦重演，不是命運懲罰，而是靈魂修正
🔸 有些別離，是還債，也是解脫
```

✅ 遞進式：
```
🔸 你選擇抱怨，痛苦就會延長
🔸 你選擇責怪，力量就會流失
🔸 你選擇等待，機會就會錯過
```

❌ 避免：
```
🔸 要學會感恩
🔸 不要太執著
🔸 放下才會自由
（太抽象，沒有對仗）
```

---

### 📦 模組 D：反問對話

**功能：** 製造思考、打破讀者的內心獨白

**使用時機：**
- 需要製造對話感
- 預測讀者會有的疑問
- 適合架構 A

**格式：**
```
你問：「[讀者的疑問]」

[回答 + 洞見]
```

**範例：**
```
你問：「為什麼老天不幫我？」

其實，神明早在幫你
只是用「現實」的樣子提醒你
```

```
你說：「我就是放不下他」

但放不下的，其實不是愛
而是習慣
```

**技巧：**
- 疑問要真實（讀者真的會這樣想）
- 回答要有洞見（打破原有思維）
- 不要太多次（一篇 1-2 次就好）

---

### 📦 模組 E：主題分段

**功能：** 深度教學，提供多個角度

**使用時機：**
- 主題複雜，需要拆解
- 適合架構 B（主題教學型）
- 讀者需要具體方法

**數量：** 3-4 個主題

**每段結構：**
```
【小標題】
【概念解釋】
【具體場景或案例】
【金句收尾】
```

**範例：**
```
學會「看見」他人
善意的眼光，是一種修行

有時我們並非不懂愛
而是太急著批判

從觀音的慈悲視角來看：
看見對方的努力
看見他還願意學習、改變的心
這份「看見」，就是愛的起點
```

**技巧：**
- 每段要能獨立成篇
- 用統一開頭（學會、從...看、...的提醒）
- 分隔線讓視覺清爽

---

### 📦 模組 F：思維對比

**功能：** 破除迷思，建立新思維

**使用時機：**
- 需要糾正錯誤觀念
- 適合架構 C（痛點解方型）
- 目標是認知重構

**格式：**
```
❌ 錯誤思維：[常見想法]
[為什麼這樣想是錯的]

✅ 正確理解：[新的視角]
[從神明象徵的洞見]
```

**範例：**
```
❌ 錯誤思維：比較別人的財運

「為什麼他很有錢，我就沒有？」
這種想法只會浪費能量

✅ 正確理解：向內求，找到屬於你的方式

從五路財神的「通路」象徵來看：
每個人的致富路徑都不一樣
停止比較，財神才會靠近
```

**技巧：**
- 用 ❌ ✅ 製造視覺對比
- 錯誤要具體（不只說錯，要說為什麼錯）
- 正確要有洞見（不只說對，要給新視角）

---

### 📦 模組 G：行動指引

**功能：** 給出具體可執行的第一步

**使用時機：**
- 讀者需要具體方法
- 目標是促進行動
- 收尾時使用

**格式選擇：**

**1. 簡單版：**
```
✨ 今天起，試著對自己說：
「這是我的選擇，我負責」
```

**2. 多步驟版：**
```
✨ 從今天開始：
1. 每次收到錢，都真心說一句「謝謝」
2. 停下來問自己：我的能量方向對了嗎？
3. 練習一天不抱怨
```

**3. 提問式：**
```
✨ 問問自己：
我是什麼類型的人？
我的能量方向對了嗎？
```

**原則：**
- 要簡單（今天就能做）
- 要具體（知道怎麼做）
- 不要太多（1-3 個動作）

## 🎯 模組組合策略

### 策略 1：極簡組合（快速內容）
```
必備：開場 + 神明定位 + 金句 + 收尾 + 標註
選配：痛點場景
```
適合：限時動態、快速產出

---

```
必備：開場 + 神明定位 + 金句 + 收尾 + 標註
選配：痛點場景 + 🔸列點 + 反問對話
```
適合：一般 IG 貼文

---

### 策略 3：豐富組合（深度內容）
```
必備：開場 + 神明定位 + 金句 + 收尾 + 標註
選配：痛點場景 + 故事案例 + 主題分段 + 行動指引
```
適合：想要收藏、深度閱讀的內容

```
必備：開場 + 神明定位 + 金句 + 收尾 + 標註
選配：主題分段（3-4 個）+ 故事案例 + 行動指引
```
適合：人際關係、具體方法類主題

## 💡 模組使用技巧

### 1. 不要貪心
- 不是模組越多越好
- 選 2-3 個選配模組就夠
- 保持節奏流暢

### 2. 注意順序
- 痛點場景：開場
- 故事案例：中間
- 行動指引：結尾

### 3. 保持一致
- 同一篇內容風格要統一
- 不要同時用太多技巧

### 4. 測試效果
- 記錄哪些模組組合效果好
- 根據數據調整
