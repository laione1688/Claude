# 進階寫作技巧｜避免說教感、製造生活畫面

## 🎯 核心問題

即使結構對了、邏輯順了，還是可能讓讀者覺得「怪」。
因為差的是：**語氣親民度** 和 **畫面感**

---

## ❌ 常見的「怪」

### 問題 1：重複使用「提醒我們」結構

**為什麼會怪？**
- 重複 = 說教感
- 尤其金錢、焦慮主題，容易讓讀者有壓力

**錯誤示範：**
```
祂提醒我們：致富的路不只一條
（第 1 次）

祂是提醒你——
找到適合你的路
（第 2 次，結構重複）
```

**正確做法：**
```
祂提醒我們：
賺錢的方式不只一種
（開場用 1 次就好）

五路財神給人的智慧很樸實：
不是叫你跟著別人走，
而是讓你找到適合自己的那條路
（換成「給人的智慧」）

這就是五路財神教我們的：
方向對了，財自然來
（結尾換成「教我們的」）
```

**原則：**
- 「提醒我們」全篇只用 1 次
- 其他地方換說法：
  - 「給人的智慧」
  - 「教我們的」
  - 「讓我們看到」
  - 「從祂身上學到」

---

### 問題 2：太多「標語式」句子，缺少生活畫面

**為什麼會怪？**
- IG 讀者不喜歡「道理」
- 喜歡「故事」和「畫面」

**錯誤示範：**
```
找到適合你的那條路，才會順
適合你的路，才是你的財路
```
→ 像標語、太抽象、沒畫面

**正確做法：**
```
有人適合做生意，
有人適合上班，
有人適合投資，
有人適合慢慢存——
每一條路都能走出財富，
只要「合乎你自己」
```

**原則：**
- 不要只講「適合你的路」（抽象）
- 要列舉具體選項（做生意、上班、投資、慢慢存）
- 給讀者畫面和選擇
- 用「——」串接，更有節奏

---

### 問題 3：故事缺少情緒張力

**為什麼會怪？**
- 只講結果，沒講「走錯路的心酸」
- 缺少情緒對比

**錯誤示範：**
```
看別人炒股賺錢，也跟著炒，
結果賠了一屁股。

後來他發現，
自己其實適合踏實工作、慢慢存
```
→ 平鋪直敘，沒有情緒起伏

**正確做法：**
```
看別人炒股賺錢，也跟著衝，
結果賠到痛不欲生。
（情緒低點）

後來他放下跟風，
回到自己擅長的穩定收入、慢慢累積。
（轉折）

雖然沒有暴富，
但每一年都在往上走，
心也越來越安穩。
（情緒高點）

他說：
不是那條路不好，
是那條路不是我的。

這句話，根本就是財神的語氣。
（巧妙連回神明）
```

**原則：**
- 強調「走錯路的心酸」（賠到痛不欲生）
- 有情緒對比（痛不欲生 → 安穩）
- 點出問題（跟風）和解方（放下、回到擅長的）
- 最後用「他說」+ 連回神明

## ✅ 7 個進階技巧

### 技巧 1：「提醒我們」只用 1 次，其他換說法

**變化詞彙庫：**
- 提醒我們（開場用 1 次）
- 給人的智慧
- 教我們的
- 讓我們看到
- 從祂身上學到

**範例：**
```
開場：祂提醒我們...
中段：XX給人的智慧很樸實...
結尾：這就是XX教我們的...
```

---

### 技巧 2：用「列舉」取代「抽象」

**對照表：**

| 抽象（❌） | 具體列舉（✅） |
|---------|------------|
| 找到適合你的路 | 有人適合做生意、有人適合上班、有人適合投資、有人適合慢慢存 |
| 每個人都不一樣 | 有人喜歡熱鬧、有人喜歡安靜、有人喜歡挑戰、有人喜歡穩定 |
| 要懂得感恩 | 感謝今天的熱茶、準時的公車、順利的工作 |

**公式：**
```
有人[選項A]，
有人[選項B]，
有人[選項C]，
有人[選項D]——
[總結]
```

---

### 技巧 3：故事要有「情緒三段式」

**結構：**
1. 情緒低點（痛不欲生、累到崩潰、賠到想哭）
2. 轉折（放下、發現、後來）
3. 情緒高點（安穩、踏實、自在）

**範例：**
```
（低點）結果賠到痛不欲生
（轉折）後來他放下跟風
（高點）心也越來越安穩
```

---

### 技巧 4：用「帶你走」比「是你的」更有畫面

**對照表：**

| 抽象（❌） | 有畫面（✅） |
|---------|------------|
| 適合你的路，才是你的財路 | 適合你的路，才會帶你走長久 |
| 這是你的福氣 | 這份福氣會跟著你 |
| 這是你的力量 | 這份力量會陪著你 |

**原則：**
- 用動詞（帶、跟、陪）
- 製造動態感

---

### 技巧 5：問句要更口語、更生活化

**對照表：**

| 書面語（❌） | 口語化（✅） |
|----------|----------|
| 我擅長什麼？ | 我做什麼最順？ |
| 什麼事我做起來最順？ | 我什麼不累、還做得下去？ |
| 我適合什麼？ | 什麼樣的生活我最自在？ |

**原則：**
- 用「最順」「不累」「自在」這類生活化詞彙
- 不用「擅長」「適合」這類正式詞

---

### 技巧 6：故事後加「他說」+ 巧妙連結神明

**公式：**
```
（講完故事）

他說：
「[金句]」

這句話，根本就是[神明]的語氣。
```

**範例：**
```
他說：
不是那條路不好，
是那條路不是我的。

這句話，根本就是財神的語氣。
```

**作用：**
- 「他說」讓故事更真實
- 「根本就是XX的語氣」巧妙連回神明
- 不只講故事，還扣回主題

---

### 技巧 7：金句用「三詞遞進」製造節奏

**對照：**

| 平淡（❌） | 有節奏（✅） |
|---------|----------|
| 即使走得慢，只要是你的路，就會順 | 即使走得慢，也會穩、會順、會長久 |
| 你會過得很好 | 你會過得舒服、自在、踏實 |

**公式：**
```
會[詞1]、會[詞2]、會[詞3]
```

**常用三詞組合：**
- 穩、順、長久
- 舒服、自在、踏實
- 清楚、明白、不慌
- 溫柔、堅定、有力

**有哪些問題？**
1. 「提醒」用了 2 次 → 說教感

4. 問句太書面 → 不夠親民

## 🎯 核心原則總結

### 避免說教的 3 個關鍵

1. **「提醒」只用 1 次**
   - 其他換：給人的智慧、教我們的

2. **用列舉，不用抽象**
   - 不說：找到適合你的路
   - 要說：有人適合做生意、有人適合上班...

3. **故事要有情緒對比**
   - 低點（痛不欲生）
   - 轉折（放下跟風）
   - 高點（心越來越安穩）

---

### 製造畫面的 4 個技巧

1. **列舉具體選項**
   - 做生意、上班、投資、慢慢存

2. **用動詞製造動態**
   - 帶你走、跟著你、陪著你

3. **問句要口語**
   - 最順、不累、自在

4. **金句有節奏**
   - 穩、順、長久（三詞遞進）

## 🌸 觀音系特殊技巧

### **觀音系內容的核心：情緒、陪伴、不講正確答案**

觀音系神明（觀音、地藏王、媽祖）需要特別注意：

#### **特殊技巧 1：用「情緒詞」取代「概念詞」**

❌ **概念化（錯誤）：**
```
真正的慈悲，是先把自己照顧好
```

✅ **情緒化（正確）：**
```
真正的慈悲，是不讓自己被耗盡
```

**常用替換：**
- 照顧好自己 → 不讓自己被耗盡
- 對自己的慈悲 → 變得更平靜、更自在
- 學會愛自己 → 終於開始照顧好自己

---

#### **特殊技巧 2：用「可以，但不是...」取代列舉**

❌ **列舉式（在教）：**
```
有人需要溫柔，有人需要界線
```

✅ **陪伴式（在理解）：**
```
柔軟可以，但不是無止境地退讓；
堅定可以，但不是把牆築給每個人
```

---

#### **特殊技巧 3：點出「美德綁架」**

```
祂不會用「愛」要求自己犧牲，
也不會用「慈悲」逼自己強撐
```

**公式：**
```
不會用「[美德]」要求/逼自己[負面行為]
```

---

#### **特殊技巧 4：用短句點出「痛的核心」**

```
但越忍，只會越痛。
```

**公式：**
```
但越[動詞]，只會越[情緒]。
```
