# 內容日曆系統

## 📅 日期驅動的內容生成

這個系統讓你可以直接說「請生成 X 月 X 日的內容」，Claude 會自動匹配主題。

---

## 📋 使用方式

### 方式 1：直接指定日期

**用戶說：**
```
請生成 11/7 週四的內容
```

**Claude 會：**
1. 查看日曆：週四 = 失控感 + 玉皇大帝/城隍爺
2. 自動選擇：
   - 痛點：失控感
   - 神明：玉皇大帝或城隍爺（輪流或根據最近使用）
   - 主題：選擇與責任相關
   - 架構：A（哲理深省型）
3. 生成完整內容

---

### 方式 2：日期 + 自訂主題

**用戶說：**
```
請生成 11/7 的內容
主題：每個選擇都會回到自己身上
```

**Claude 會：**
- 遵循週四的痛點和神明設定
- 但使用你指定的主題
- 保持整體規劃的一致性

---

### 方式 3：預覽整週規劃

**用戶說：**
```
請給我 11/4 - 11/10 這週的內容規劃
```

**Claude 會回覆：**
```
📅 本週內容規劃（11/4 - 11/10）

週一 11/4（迷茫感）
- 神明：媽祖
- 建議主題：在迷霧中找到方向
- 架構：C（痛點解方型）

週二 11/5（焦慮感）
- 神明：福德正神
- 建議主題：踏實的心最招財
- 架構：B（主題教學型）

（以此類推...）

確認後，我會逐日為你生成內容。
```

---

### 方式 4：批次生成

**用戶說：**
```
請一次生成本週一到週五的內容
```

**Claude 會：**
- 按照日曆規劃
- 生成 5 篇完整內容
- 每篇都符合當日主題

## 🔄 輪替策略

### 同一天有多個神明選擇時

**週四（失控感）**
- 選項 1：玉皇大帝
- 選項 2：城隍爺

**輪替規則：**
- 第 1 週：玉皇大帝
- 第 2 週：城隍爺
- 第 3 週：玉皇大帝
- 第 4 週：城隍爺

或根據主題自動選擇：
- 主題偏「選擇、主宰」→ 玉皇大帝
- 主題偏「因果、覺醒」→ 城隍爺
