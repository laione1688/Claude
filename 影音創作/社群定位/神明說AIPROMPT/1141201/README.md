# 香供養內容生成專案｜使用說明

## 📦 這個專案是什麼？

這是一個完整的 **Claude Project 資料包**，專門用來生成「香供養」風格的社群內容：
- 將台灣民間信仰的文化象徵轉化為現代心靈啟發
- 解決現代人的五大核心痛點
- 適合 Instagram／Facebook／小紅書等平台

## 🚀 如何開始使用

### 方法 A：在 Claude.ai 建立專案（推薦）

1. **登入 Claude.ai**
   - 前往 https://claude.ai

2. **建立新專案**
   - 點擊左側的「Projects」
   - 點擊「Create Project」
   - 命名為：「香供養內容生成」

3. **設定專案指令**
   - 在「Custom instructions」欄位
   - 複製 `01_專案說明書_Project_Instructions.md` 的內容
   - 貼上並儲存

4. **上傳知識庫文件**
   - 點擊「Add content」
   - 上傳以下檔案：
     - `02_神明象徵對照表.md`
     - `03_痛點內容策略.md`
     - `04_內容架構範本.md`
     - `05_模組組合指南.md`
     - `06_風格參考範例.md`
     - `07_快速啟動指南.md`
     - `08_內容日曆系統.md`
     - `09_溫暖語氣指南.md`
     - `10_格式更新說明.md`
     - `11_分享式語氣指南.md` ⭐ 必讀
     - `12_流暢寫作指南.md` ⭐⭐ 核心文件
     - `13_新風格神明範例庫.md` ⭐⭐ 核心文件（已更新）
     - `14_進階寫作技巧.md` ⭐⭐⭐ 最新核心
     - `15_觀音系寫作指南.md` ⭐⭐⭐ 觀音/地藏王/媽祖必讀（已更新）
     - `16_故事真實性指南.md` ⭐⭐⭐ 所有內容必讀
     - `17_寫手風格訓練手冊_v1.7.md` ⭐⭐⭐ 寫手必讀
     - `11_分享式語氣範例庫.md` ⭐ 重要

5. **開始對話**
   - 在專案內開啟新對話
   - Claude 會自動載入所有設定和知識庫
   - 直接開始下指令生成內容！

3. **需要時上傳參考文件**

## 💡 使用流程

### 🎯 方法 A：日期驅動（最快速）⭐ 推薦

**適合：有固定發文計劃的團隊**

   - 匹配當日痛點和神明
   - 選擇適合架構
   - 生成完整內容

```
請生成 11/7 的內容

```

**優點：**
- 最快速（一句話搞定）

## ⚠️ 重要提醒

### ✅ 一定要做的事

1. **設定專案指令**
   - 確保 Claude 理解身份和原則
   - 避免每次都要重新說明

2. **開場說明神明定位**
   - 每篇都要說「在台灣民間信仰中...」
   - 建立「詮釋象徵」的框架

3. **結尾標註來源**
   - 每篇都要有「💭 這是我們從...」
   - 明確這是我們的詮釋

4. **品質檢查**
   - 對照檢查清單
   - 確保風格一致

### ❌ 絕對不要做的事

1. **不要用「XX 說」**
   - 避免「觀音說」、「福德正神說」
   - 改用「從 XX 的象徵看」

2. **不要省略神明定位**
   - 每篇開場都要說明文化定位
   - 不能直接開始內容

3. **不要省略來源標註**
   - 結尾一定要標註
   - 明確這是詮釋而非神諭

4. **不要過度使用宗教詞彙**
   - 避免：皈依、法門、功德、業障
   - 使用：修心、覺察、選擇、轉念

## 🔧 疑難排解

### 問題 1：Claude 不按照設定執行

**可能原因：**
- 專案指令沒設定好
- 對話歷史太長，忘記指令

**解決方法：**
- 重新確認專案指令
- 開啟新對話重新開始
- 在指令中強調：「請嚴格按照專案說明書」

---

### 問題 2：生成內容風格不對

**可能原因：**
- 沒有參考範例
- 指令不夠具體

**解決方法：**
- 在指令中加入「風格參考：[範例名稱]」
- 上傳 `06_風格參考範例.md`
- 具體說明要什麼樣的語氣和節奏

---

### 問題 3：內容太長或太短

**可能原因：**
- 沒有指定長度
- 模組選太多或太少

**解決方法：**
- 在指令中加入長度要求
- 調整選配模組數量
- 要求 Claude「請精簡」或「請展開」

---

### 問題 4：金句不夠有力

**可能原因：**
- 沒有強調金句的重要性
- 洞見不夠深刻

**解決方法：**
```
請強化核心金句，要求：
- 簡短有力（10-20 字）
- 有對比或反轉
- 可以單獨傳播
- 打破慣性思維
```

## 📝 版本記錄

**v1.7** - 2024.11.06 ⭐⭐⭐ 信任度突破
- 新增：故事真實性指南（避免虛構人物疲勞）
- 核心發現：「我有個朋友」久了會造成信任危機
- 替換方案：用「你可能也遇過」「我們都曾經」取代
- 使用頻率：「朋友」兩個月最多1次，「群體經驗」可以每篇用
- 核心原則：讓讀者是主角，不是旁觀者
- 信仰溫度：來自共鳴，不是人物設定
- 更新：觀音系寫作指南（加入避免虛構人物疲勞）
- 更新：新風格神明範例庫（觀音改用「我們都曾經」）

**v1.6** - 2024.11.06 ⭐⭐⭐ 觀音系突破
- 新增：觀音系寫作指南（情緒化、陪伴式、不講正確答案）
- 核心技巧：用「情緒詞」取代「概念詞」（耗盡 vs 照顧好）
- 陪伴式寫法：用「可以，但不是...」取代列舉
- 點出美德綁架：「不會用『愛』要求自己犧牲」
- 短句有力量：「但越忍，只會越痛」
