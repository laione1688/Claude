## 1️⃣ 核心風格定位

### ✔ 不是宗教文，是生活文

所有文章「不是在宣講宗教」，
而是用台灣民俗信仰做比喻、做啟發，
帶讀者理解自己的生活、情緒、心理。

---

### ✔ 語氣：像陪伴，不像教導

不要「教」、「說理」、「警告」、「開示」。
要像：
- 陪伴一個心情不好的人
- 讓他被理解
- 用溫柔的方式協助他看懂自己

**這是最重要的。**

---

### ✔ 神明不是主角，人的生活才是主角

文章不是在介紹神明，
而是在透過神明的文化精神
「看見一個現代人的生活痛點」。

**從神明學到的，不是神蹟，而是人生體會。**

---

## 2️⃣ 神明角色設定（非常重要）

每位神明都不能寫得太宗教化，要寫「文化精神」。
以下是可使用的核心觀點：

### 👇 請務必熟記：

**● 觀音：慈悲＝理解感受＋柔軟的界線**
- 不盲目付出、不委屈自己、先照顧好自己
- **情緒化、陪伴式、不講正確答案**
- **用「可以，但不是...」取代列舉**

**● 地藏王：願力＝陪伴黑暗的人、不離不棄**
- 不是說教，而是「在」
- 不是叫人想開，而是「我知道很難」
- **情緒化、陪伴式、不催促**

**● 五路財神：方向＝找到適合自己的路**
- 不是暴富，而是找到自己的財路
- 不是比較別人，而是回到自己
- **用列舉（做生意、上班、投資、慢慢存）取代抽象**

**● 福德正神：穩定＝心安事順、踏實比急更重要**
- 週一顧好心，一週才會順
- 心亂，什麼都不順
- **樸實、踏實、不浮誇**

**● 城隍爺：良心＝因果不是報應，是選擇的累積**
- 你怎麼對人，世界就怎麼對你
- **能量循環、因果自然**

**● 媽祖：勇氣＝怕了還是去做**
- 勇氣不是不怕，而是怕了還是往前走
- **溫柔而堅定**

## 3️⃣ 語氣準則（寫手常犯錯的地方）

### ❌ 請避免以下語句：

❌「神明提醒你」
❌「祂說」
❌「祂告訴你」
❌「祂要你做什麼」
❌「祂正在傳遞訊息」
→ 會讓人誤會成通靈訊息

### ⚠️ **重要更新：「提醒我們」只用 1 次**

❌ **錯誤（重複使用）：**
```
祂提醒我們：致富的路不只一條
（第 1 次）

祂是提醒你——找到適合你的路
（第 2 次，造成說教感）
```

✅ **正確（只用 1 次，其他換說法）：**
```
祂提醒我們：賺錢的方式不只一種
（開場用 1 次）

五路財神給人的智慧很樸實：
不是叫你跟著別人走，
而是讓你找到適合自己的那條路
（換成「給人的智慧」）

這就是五路財神教我們的：
方向對了，財自然來
（結尾換成「教我們的」）
```

### ✔ 可以用的說法：

✔「祂教導我們……」
✔「我們從祂身上學到……」
✔「這個文化意涵讓我們看到……」
✔「這讓我們想到……」
✔「祂給人的智慧是……」
✔「祂帶給人的智慧很溫柔……」
✔「祂讓我們看到……」

**變化使用，避免重複！**

## 4️⃣ 故事真實性（⭐⭐⭐ 超重要更新）

### ⚠️ **「我有個朋友」久了會造成信任危機**

**問題：**
- 讀者會懷疑：你朋友怎麼故事這麼多？
- 會覺得：是不是編的？
- **信任度下降**

這在內容寫作學裡叫：**「虛構人物疲勞 (fiction fatigue)」**

### ❌ **少用（兩個月最多 1 次）：**
- 我有個朋友
- 我曾有一個朋友

### ✅ **多用（每篇都可以用）：**

**替換方案 1：**
```
你可能也遇過這樣的人——
對誰都很好，對自己卻最不溫柔
```

**替換方案 2：**
```
我們很多人都有過這樣的時期——
把所有人的需求放第一位
```

**替換方案 3：**
```
很多人其實都有一段時期，
總是把自己放在最後
```

**替換方案 4：**
```
身邊的人常常這樣——
笑著說沒事，心裡卻已經撐到極限
```

**替換方案 5：**
```
我們都曾經，
把別人的需求放在自己之前，
卻忘了問一句：「那我呢？」
```

**→ 讓讀者是主角，不是旁觀者**
**→ 信仰的溫度來自共鳴，不是人物設定**

## 5️⃣ 敘事結構（非常重要）

每篇文章都要遵守「流暢結構」：

### ① 開場：從神明學到的事（不是道理）

**格式：**
```
從○○學到的事
「象徵意涵」

我們從○○身上學到的，
不是[誤解]，
而是——
[真正的體會]
```

**範例：**
```
從觀音學到的事
「照顧別人之前，先照顧好自己」

我們從觀音身上學到的，
不是無條件把心掏給每個人，
而是——
真正的慈悲，是不讓自己被耗盡
```

❗ **要點：**
- 講「從神明學到什麼」
- 不是「講神明的故事」

---

### ② 連結現代痛苦

**用「你有沒有」邀請共鳴：**
```
你有沒有看過這樣的人——
對誰都很好，對自己卻最不溫柔；
把所有力氣給了別人，
輪到自己時卻只剩下疲憊
```

❗ **要點：**
- 有具體畫面
- 讀者會說「對，就是這樣」

---

### ③ 回扣神明精神

**用「神明給人的智慧」：**
```
觀音帶給人的智慧很溫柔：
祂不會用「愛」要求自己犧牲，
也不會用「慈悲」逼自己強撐
```

❗ **要點：**
- 不斷回扣神明
- 不要脫節

---

### ④ 故事印證（用群體經驗）

**用「我們都曾經」或「你可能也遇過」：**
```
我們很多人都有過這樣的時期——
把所有人的需求放第一位，
直到累得說不出話，
還覺得是自己做得不夠好
```

❗ **要點：**
- 不用「我有個朋友」
- 用群體經驗

---

### ⑤ 深化洞見

**再次連回神明：**
```
那是她人生裡第一次明白——
對別人再好，都不該以犧牲自己為代價。

而懂得這件事那天，
她變得更平靜，也更自在
```

❗ **要點：**
- 講感受（平靜、自在）
- 不講概念（慈悲）

---

### ⑥ 可執行建議

**用「你可以告訴自己」：**
```
你可以告訴自己：
「我需要休息」
「這次我幫不上」
「我要先回到自己身上」
```

❗ **要點：**
- 簡單、做得到
- 溫柔、不評判

---

### ⑦ 收尾回扣

**用「就像○○讓我們看到的」：**
```
記住：
慈悲不是委屈自己去滿足別人，
而是讓自己在溫柔與界線之間，
找到平衡。

即使偶爾說不，
你依然值得被溫柔對待——
就像觀音一直讓我們看到的那樣
```

❗ **要點：**
- 完整閉環
- 回扣神明
- 溫柔收尾

## 6️⃣ 觀音系特殊技巧（⭐⭐⭐ 重要）

**觀音、地藏王、媽祖需要特別注意：**

### 技巧 1：用「情緒詞」取代「概念詞」

❌ **概念化：**
```
真正的慈悲，是先把自己照顧好
```

✅ **情緒化：**
```
真正的慈悲，是不讓自己被耗盡
```

---

### 技巧 2：用「可以，但不是...」取代列舉

❌ **列舉式（在教）：**
```
有人需要溫柔，有人需要界線
```

✅ **陪伴式（在理解）：**
```
柔軟可以，但不是無止境地退讓；
堅定可以，但不是把牆築給每個人
```

---

### 技巧 3：點出「美德綁架」

```
祂不會用「愛」要求自己犧牲，
也不會用「慈悲」逼自己強撐
```

---

### 技巧 4：用短句點出「痛的核心」

```
但越忍，只會越痛。
```

**公式：**
```
但越[動詞]，只會越[情緒]。
```

---

### 技巧 5：故事結果講「感受」不是「概念」

❌ **概念：**
```
原來「愛自己」不是自私，
而是對自己最基本的慈悲
```

✅ **感受：**
```
而懂得這件事那天，
她變得更平靜，也更自在
```

## 7️⃣ 進階寫作技巧

### 技巧 1：避免重複「提醒我們」

**全篇只用 1 次，其他換說法**

---

### 技巧 2：用「列舉」取代「抽象」

❌ **抽象：**
```
找到適合你的路
```

✅ **具體列舉：**
```
有人適合做生意，
有人適合上班，
有人適合投資，
有人適合慢慢存——
每一條路都能走出財富
```

---

### 技巧 3：故事要有「情緒三段式」

**結構：**
1. 情緒低點（痛不欲生、累到崩潰）
2. 轉折（放下、發現、後來）
3. 情緒高點（安穩、踏實、自在）

---

### 技巧 4：用「帶你走」比「是你的」更有畫面

❌ **抽象：**
```
適合你的路，才是你的財路
```

✅ **有畫面：**
```
適合你的路，才會帶你走長久
```

---

### 技巧 5：問句要更口語

❌ **書面語：**
```
我擅長什麼？
```

✅ **口語化：**
```
我做什麼最順？
我什麼不累、還做得下去？
```

---

### 技巧 6：金句用「三詞遞進」

❌ **平淡：**
```
即使走得慢，只要是你的路，就會順
```

✅ **有節奏：**
```
即使走得慢，也會穩、會順、會長久
```

## 8️⃣ 文風禁忌（必須完全避免）

❌ 太宗教
❌ 太 preachy（教訓人）
❌ 太心理學專業名詞
❌ 太像勵志文章
❌ 太像作文
❌ 太多因果恐嚇
❌ 太硬的神職介紹
❌ 太像「神明說話」
❌ **重複使用「提醒我們」** ⭐ 新
❌ **頻繁使用「我有個朋友」** ⭐ 新
❌ **只講道理不講感受** ⭐ 新

---

## ✔ 要寫成：

- 溫柔的陪伴
- 一個很懂人的人
- 看透，但不批判
- 拿信仰當作一面鏡子，而不是棒子
- 讓讀者覺得「啊，被理解了」
- **用情緒詞，不用概念詞** ⭐ 新
- **用群體經驗，不用虛構朋友** ⭐ 新
- **講感受，不講概念** ⭐ 新

這是你（品牌）最重要的調性。

## 9️⃣ 寫作範例（示範「錯 → 對」）

### 範例 1：地藏王

❌ **錯的寫法（太道理、太講教條）：**
```
地藏王告訴我們要放下，因為執著會造成痛苦。
```

✅ **對的寫法（v1.7 風格）：**
```
很多人以為，放下是說服自己不痛。
但地藏王讓我們看到：
放下不是否定痛，而是不讓痛困住你。
```

---

### 範例 2：五路財神

❌ **錯的寫法（太宗教化）：**
```
五路財神掌管東西南北中五方財庫，只要虔誠祈求便能得財。
```

✅ **對的寫法（v1.7 風格）：**
```
五路財神的智慧不是『求就有』，
而是提醒我們——
財富有很多條路，走對了，你才會順。
```

---

### 範例 3：觀音（情緒化）

❌ **錯的寫法（太概念化）：**
```
真正的慈悲，是先把自己照顧好。

有人需要溫柔，有人需要界線。

我有個朋友學會了愛自己，
終於明白這是對自己最基本的慈悲。
```

✅ **對的寫法（v1.7 風格）：**
```
真正的慈悲，是不讓自己被耗盡。

柔軟可以，但不是無止境地退讓；
堅定可以，但不是把牆築給每個人。

我們很多人都有過這樣的時期——
把所有人的需求放第一位，
直到累得說不出話。

而懂得這件事那天，
她變得更平靜，也更自在。
```
