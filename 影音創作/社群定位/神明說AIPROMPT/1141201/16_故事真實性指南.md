# 故事真實性指南｜避免「虛構人物疲勞」

## ⚠️ 核心問題

**「我有個朋友」放一次 OK，但常出現會造成信任危機**

---

## 🚨 為什麼「我有個朋友」久了會有問題？

### **問題 1：讀者會開始懷疑**

當文章常出現「我有個朋友」，讀者會想：
- 你朋友怎麼故事這麼多？
- 你的朋友是不是你自己？
- 這帳號會不會一直編？
- **真實性下降 → 信任感下降**

**這在內容寫作學裡叫：**
**「虛構人物疲勞 (fiction fatigue)」**
→ 是造成粉絲信任危機最常見的寫作陷阱

---

### **問題 2：人的經驗有限，故事不可能這麼剛好**

如果每篇都有一個朋友發生情緒故事，
讀者會覺得：
- 「太剛好了吧？」
- 「哪來這麼多朋友？」
- 「感覺是編的故事......」

**IG 與 FB 的內容，一旦被懷疑「你是不是寫故事給自己用？」**
**信任度會直接下滑。**

---

### **問題 3：「朋友」把情緒距離拉遠了**

你想呈現的是：
- 真實生活情境
- 常見的人類心境

但「我朋友」會讓讀者變成**第三人稱旁觀**，
距離立刻拉遠。

---

### **問題 4：過度使用會變成「說教軸心」**

當故事是「朋友」時，主角不是讀者。
讀者會覺得你在講別人的事，不是在陪他。

**信仰心理系內容最重要的是：**
**「你講的是我」**
**不是「你講的是某個你編出來的人」**

---

### **問題 5：會被視為套路，而不是洞察**

久了粉絲看懂公式：
```
主題 → 語錄 → 朋友故事 → 結語
```

一旦公式化，內容魅力會下降。

---

## ✅ 該怎麼取代「我有個朋友」？

### **替換方案 1：用「你可能也遇過這樣的人」**

```
你可能也遇過這樣的人——
對每個人都好，卻對自己最不溫柔。
```

**優點：**
- 超親民
- 完全不說謊
- 讓讀者自己想起身邊的人
- 可信度 100%

---

### **替換方案 2：用「很多人其實都有一個時期」**

```
很多人其實都有一段時期，
總是把自己放在最後。
```

**優點：**
- 群體經驗
- 讀者更容易代入
- 不指涉特定人物

---

### **替換方案 3：用「身邊的人其實常常這樣」**

```
身邊的人常常這樣——
笑著說沒事，心裡卻已經撐到極限。
```

**優點：**
- 不指涉虛構人物
- 可信度更高
- 更生活化

---

### **替換方案 4：用「我們都曾經」**

```
我們都曾經，
把別人的需求放在自己之前，
卻忘了問一句：「那我呢？」
```

**優點：**
- **包容性最高**
- **最不會被懷疑**
- 讓讀者感覺「我也是」

---

### **替換方案 5：如果真的要用朋友，也要弱化人物感**

❌ **不好（人物感太強）：**
```
我有個朋友......
我曾有一個朋友......
```

✅ **更好（弱化成案例）：**
```
我聽過一個很共鳴的故事——
有人總是習慣把所有人放在自己前面。
```

**優點：**
- 讓故事變成「案例」
- 不是「虛構朋友」
- 可信度更高

---

### **替換方案 6：用「我想起一個很多人都有過的經歷」**

```
我想起一個很多人都有過的經歷——
把所有人的需求放第一位，
直到累得說不出話，
還覺得是自己做得不夠好。
```

**優點：**
✔ 不虛構、無需朋友
✔ 更貼近讀者
✔ 更容易代入
✔ 更像觀音的氣質（慈悲與理解）

---

## 📋 完整對照：觀音故事段落

### ❌ 原版（有問題）

```
我曾有一個朋友，
總是把別人的需求放在第一位，
自己累到生病了，還在幫別人忙。

後來她學會說「不」，
有人說她變了、變自私了。

但她說：
不是變自私，是終於學會愛自己。
```

**問題：**
- 「我曾有一個朋友」= 虛構人物感太強
- 久了會被懷疑

---

### ✅ 優化版 1（群體經驗）

```
我們很多人都有過這樣的時期——
把所有人的需求放第一位，
直到累得說不出話，
還覺得是自己做得不夠好。

有人就是在這樣的循環裡，
終於有一天學會說「不」。

周圍的人覺得她變了、變得冷淡了。

但她說：
「不是變了，是我終於開始照顧好自己。」

那是她人生裡第一次明白——
對別人再好，都不該以犧牲自己為代價。

而懂得這件事那天，
她變得更平靜，也更自在。
```

**改善：**
✔ 「我們很多人」= 包容性高
✔ 「有人就是」= 弱化人物感
✔ 不指涉特定朋友
✔ 可信度更高

---

### ✅ 優化版 2（你可能也遇過）

```
你可能也遇過這樣的人——
對誰都很好，對自己卻最不溫柔；
把所有力氣給了別人，
輪到自己時卻只剩下疲憊。

有些人會在某個瞬間醒過來，
開始學會說「不」。

周圍可能會有人覺得：
「你變了、變得冷淡了。」

但那個人會說：
「不是變了，是我終於開始照顧好自己。」

那是人生裡很重要的一刻——
明白對別人再好，都不該以犧牲自己為代價。

而懂得這件事之後，
人會變得更平靜，也更自在。
```

**改善：**
✔ 「你可能也遇過」= 讀者自己想起身邊的人
✔ 「有些人會」= 更寬泛，不指涉特定人
✔ 完全不說謊
✔ 超親民

---

### ✅ 優化版 3（我們都曾經）

```
我們都曾經有過這樣的時候——
把別人的需求放在自己之前，
累到撐不住了，
還覺得是自己做得不夠。

後來有些人會在某個瞬間，
第一次學會對別人說「不」。

周圍的人可能會不習慣：
「你怎麼變了？」

但那個人心裡很清楚：
「不是變了，是我終於開始照顧好自己。」

那是人生裡很重要的領悟——
對別人再好，都不該以犧牲自己為代價。

懂得這件事之後，
人會變得更平靜，也更自在。
```

**改善：**
✔ 「我們都曾經」= 包容性最高
✔ 「後來有些人」= 不指涉特定人
✔ 最不會被懷疑
✔ 讀者感覺「我也是」

## 🎯 使用頻率建議

### **可以常用（不會被懷疑）：**
1. 「你可能也遇過這樣的人」
2. 「很多人其實都有一個時期」
3. 「我們都曾經」
4. 「身邊的人常常這樣」

**→ 這些完全可以每篇都用，不會造成疲勞**

---

### **偶爾用（弱化人物感）：**
1. 「我聽過一個很共鳴的故事」
2. 「我想起一個很多人都有過的經歷」

**→ 一個月用 1-2 次 OK**

---

### **少用（容易疲勞）：**
1. 「我有個朋友」
2. 「我曾有一個朋友」

**→ 兩個月最多 1 次**

---

## ✅ 故事真實性檢查清單

寫完故事段落後，檢查：

- [ ] 有用「你可能也遇過」或「我們都曾經」？

### 可信度
- [ ] 故事不會讓人覺得「太剛好」？
- [ ] 不會讓人覺得「朋友怎麼這麼多」？
- [ ] 不會讓人懷疑「是不是編的」？

### 距離感
- [ ] 讀者是主角（不是旁觀者）？
- [ ] 讀者會覺得「你講的是我」？
- [ ] 不會覺得「你在講別人的事」？

### 套路感
- [ ] 不會每篇都是一樣的公式？
- [ ] 故事呈現方式有變化？

## 💡 核心原則

### **信仰心理系內容最重要的是：**

**「你講的是我」**
**不是「你講的是某個你編出來的人」**

---

### **信仰的溫度來自共鳴，不是人物設定**

所以：
- 用「群體經驗」的方式呈現
- 會更貼近大家的生活
- 不會被懷疑真實性

## 🌸 觀音系特別注意

**觀音系內容（觀音、地藏王、媽祖）更要避免「虛構人物感」**

因為：
- 觀音系強調「陪伴」
- 陪伴的前提是「真實」
- 如果讀者覺得「你在編故事」
- 陪伴感立刻消失

**所以觀音系更要用：**
- 「你可能也遇過」
- 「我們都曾經」
- 「很多人都有過」

**→ 讓讀者覺得「你真的懂我」**
**→ 而不是「你在講別人」**

---

## 🎯 核心記住

**「虛構人物疲勞」是信任危機的來源**

避免方法：
1. 少用「我有個朋友」
2. 多用「你可能也遇過」「我們都曾經」
3. 讓讀者是主角，不是旁觀者
4. 故事來自共鳴，不是人物設定

---
