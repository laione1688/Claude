# 快速啟動指南

## 🚀 5 分鐘開始使用這個系統

---

## 步驟 1：了解你的目標（30 秒）

在開始創作前，先問自己：

```
今天要解決什麼痛點？
□ 失控感（覺得人生不由自己掌控）
□ 焦慮感（擔心錢、擔心未來）
□ 執著感（放不下過去）
□ 孤獨感（人際關係疲憊）
□ 迷茫感（不知道方向）
```

---

## 步驟 2：選擇對應神明（30 秒）

根據痛點快速選擇：

| 你的痛點 | 推薦神明 |
|---------|---------|
| 失控感 | 玉皇大帝、城隍爺 |
| 焦慮感 | 福德正神、五路財神 |
| 執著感 | 地藏王、觀音 |
| 孤獨感 | 觀音、月老 |
| 迷茫感 | 媽祖、文昌帝君、五路財神 |

---

## 步驟 3：選擇架構類型（30 秒）

根據痛點選擇最適合的架構：

| 痛點 | 推薦架構 | 特色 |
|------|---------|------|
| 失控感 | 架構 A：哲理深省型 | 金句密集、引發覺醒 |
| 焦慮感 | 架構 C：痛點解方型 | 破除迷思、給方向 |
| 執著感 | 架構 A：哲理深省型 | 情感共鳴、深度思考 |
| 孤獨感 | 架構 B：主題教學型 | 實用建議、溫柔引導 |
| 迷茫感 | 架構 C：痛點解方型 | 邏輯清晰、找到路 |

---

## 步驟 4：向 AI 下指令（2 分鐘）

### 方法 A：簡單版（適合快速產出）

```
請用以下設定生成內容：

痛點：[選擇一個]
神明：[選擇一個]
主題：[一句話描述]
架構：[A/B/C]
```

**範例：**
```
請用以下設定生成內容：

痛點：焦慮感
神明：福德正神
主題：感恩比努力更招財
架構：B（主題教學型）
```

---

### 方法 B：詳細版（適合精準控制）

```

```

## 步驟 5：檢查品質（1 分鐘）

收到 AI 生成的內容後，快速檢查：

### 必備檢查清單
- [ ] 開場有說明神明的文化定位
- [ ] 沒有使用「XX 說」的直接引述
- [ ] 至少有 2 個可獨立傳播的金句
- [ ] 每段 3-5 行，節奏流暢
- [ ] 結尾有來源標註（💭）
- [ ] 語氣溫柔但有力量

### 如果需要調整
```
請調整以下部分：
1. [具體指出要改什麼]
2. [為什麼要改]
3. [改成什麼樣子]
```

```

```

### 技巧 2：指定語氣
在指令中加入：
```
語氣：溫柔但有力量，像老友提醒而非長輩說教
```

### 技巧 3：控制長度
在指令中加入：
```
長度：適合 IG 貼文（約 300-500 字）
或：適合深度閱讀（約 800-1000 字）
```

## ⚠️ 常見錯誤與解決

### 錯誤 1：AI 用了「XX 說」

**解決：**
```
請修改，不要用「XX 說」
改用「從 XX 的『象徵』看」
```

### 錯誤 2：沒有神明文化定位

**解決：**
```
請在開場加上神明的文化定位說明
格式：在台灣民間信仰中，XX 被視為...
```

### 錯誤 3：太抽象，不夠具體

**解決：**
```
請加入具體場景描述
讓讀者能想像或回憶類似經歷
```

### 錯誤 4：金句不夠有力

**解決：**
```
請強化核心金句
使用對比、反轉或因果關係
讓金句可以獨立傳播
```

## 📊 產出後的下一步

### 1. 儲存金句
把好的金句單獨存檔，可以：
- 做成限時動態
- 做成圖文卡片
- 用在其他內容

### 2. 記錄數據
記錄哪些內容表現好：
- 痛點 + 神明組合
- 架構類型
- 模組組合
- 發布時間

### 3. 持續優化
根據數據調整：
- 哪些痛點最受歡迎
- 哪些架構互動最高
- 哪些神明最有共鳴

## ✨ 第一次使用建議

### 建議 1：從簡單開始
第一次使用，建議：
- 選擇你最熟悉的痛點
- 使用架構 A（最簡單）
- 不要一次加太多模組

### 建議 2：對比參考範例
- 生成後和範例比較
- 看節奏、金句、結構
- 學習精髓而非照抄

### 建議 3：多次調整
- 第一版不會完美
- 多次調整找到感覺
- 建立自己的模板

## 📞 遇到問題怎麼辦

### 問題 1：不知道選什麼痛點
→ 回想最近收到最多共鳴的貼文是什麼主題

→ 用「痛點 → 神明」快速對照表

### 問題 3：AI 產出不滿意
→ 先檢查是不是指令不夠清楚
→ 參考「常見錯誤與解決」

### 問題 4：風格不對
→ 在指令中加入「風格參考：[範例名稱]」
→ 多調整幾次找感覺
