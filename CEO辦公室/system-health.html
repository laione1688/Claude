🔍 各排程的驗證方法

如何判斷每個排程有沒有跑？

GitHub 備份 — 看 git -C ~/.claude log --oneline -1 的日期是否為今天
iCloud 備份 — 看 ls -lt ~/Library/Mobile Documents/com~apple~CloudDocs/claude-data-backup/ 修改日期
競品抓取 — 看 Obsidian 競品分析/ 裡最新的 raw-data.json 日期
Notion 預檢 — 目前無 log ⚠️，預計加 TG 告警通知
晨報 — 看 Obsidian 晨報資料夾有沒有今天的 .md 檔
CEO 報表 — 看 daily-planner.html 頁面上的「資料更新時間」是否為今天
Healthcheck — Remote Trigger 自帶 lastRunAt 記錄
Self-review — Remote Trigger lastRunAt + DAILY 文件內容非 stub
🛠️ 快速診斷指令

launchctl list | grep com.pai — 看所有 PAI 排程是否載入
