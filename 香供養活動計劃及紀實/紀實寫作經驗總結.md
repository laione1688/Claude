# 紀實寫作經驗總結

> 來源：1150304 五路財神＋1150305 竹林山觀音寺，兩篇紀實的實戰累積

---

## 一、香供養儀式流程（每場通用）

| 步驟 | 內容 | 注意事項 |
|------|------|----------|
| ① 稟報 | 向主神稟報供養目的、名單、供品數量，請神明派兵馬監查 | 每場都一樣，不能省 |
| ② 整理供養品 | 名條與疏文逐一對照，**同時拍攝紀錄照** | 不是「先確認完再拍」，是一邊對一邊拍 |
| ③ 擺設 | 供花、五果與香品擺設完成 | — |
| ④ 誦讀疏文 | 主祭者誦讀總疏文，每位供養人的名字被唸出來 | 還願唸的是感謝，祈願唸的是願望 |
| ⑤ 擲杯 | 確認**何時**可以焚化 | 不是確認「可不可以」，是確認「什麼時候」 |
| ⑥ 等待＋焚化 | 等到神明同意的時間到，才把文疏送入金爐 | 神明認真看待每次供養，需要時間審閱 |
| ⑦ 圓滿杯 | 回主殿請示圓滿杯 | — |
| ⑧ 感謝狀 | 廟方開立感謝狀 | 是**廟方**開的，不是我們的東西 |

## 二、紀實文章標準格式（10 元素）

1. YAML frontmatter（title、date、keywords、description）
2. H1 創意主標＋日期尾碼
3. H2 農曆日期副標
4. emoji 段落標題（📿🕯️✨💝 等）
5. 📷 照片佔位符
6. 🌿 下一棒預告（含日期、地點、收單截止、報名連結）
7. 🙏 感恩段落
8. 📸 照片回傳通知
9. 📋 功德芳名錄
10. closing tagline（明心福旺閣…）

---

## 三、寫作原則

- **不替神明說話**：不寫「神明告訴我們」「菩薩說」，用中性語言描述擲杯過程
- **還願 vs 祈願**：語氣不同——還願是「謝謝您，我收到了」，祈願是「請幫幫我」
- **不只還願也有月供養**：描述圓滿時要涵蓋兩種供養人
- **配圖文案是獨立的**：圓滿杯、感謝狀的配圖文案（主標＋百字內文）不放在紀實文章裡
- **紀實歸紀實，行銷歸行銷**：結尾的標準段落（下一棒/感恩/照片通知/芳名錄/closing）是格式的一部分，不能砍
- **感謝狀是廟方開立的**：不是我們做的

## 四、編輯紀律

| 錯誤 | 正確做法 |
|------|----------|
| 編輯建議說「某三段太行銷」，把整個結尾都砍了 | 精確解讀範圍——建議點名哪段就只動哪段，不擴大 |
| 用戶說「這個很好不要動」，理解成「這個建議很好」就動了 | 「不要動」= 不要動，沒有第二種解釋 |
| 把配圖文案塞進紀實文章裡 | 配圖文案是獨立產物，不是文章的一部分 |
| 寫「確認完畢，開始拍照」分成兩步 | 確認和拍照是同步進行的 |
| 寫「文疏送入金爐」像馬上就燒 | 要寫「等待神明同意的時間到」才送入 |
| 感謝狀文案寫成「我們的」角度 | 感謝狀是廟方開立的 |
