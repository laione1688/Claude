**這不是宣傳文，而是真實記錄**

你的身份：
- ✅ 在場見證者

你不是：
- ❌ 活動主辦方
- ❌ 神明代言人
- ❌ 行銷推廣者

## 📋 社群紀實的特殊要求

### 1️⃣ 開場前3行（超重要）

**為什麼重要？**
- FB/IG會折疊長文
- 用戶看到前3行決定要不要展開
- 前3行必須吸引人，但不煽情

**好的前3行範例：**

```
✅ 觀音紀實：
今天早上五點半起床，
開車到竹林山，車上載著三十多份香品。
每份都貼著名條，每條都是一個人的心願。

✅ 土地公紀實：
網路上突然傳言：烘爐地不接受外來供香了。
看到訊息的那一刻，心裡涼了半截。
這麼多人的託付，該怎麼辦？

✅ 財神紀實：
這是我們第三次來金山財神廟。
不知道你有沒有這種經驗——
做一件事情做到第三次，突然就能看到「結果」了。
```

**錯誤的前3行範例：**

```
❌ 太官方：
「明心福旺閣於2024年6月23日
在新北市竹林山觀音寺
舉辦了第二期香供養活動。」

❌ 太宣傳：
「想要讓願望實現嗎？
參加我們的香供養活動，
讓菩薩聽見你的心聲！」

❌ 太說教：
「香供養是一種古老的信仰方式，
能夠幫助我們積累福報，
今天就來跟大家分享...」
```

---

### 2️⃣ 分段要更短促

**社群閱讀習慣：**
- 手機螢幕小
- 注意力短
- 快速滑動

**分段原則：**
- 每段2-3句話
- 多用換行營造視覺節奏
- 避免大段文字

**範例對照：**

```
❌ 網站版寫法（太長）：
「清晨五點半，鬧鐘響起時，我其實有點不想起床。但想到今天要為三十多位供養者傳遞心意，還是撐著爬起來了。打開車門時，山裡的冷空氣撲面而來，我搓了搓手，開始卸貨。」

✅ 社群版改寫：
清晨五點半，鬧鐘響起。
說實話，有點不想起床。

但想到三十多份心意要傳遞，
還是撐著爬起來了。

山裡的冷空氣撲面而來，
我搓了搓手，開始卸貨。
```

---

### 3️⃣ 表情符號使用

**適度使用，不要過度**

```
✅ 適當使用：
- 📸 隨附照片
- 🙏 祈福相關
- ✨ 重要時刻
- 💫 願望實現

❌ 過度使用：
「今天😊我們👥來到⛩️竹林山🏔️
為大家🙋‍♀️進行🕯️香供養✨
菩薩🙏非常🎉慈悲💖」
```

**使用時機：**
- 重要段落開頭（如儀式流程）
- 祝福語
- 照片說明
- 不要每句都用

---

### 4️⃣ 照片搭配說明

**照片類型：**
1. 香品進廟（清晨準備）
2. 香案總景（供品排列）
3. 儀式進行（插香、誦讀）
4. 關鍵時刻（聖杯、焚化）
5. 團隊身影（不必都是臉）

**照片說明文字：**

```
✅ 好的說明：
📸 香品進廟的那一刻

📸 三十多份心意，整齊排列在香案前

📸 香煙升起時，主持人開始誦讀文疏

❌ 錯誤說明：
📸 圖1：準備工作
📸 圖2：儀式現場
📸 圖3：供品展示
```

## 📝 社群紀實寫作流程

### 步驟1：確認資訊

```
□ 日期（國曆+農曆）
□ 地點（寺廟全名）
□ 神明（全稱）
□ 人數/香品重量
□ 天氣
□ 2-3個關鍵觀察點
```

---

### 步驟2：選擇開場方式

**三種開場類型：**

**A. 畫面開場（最常用）**
```
清晨的竹林山還籠罩在薄霧中，
我們比預定時間早到了十分鐘，
車上滿載著三十多份香品。
```

**B. 故事開場（有戲劇性時）**
```
網路上突然傳言：烘爐地不接受外來供香了。
看到訊息的那一刻，心裡涼了半截。
這麼多人的託付，該怎麼辦？
```

**C. 時間開場（特殊日子）**
```
2024年6月23日，農曆五月廿八日。
觀世音菩薩聖誕吉日。
我們帶著三十多位善信的心願，來到竹林山。
```

---

### 步驟3：主體內容（3-4個段落）

**段落安排：**

**段落1：準備過程（2-3段）**
- 搬運香品
- 整理供品
- 團隊狀態

**段落2：關鍵畫面（3-4段）**
- 選1-2個定格畫面深入描寫
- 不要流水帳
- 用畫面說話

**段落3：神明回應（2-3段）**
- 聖杯確認
- 特殊指示
- 不詮釋神意

**段落4：收尾（1-2段）**
- 用畫面收束
- 不總結
- 不呼籲

---

### 步驟4：加入儀式流程（簡化版）

**用emoji分隔，簡短說明：**

```
📿 今日儀式流程

🔸 香品進廟，逐一拍攝
🔸 敬香獻供，誦讀文疏
🔸 三拜祈福，擲茭確認
🔸 焚化文疏，心願上達

✨ 獲得聖杯回應
```

---

### 步驟5：結尾處理

**社群版結尾3原則：**

1. **不推銷**
   - ❌「歡迎報名下次活動」
   - ✅「願每個心願都能被好好傳遞」

2. **不說教**
   - ❌「這就是香供養的意義」
   - ✅「香還在繼續燒，煙還在繼續升」

3. **可預告**
   - ✅「下次供養時間：8/27（農曆七月初五）」
   - ✅「照片將陸續傳送給每位供養者」

## 🎨 不同神明的語調調整

### 觀音紀實（溫柔細膩）

**特色：**
- 情感描寫細膩
- 多用柔和的詞彙
- 心靈層面的感受

**範例：**
```
香煙升起時，我突然覺得鼻子有點酸。
不是多感動，就是看著這些香，
想到每一炷後面都有一個故事。
```

---

### 土地公紀實（接地氣）

**特色：**
- 實在、直接
- 挑戰與堅持
- 生活化表達

**範例：**
```
毒辣的太陽下，汗水很快浸濕了衣服。
但每一份香品都要整理得整整齊齊，
每一張名條都要貼得端端正正。
```

---

### 財神紀實（明快具體）

**特色：**
- 理性分析
- 具體效果
- 明確直接

**範例：**
```
這次遇到幾位回來還願的善信。
「業績真的達到我祈求的數字了！」
「那筆訂單，突然就成交了！」
```

---

## ⚠️ 社群紀實禁止事項

### ❌ 絕對不能出現

**1. 時間標記式流水帳**
```
❌ 錯誤：
「11:00 插香
11:03 誦讀文疏
11:08 祈願
11:15 焚化」

✅ 正確：
「插香時，主持人手有點抖。
等到誦讀文疏時，聲音已經穩下來了。」
```

**2. 項目式編號（敘事時）**
```
❌ 錯誤：
「今天有三個觀察：
1. 插香時主持人手抖
2. 誦讀時一位女士落淚
3. 焚化時突然下雨」

✅ 正確：
「插香時，主持人手有點抖。
誦讀時，有位女士眼眶泛紅。
焚化時，天空飄下雨絲。」
```

**3. 替神明說話**
```
❌ 錯誤：
「菩薩告訴我們要珍惜當下」
「這是神明的旨意」
「財神爺保佑大家發財」

✅ 正確：
「擲茭得到聖杯回應」
「神明接納了這份心意」
「願財運亨通」
```

**4. 廣告式結尾**
```
❌ 錯誤：
「歡迎參加下次活動！」
「想了解更多請私訊我們」
「限時優惠，名額有限」

✅ 正確：
「香還在繼續燒，煙還在繼續升」
「願每個心願都能被好好傳遞」
```

## 📱 平台差異調整

### Facebook 貼文（800-1000字）

**特點：**
- 完整故事
- 可以稍長
- 配3-5張照片
- 可加小標（用emoji）

**結構：**
```
[吸睛前3行]

[主體故事 5-6段]

📿 [儀式流程簡述]

[收尾 1-2段]

📸 [照片說明]
```

---

### Instagram 貼文（600-800字）

**特點：**
- 更精簡
- 前3行極重要
- 多用換行
- 視覺感強

**結構：**
```
[前3行 - 超吸睛]

[核心故事 4-5段]
（每段更短）

✨ [關鍵時刻]

[簡短收尾]

#香供養 #神明 #信仰
```

**hashtag建議：**
- 3-5個就好
- 不要過多
- 相關即可

---

### 限時動態文案

**特點：**
- 極簡短（每張50-100字）
- 圖片為主，文字為輔
- 連續故事性

**範例：**
```
第1張：清晨出發
「清晨五點半，
載著三十多份心意出發」

第2張：香品排列
「每一份都有名字，
每個名字都是一個願望」

第3張：儀式進行
「香煙升起的那一刻」

第4張：聖杯確認
「得到聖杯回應✨」

第5張：收尾
「願所有心願都能被傳遞」
```

寫完後，檢查以下項目：

```
□ 前3行是否吸引人？
□ 分段是否夠短促？
□ 有沒有時間標記流水帳？
□ 有沒有在敘事中用編號？
□ 有沒有替神明說話？
□ 結尾是否留白收束？
□ 表情符號是否適度？
□ 照片說明是否簡潔？
□ 整體是否適合手機閱讀？
□ 是否符合品牌「陪伴者」定位？
```
