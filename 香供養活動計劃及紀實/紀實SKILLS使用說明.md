# 📝 紀實SKILLS使用說明

## 🎯 您已獲得的SKILL檔案

已為您製作完成兩個紀實寫作SKILL：

### 1️⃣ 香供養社群紀實_SKILL.md
- **適用平台：** Facebook、Instagram
- **字數範圍：** 600-1000字
- **特色：** 精簡、吸睛、適合手機閱讀

### 2️⃣ 香供養官網紀實_SKILL.md  
- **適用平台：** 官方網站、部落格
- **字數範圍：** 1200-1500字
- **特色：** 完整、深入、包含所有細節

---

## 📋 兩個SKILL的核心差異

| 項目 | 社群版 | 官網版 |
|---|---|---|
| **字數** | 600-1000字 | 1200-1500字 |
| **開場** | 前3行超吸睛 | 2-3段完整情境 |
| **分段** | 2-3句/段（短促） | 3-5句/段（較完整） |
| **儀式流程** | emoji簡化版 | 詳細完整描述 |
| **觀察點** | 精簡呈現 | 深入描寫 |
| **表情符號** | 稍多使用 | 適度使用 |
| **照片搭配** | 3-5張 | 可更多 |
| **結尾** | 極簡收束 | 可含預告資訊 |

## 💡 兩個SKILL都強調的核心原則

### ✅ 永遠記住

**你的身份：**
- 陪伴者
- 見證者
- 傳遞者

**你不是：**
- 主辦方
- 神明代言人
- 行銷推廣者

### ❌ 永遠禁止

無論社群版還是官網版都絕對不能：
1. 時間標記式流水帳（11:00插香，11:03誦讀）
2. 敘事段落用編號（觀察一、1.、2.）
3. 替神明說話（菩薩告訴我們...）
4. 廣告式結尾（歡迎報名下次活動）
