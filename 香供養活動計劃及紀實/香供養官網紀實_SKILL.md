# 香供養官網紀實 SKILL

## 🌐 適用平台
- 官方網站文章
- 部落格長文
- 完整記錄版本

---

## 🎯 核心定位

**這是完整的活動記錄，不只是故事**

你的身份：
- ✅ 完整見證者
- ✅ 詳細記錄者
- ✅ 陪伴傳遞者

你不是：
- ❌ 活動主辦方
- ❌ 神明代言人  
- ❌ 行銷推廣者
- ❌ 宗教詮釋者

## 📋 官網紀實的特殊要求

### 1️⃣ 字數與篇幅

**標準字數：1200-1500字**
- 比社群版更完整
- 包含更多細節
- 保留完整儀式流程
- 可以有更深入的描寫

**分段原則：**
- 每段3-5句話（比社群版略長）
- 適合電腦螢幕閱讀
- 保持段落間的節奏

---

### 2️⃣ 結構完整性

**官網版必須包含：**

```
1. 【情境開場】2-3段
   - 時間、地點、天氣
   - 團隊出發狀態
   - 初始情境設定

2. 【準備過程】2-4段
   - 搬運香品細節
   - 整理供品過程
   - 團隊分工描寫
   - 內在壓力或期待

3. 【儀式進行】4-6段
   - 選2-3個定格畫面深入描寫
   - 完整儀式流程說明
   - 關鍵時刻描寫

4. 【觀察點深化】3-5段
   - 把觀察點轉化為故事（畫面式）或反思（思辨式）
   - 人的狀態與選擇
   - 困境如何被走過

4b.【感謝與人的記錄】（如有）
   - 當感謝對象不只一個時，可各自獨立成段
   - 每段有自己的畫面和節奏
   - 用標題點出核心意象（如「一張桌子的重量」「金爐旁的身影」）
   - 用畫面和感受收束，而非條列感謝

5. 【神明回應】2-3段
   - 聖杯確認過程
   - 特殊指示（如有）
   - 不詮釋神意

6. 【收尾留白】1-2段
   - 用畫面收束
   - 不總結不升華
   - 不呼籲不CTA
```

### 3️⃣ 開場方式

**官網版可以用更完整的開場：**

**方式A：時間+地點+天氣（最常用）**
```
2024年6月23日，農曆五月廿八日。
清晨的竹林山還籠罩在薄霧中，
我們比預定時間早到了十分鐘，
車上滿載著三十多份香品，
每一份都貼著供養者的名條。

打開車門時，山裡的冷空氣撲面而來，
我搓了搓手，開始卸貨。
```

**方式B：戲劇性開場（有故事時）**
```
「烘爐地福德宮不接受外來供香了！」

周末的晚上，這則訊息在網路上瘋傳。
看到的那一刻，心中彷彿被雷劈中。
這麼多善信的託付，這麼多人的期待，
如果因為這個消息而無法進行，
我們該如何面對大家的信任？
```

**方式C：意義引入（特殊主題）**
```
這是我們第三次來金山財神廟。

不知道你有沒有這種經驗——
做一件事情做到第三次，
突然就能看到「結果」了。

前兩次，我們認真地為大家供香、拍照、祈福，
心裡想著：不知道財神爺有沒有聽到大家的願望？

這次，我們終於看到了——
開始有人回來還願了。
```

### 4️⃣ 儀式流程描寫（官網版必含）

**兩種呈現方式可選：**

**方式A：模板格式（清楚、有結構感）**
- 用標題分隔每個環節
- 適合流程較多、需要條理的場次

**方式B：敘事格式（自然、融入文章節奏）**
- 用段落串起流程，不使用emoji標記
- 每個環節之間用敘事銜接
- 適合觀察點和感受較多、流程本身不是重點的場次
- 可以在流程中穿插當下的感受或畫面

**完整但不冗長（以下為方式A範例）：**

```
📿 今日儀式完整流程

【香品進廟】
清晨時分，我們將所有香品小心翼翼地運入殿內。
每一包香品都貼上供養者的姓名敬獻條，
準備供花、五果，莊嚴擺設香案。

【個人供養品拍攝】
在[天氣描述]下，我們逐一為每位供養者的香品拍攝紀錄照片。
確保每張照片都包含個人名條與神聖背景。

【敬香獻供】

豐收滿載福臨門。

【恭讀文疏】

一個個名字從口中念出，
就像在為每個人向[神明]介紹：
「[尊稱]啊，這個人帶著這樣的心意，
來到了您的面前。」

【三拜祈福】（如有）
我們延續傳統，進行莊嚴的三拜祈福：

第一拜｜[第一個祈願類別]
[祈福詞內容]

[祈福詞內容]
三拜！

【擲茭確認】
向[神明]擲茭確認，
杯落地的那一聲清響——是聖杯！

那一刻，所有的辛苦都值得了。
我們知道，[神明]聽見了每一份虔誠，
也接納了每一個心願。✨

【焚化文疏】
將總疏文虔敬焚化，
看著文字在火中化為煙霧，緩緩上升。

這張感謝狀，代表著：
- 廟方對這次香供養活動的認可
- 眾善信誠心參與的見證  
- 這段供養過程的真實性與莊嚴性
```

### 5️⃣ 觀察點深化（官網版核心）

**官網版可以更深入描寫觀察點：**

⚠️ **重要：觀察點編號只存在於素材區，正文中絕對不能出現編號！**

**轉化方式：**

```
素材區觀察點：
【觀察點1】
今天有位供養者是為重病的母親祈福

❌ 錯誤轉化（直接陳述+詮釋）：
「觀察點1：有位供養者為重病母親祈福。
我相信觀音菩薩一定會保佑她母親康復。」

✅ 正確轉化（畫面+行為+情感）：
「整理香品時看到一張祈願卡，
上面寫著『願母親平安』，
字跡工整但紙上有點皺，
可能是寫的時候手有點抖。

插香時我特別小心，
怕弄壞了這份為母親的心意。」
```

**深化原則：**
1. 把「事件」→ 轉成「人在當下的狀態」
2. 把「情緒」→ 放進「行為與選擇」裡
3. 把「困境」→ 寫成「沒有被解決、但被走完」

**轉化方式B：思辨式（從場景引發提問與反思）**

```
適用時機：
- 觀察點不是一個「畫面」，而是一個「感悟」
- 想表達的不是情感，而是一層理解
- 特別適合地藏王菩薩等具有深層悲願的神明

素材區觀察點：
【觀察點】
看到香牆，地藏王菩薩不缺香，
但祂卻多次引導我們來供養

❌ 錯誤轉化（直接下結論）：
「地藏王菩薩不缺香，祂要的是認識你們每一個人。
祂主動來找你們，這就是祂的疼愛。」

✅ 正確轉化（提問+留白，讓讀者自己感受）：
「站在那裡時，心裡反而冒出一個很清楚的念頭——
祂並不缺香。

那這樣的供養，究竟是在做什麼？

如果祂什麼都不缺，卻一再引導我們走到這裡——
那祂真正想要的是什麼？

站在殿前，答案其實並不複雜。」

思辨式原則：
1. 從場景出發，帶出一個疑問
2. 不急著給答案，讓問題停留一下
3. 如果要給方向，用「感受」而非「結論」
4. 結尾留白，讓讀者自己體會
```

### 6️⃣ 不同神明的深度調整

**觀音紀實（心靈層面）**

```
特色：
- 更多內在感受描寫
- 溫柔細膩的情感流動
- 心靈撫慰的氛圍

範例段落：
「誦讀文疏時，
我看到一位女士眼眶泛紅，
但她沒有哭出來，
只是深深吸了口氣，
然後很慢很慢地把三炷香插進香爐。

那個動作很輕，很輕，
像是怕驚擾了什麼，
又像是要把所有的心意，
都放進這個動作裡。」
```

---

**土地公紀實（生活挑戰）**

```
特色：
- 強調考驗與堅持
- 實際困難的描寫
- 在挑戰中的成長

範例段落：
「毒辣的太陽下，
我們開始了今天最重要的工作——
為每一位供養者整理專屬的香品。

汗水很快就浸濕了衣服，
但我們不敢有絲毫馬虎。
每一份香品都要整理得整整齊齊，
每一張名條都要貼得端端正正。

『這一份，是王先生的心意...』
『這一份，是陳小姐為家人健康的祈願...』

在烈日下，我們一份份地擺設，
一個個地稟報。
汗珠滴在地面上，
但心中滿懷著對每位託付者的敬重。」
```

---

**財神紀實（理性分析）**

```
特色：
- 理性觀察與分析
- 具體效果的記錄
- 明確的因果關係

範例段落：
「這次遇到幾位回來還願的善信，
他們分享的內容都很具體：

『上個月業績真的達到我祈求的數字了！』
『那筆談了很久的訂單，突然就成交了！』
『專案卡關很久，突然有了突破！』

聽著聽著，我們突然明白了一件事：

為什麼五路財神的靈驗特別容易被『感受到』？

因為財運的願望，往往很具體。
你不會只是說『希望財運好』，
你會說『希望這個月業績達到50萬』、
『希望這筆訂單能簽下來』。

所以當願望實現時，
你會清清楚楚知道——
這不是巧合，是財神爺真的幫忙了。」
```

---

**地藏王菩薩紀實（沉穩思辨）**

```
特色：
- 沉穩、留白多，不急著給答案
- 拋出問題讓讀者自己體會
- 悲願感（不同於觀音的慈悲感）
- 語調比觀音更重、比土地公更深
- 會從一個場景引發一連串反思

核心語感：
- 觀音是「溫柔地接住你」
- 地藏王是「安靜地站在那裡，等你自己走過來」
- 不解釋、不催促，把空間留給讀者

範例段落：
「站在那裡時，心裡反而冒出一個很清楚的念頭——
祂並不缺香。

那這樣的供養，究竟是在做什麼？

想了很久，慢慢有了一個感受——
如果祂什麼都不缺，卻一再引導我們走到這裡，
那祂真正想要的是什麼？

站在殿前，答案其實並不複雜。

『地獄不空，誓不成佛。』

不是為了自己，
也不是為了形式。

是希望每個人都能好好地走在各自的路上，
願意承接、願意面對，也願意不逃避。」

禁忌寫法：
- ❌ 不要寫成陰沉或恐怖（地藏王不等於地獄）
- ❌ 不要過度強調因果報應
- ❌ 不要替菩薩下結論（如「祂要的是認識你們每一個人」）
- ✅ 用提問代替結論，讓讀者自己感受
- ✅ 可以引用「地獄不空，誓不成佛」但不要過度詮釋
```

## 📝 官網紀實寫作流程

### 步驟1：收集完整素材

```
基本資訊：
□ 日期（國曆+農曆）
□ 時間（出發、到達、儀式開始）
□ 地點（寺廟全名+地理特徵）
□ 神明（全稱）
□ 規模（人數、香品重量）
□ 天氣（真實描述）

活動資料：
□ 流程稿檔案名稱
□ 主持人稿（如有）
□ 疏文內容
□ 照片清單

觀察記錄：
□ 觀察點3-5個
□ 每個觀察點要有具體畫面
□ 記錄當下的狀態和選擇

神明回應：
□ 聖杯過程
□ 特殊指示（如有）
□ 擲茭細節
```

---

### 步驟2：規劃文章結構

**用這個模板：**

```
第一部分：開場情境（200-300字）
- 2-3段
- 時間地點天氣
- 團隊狀態
- 初始情境

第二部分：準備過程（200-300字）
- 2-4段
- 搬運香品
- 整理供品
- 內在感受

第三部分：儀式進行（400-500字）
- 4-6段
- 完整流程描述
- 2-3個定格畫面深入描寫

第四部分：觀察點深化（300-400字）
- 3-5段
- 觀察點轉為故事
- 人的狀態與選擇

第五部分：神明回應（150-200字）
- 2-3段
- 聖杯過程
- 特殊指示

第六部分：收尾留白（100-150字）
- 1-2段
- 畫面收束
- 不總結不呼籲

總計：1350-1850字
調整至：1200-1500字
```

---

### 步驟3：撰寫各部分

**開場範例（觀音）：**

```
2024年6月23日，農曆五月廿八日，正值觀世音菩薩聖誕吉日。

清晨的竹林山還籠罩在薄霧中，
我們比預定時間早到了十分鐘。
車上滿載著三十多份香品，
每一份都貼著供養者的名條，
每一條名條背後，都是一個人的心願。

打開車門時，山裡的冷空氣撲面而來。
我搓了搓手，深吸一口氣，
開始卸貨。

今天的天氣預報說，下雨機率100%。
我們都在擔心儀式要如何進行。
```

---

**準備過程範例（土地公）：**

```
搬運香品的過程中，
每一份都要小心翼翼。
三十多份香品，重量不輕，
從車上搬到殿內，來回好幾趟。

開始整理供品時，
看到每一張名條上的字跡：
有的工整，有的潦草，
有的寫得很多，有的只寫了幾個字。

「王先生，生意興隆」
「陳小姐，家人健康」
「李太太，子女平安」

每一份心意都不一樣，
但都同樣真誠。

我們開始為每位供養者拍照，
確保每張照片都清楚呈現：
香品、名條、文疏、神明背景。

這是最花時間的工作，
但我們覺得最重要。
```

---

**儀式進行範例（財神）：**

```
上午時分，我們開始進行供養儀式。

依序插香、擺設供品、獻上鮮花水果，
然後恭讀《五路財神香供養敬告文疏》，
將每一份心意，安靜而完整地呈上。

插香時，
三十幾炷香同時點燃，
煙霧瞬間瀰漫整個香案。

主持人深吸了一口氣，
開始誦讀文疏。

那些文言文的字句，
被念得很清楚、很慢，
每個名字都被認真地唸出來，
像是在為每個人向財神爺介紹：
「元帥啊，這個人帶著這樣的心意，來到了您的面前。」

誦讀完畢，
將文疏焚化，
看著火光與煙霧升起。

那一刻，彷彿所有的願望，
都隨著煙霧，送到了天上。
```

**觀察點深化範例（觀音）：**

```
整理香品時，
我注意到一張祈願卡。

上面寫著「願母親平安」，
字跡工整，但紙上有點皺，
可能是寫的時候手有點抖。

插香時我特別小心，
怕弄壞了。

不知道那位母親現在怎麼樣了，
不知道寫這張卡的人此刻在哪裡。

但我知道，
這份為母親的心意，
已經被好好地傳遞出去了。

---

誦讀文疏時，
我看到一位女士站在旁邊，
跟著我們的節奏合掌、低頭、再合掌。

動作很慢很慢，
每個姿勢都停留很久，
像是要把每個動作都做到位才安心。

```

```
11:08 進行三拜祈福
```

## 🎯 品質自我檢查

寫完官網紀實後，必須通過以下檢查：

### 五大檢查問題

```
□ 1. 拿掉神明名字，文章還成立嗎？
   （如果不成立 = 在依賴神明撐場面）

□ 2. 這篇是在記錄「人」，還是在解釋「信仰」？
   （如果在解釋信仰 = 變成老師不是見證者）

□ 3. 有沒有一句話，其實是在幫神明說話？
   （如果有 = 立刻刪除改寫）

□ 4. 敘事段落是否出現編號／條列？
   （如果有 = 改為自然敘事）

□ 5. 結尾會不會讓人想報名或了解更多？
   （如果會 = 重寫結尾）
```

### 內容完整性檢查

```
□ 基本資訊齊全（時間、地點、神明、規模）
□ 開場情境清楚（天氣、團隊狀態）
□ 準備過程描寫（搬運、整理）
□ 完整儀式流程（含獻花獻果詞）
□ 2-3個定格畫面深入描寫
□ 觀察點已轉化為故事
□ 神明回應記錄（聖杯、指示）
□ 收尾留白適當
```

### 語言風格檢查

