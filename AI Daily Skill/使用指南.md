## 📋 文件名格式

### 新的日期格式（当前配置）

- **格式**：`YYYY-MM-DD_AI日报.md`
- **示例**：`2026-01-23_AI日报.md`
- **特性**：
  - ✅ 追加新内容时，文件名自动更新为最新日期
  - ✅ 便于按日期排序和搜索
  - ✅ 文件名直观显示最新更新时间

### 文件名更新机制

```
第1天（1月23日）运行:
→ 创建: 2026-01-23_AI日报.md

第2天（1月24日）运行:
→ 自动重命名: 2026-01-23_AI日报.md → 2026-01-24_AI日报.md
→ 新内容追加到文件末尾
→ 文件包含两天的内容

第3天（1月25日）运行:
→ 自动重命名: 2026-01-24_AI日报.md → 2026-01-25_AI日报.md
→ 文件包含三天的内容
```

## 🔧 两种使用模式

### 模式 1：追加模式（默认，推荐）

所有资讯追加到同一个文件，文件名自动更新为最新日期。

```bash
./sync_to_obsidian.sh news_day1.json
./sync_to_obsidian.sh news_day2.json
./sync_to_obsidian.sh news_day3.json

# 结果：1个文件包含3天的内容
# 文件名：2026-01-25_AI日报.md（最新日期）
```

**适合场景**：
- 日常持续更新
- 需要查看完整历史
- 避免文件过多

### 模式 2：独立文件模式

每天创建独立的文件。

```bash
./sync_to_obsidian.sh news_day1.json daily
./sync_to_obsidian.sh news_day2.json daily
./sync_to_obsidian.sh news_day3.json daily

# 结果：3个独立文件
# - 2026-01-23_AI日报.md
# - 2026-01-24_AI日报.md
# - 2026-01-25_AI日报.md
```

**适合场景**：
- 需要按日期归档
- 每天内容较多
- 需要单独分享某天的资讯

## 💡 实用技巧

### 1. 快速查找

在 Obsidian 中：
- 按 `Cmd+O` 打开快速切换器
- 输入日期（如 `2026-01-23`）
- 快速跳转到对应文件

### 2. 标签搜索

在搜索栏输入：
- `tag:#模型发布` - 查找特定分类
- `tag:#Claude` - 查找特定标签
- `tag:#技术更新 path:"AI 資訊周報"` - 在指定路径搜索

### 3. 创建索引页

在 Obsidian 中创建 `AI资讯索引.md`：

```markdown

## 📅 最新

## 🏷️ 热门标签
- #模型发布
- #技术更新

## 📊 统计
使用 Dataview 插件查询统计信息
```

## ❓ 常见问题

### Q1: 如何修改文件名格式？

编辑 `convert_to_obsidian.py` 中的 `get_date_filename()` 函数。

### Q2: 可以关闭自动重命名吗？

可以。修改 Python 脚本初始化时设置 `use_date_filename=False`。

### Q3: 同一天多次运行会怎样？

会追加到当天的文件中，不会重命名（因为日期相同）。

### Q4: 如何导出为 PDF？

在 Obsidian 中使用 `Cmd+P` → "Export to PDF"。
