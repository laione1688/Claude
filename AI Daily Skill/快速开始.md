## ❓ 常见问题

### Q1: 文件没有出现在 Obsidian 中？

**解决方案**:
1. 检查 Obsidian 是否打开了正确的仓库
2. 在 Obsidian 中按 `Cmd+P`，输入 "打开保险库"
3. 选择 `/Users/laichaochang/obsidian/AI 資訊周報`

### Q2: 如何避免重复内容？

**解决方案**:
- 使用 `daily` 模式，每天创建新文件
- 或者在准备 JSON 数据时做好去重

### Q3: 可以批量转换多个 JSON 文件吗？

**解决方案**:
```bash
# 转换所有 JSON 文件
for file in *.json; do
    ./sync_to_obsidian.sh "$file" daily
done
```

### Q4: 如何从 CSV 或其他格式转换？

**解决方案**: 先转换为 JSON 格式，可以使用 Python 脚本：

```python
import pandas as pd
import json

# 读取 CSV
df = pd.read_csv('news.csv')

# 转换为 JSON 格式
data = {
    "date": "2026-01-23",
    "news": df.to_dict('records')
}

with open('output.json', 'w', encoding='utf-8') as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
```
