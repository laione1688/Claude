# 🚀 开始使用

## 最简单的 3 步

### 1️⃣ 准备数据

创建 JSON 文件（参考 `sample_data.json`）：

```json
{
  "date": "2026-01-23",
  "news": [
    {
      "title": "新闻标题",
      "url": "https://...",
      "summary": "摘要",
      "category": "分类",
      "tags": ["标签"],
      "source": "来源"
    }
  ]
}
```

### 2️⃣ 运行脚本

```bash
./sync_to_obsidian.sh your_data.json
```

### 3️⃣ 在 Obsidian 查看

打开：`AI 資訊周報` 仓库

## 💡 核心特性

1. **日期文件名**：`2026-01-23_AI日报.md`
2. **自动更新**：追加新内容时自动重命名为最新日期
3. **Obsidian 标签**：`#分类` `#标签` 自动生成
4. **两种模式**：追加模式 / 独立文件模式

---

## 🎯 快速命令

```bash
# 追加模式（默认）
./sync_to_obsidian.sh data.json

# 独立文件模式
./sync_to_obsidian.sh data.json daily

# 查看帮助
./sync_to_obsidian.sh -h
```
