# 🎉 功能更新：文件名使用日期格式

## 更新内容

### ✨ 新功能

1. **文件名使用日期格式**
   - 新格式：`2026-01-23_AI日报.md`
   - 更直观，便于在 Obsidian 中浏览和搜索

2. **自动重命名功能**
   - 追加新内容时，文件会自动重命名为最新日期
   - 旧日期的内容会保留，只是文件名更新

3. **向后兼容**
   - Python 脚本支持 `use_date_filename` 参数控制是否使用日期文件名
   - 可根据需要切换回固定文件名模式

---

## 📝 工作原理

### 单文件追加模式（默认）

```
第一次运行（2026-01-23 的数据）:
→ 创建文件: 2026-01-23_AI日报.md

第二次运行（2026-01-24 的数据）:
→ 自动重命名: 2026-01-23_AI日报.md → 2026-01-24_AI日报.md
→ 追加新内容到重命名后的文件
→ 文件包含两天的内容，文件名显示最新日期
```

### 每日独立文件模式

```
./sync_to_obsidian.sh data1.json daily
→ 创建: 2026-01-23_AI日报.md

./sync_to_obsidian.sh data2.json daily
→ 创建: 2026-01-24_AI日报.md

结果：两个独立文件，互不影响
```

## 🚀 使用示例

### 示例 1：追加模式（推荐）

```bash
# Day 1: 添加第一天的资讯
./sync_to_obsidian.sh news_0123.json
# 结果：创建 2026-01-23_AI日报.md

# Day 2: 添加第二天的资讯
./sync_to_obsidian.sh news_0124.json
# 结果：重命名为 2026-01-24_AI日报.md，包含两天的内容

# Day 3: 继续添加
./sync_to_obsidian.sh news_0125.json
# 结果：重命名为 2026-01-25_AI日报.md，包含三天的内容
```

**优点**：
- ✅ 所有资讯在一个文件中，便于查看完整历史
- ✅ 文件名始终显示最新更新日期
- ✅ 避免文件过多

### 示例 2：独立文件模式

```bash
./sync_to_obsidian.sh news_0123.json daily
./sync_to_obsidian.sh news_0124.json daily
./sync_to_obsidian.sh news_0125.json daily

# 结果：3 个独立文件
# - 2026-01-23_AI日报.md
# - 2026-01-24_AI日报.md
# - 2026-01-25_AI日报.md
```

**优点**：
- ✅ 每天独立文件，便于按日期查找
- ✅ 适合长期归档
- ✅ 可以单独分享某一天的资讯

## 🔧 技术细节

### 自动重命名逻辑

```python
# 伪代码
if 使用日期文件名:
    新文件名 = f"{日期}_AI日报.md"

    if 存在旧的日期文件:
        读取旧文件内容
        写入新文件（包含旧内容 + 新内容）
        删除旧文件
        显示: "✅ 重命名并追加: 旧文件名 → 新文件名"
    else:
        创建新文件
        显示: "✅ 创建新文件: 文件名"
```

### 配置参数

在 Python 脚本中：
```python
converter = ObsidianConverter(
    use_date_filename=True  # 使用日期文件名
)
```

## 💡 使用建议

### 推荐用法

1. **日常更新**：使用追加模式
   ```bash
   ./sync_to_obsidian.sh today.json
   ```

2. **每周回顾**：使用独立文件模式
   ```bash

   ./sync_to_obsidian.sh week_summary.json daily
   ```

3. **月度归档**：手动整理
   - 在月底，将当前文件重命名为 `2026-01月_AI日报汇总.md`
   - 下个月开始使用新的日期文件

### Obsidian 工作流

1. **创建月度文件夹**
   ```
   AI 資訊周報/
     ├── 2026-01/
     │   └── 2026-01-24_AI日报.md
     └── 2026-02/
         └── 2026-02-01_AI日报.md
   ```

2. **使用标签查询**
   在 Obsidian 搜索：`tag:#模型发布 path:"AI 資訊周報"`

3. **创建每月索引**
   创建 `2026-01_索引.md`：
   ```markdown
   # 2026年1月 AI 资讯索引

   ## 日报
   - [[2026-01-24_AI日报]]

   ## 热门标签
   - #模型发布
   - #技术更新
   ```
