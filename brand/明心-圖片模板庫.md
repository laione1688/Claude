# 明心福旺閣 圖片創作靈感庫

> **版本**：v2.4（2026-04-25｜新增技法六：極簡公式 prompt + 技法七：中式 infographic 海報結構 + 候選詞擴充工筆畫 / 多風格並置 / study manga）
> **這是什麼**：廟宇民俗生圖的技法知識 + 詞語素材 + 例子展示
> **這不是什麼**：不是填空範本，不是每次必套的格式

**用法**：每次生圖前，先想「這張圖的情緒/意圖是什麼」，再來這裡找對的詞語組合。每張圖都應該是新的——這個庫是給你找靈感的材料庫，不是生產線。

---

## 技法一：分層思考（想不到怎麼描述時來這裡）

六個維度幫你想清楚要說什麼，不必每層都用，挑有用的：

**風格** — 這張圖的美學基底是什麼？
- 工筆彩繪（細膩、傳統、適合神明正像）
- 水墨淡彩（寫意、有呼吸感、適合空間/紀實）
- 新中式極簡（現代感、留白多、適合社群封面）
- 閩南木刻版畫（古樸、力道感、適合節慶/海報）
- 台灣廟宇海報風（金紅飽和、喜慶、適合宣傳）

**主體** — 畫面裡最重要的東西是什麼？
- 神明：坐像、法相、手持法器、神龕全景
- 場景：廟宇正殿、天井、廊道、山門、供桌
- 人物：信眾背影、師父側影、合十雙手（臉不清）
- 物件：香爐、燭火、供果、佛珠、疏文捲軸

**光線** — 光從哪裡來？氣氛如何？
- 暖黃燭光（靜謐、虔誠、廟宇夜晚）
- 晨光斜穿天井（空間感、有希望感）
- 夕陽金光打在屋瓦（懷舊、儀式結束感）
- 逆光青煙（神秘、仙氣）
- 燈籠暖光暈（節慶、喜悅）
- 戲劇性輪廓光（電影感、莊嚴神像）
- 柔和散射光 + 顆粒感（紀實感、有歲月痕跡）
- 逆光 + 光折射（有靈氣感，適合供品靜物）

**材質** — 什麼表面？什麼觸感？
- 木雕漆金（神像質感）
- 青石地磚、紅磚（閩南建築）
- 宣紙紙紋（水墨底）
- 絹布刺繡（廟宇旗幟）
- 鑄銅霧面（香爐）
- 供果水潤飽滿（靜物感）
- 老印刷品質感（復古廟宇海報、有歷史感）
- 油脂光澤（燭台、供品）
- 陶瓷質感（香爐、供碗）
- 發絲細節 / 布料纖維（人物特寫）

**構圖** — 畫面怎麼安排？
- 中軸對稱（正式、莊嚴、神像首選）
- 三分之一法則（活潑、視覺動線清楚）
- 下方留空（要疊標題時用）
- 景深散焦前景（紀實感、有層次）
- 大量留白（禪意、呼吸感）
- 45 度俯視角（供品靜物最自然）
- f/2.8 淺景深（聚焦主體，背景虛化）
- 85mm 鏡頭感（人像電影感，適合神明正像）
- 前景虛化 + 遠景神像（廟宇空間感）

**情感** — 看這張圖應該感受到什麼？
- 莊嚴有溫度（不冷也不親暱）
- 靜謐虔敬（個人祈禱時刻）
- 慈祥親切（媽祖婆風格）
- 圓滿喜悅（活動結束、感謝）
- 獨處時的寧靜（照見系）

## 技法二：精準大氣描述（少說多準）

> 來自 GPT-Image-2 實測核心心得：**不要堆疊形容詞，選一個主要情感詞就好**。

**錯誤示範**（形容詞堆疊）：
```
cinematic dramatic volumetric golden mystical ethereal divine atmospheric warm light
```

**正確示範**（一個主詞定調）：
```
warm candlelight  →  靜謐虔誠感
moody backlight   →  神秘仙氣感
soft morning haze →  希望開始感
```

**明心廟宇對應的一詞定調**：

| 情境 | 一個詞定調 | 感受 |
|------|-----------|------|
| 媽祖封面 | `benevolent` | 慈祥親切 |
| 香供養宣傳 | `sacred` | 神聖莊嚴 |
| 照見系禪意 | `meditative` | 冥想呼吸 |
| 廟宇紀實 | `timeless` | 歲月靜謐 |
| 節慶活動 | `festive` | 喜慶熱鬧 |
| 圓滿感謝 | `serene` | 平靜圓滿 |

## 技法三：否定指令（生出來不對時對症下藥）

遇到問題才加，不是每張圖都貼：

| 問題 | 加這句 |
|------|--------|
| 圖上出現英文/文字 | `no text, no watermark, no latin script` |
| 神明臉孔西化 | `no western facial features, East Asian deity physiognomy` |
| 神明表情恐怖 | `no fierce expression, benevolent deity face only` |
| 圖太滿、要疊字 | `leave lower third empty for text overlay` |
| 過度卡通、失去廟宇感 | `no cute cartoon style, maintain traditional aesthetic` |
| 背景太雜 | `simple background, no cluttered composition` |
| 出現現代元素（車/廣告） | `no modern vehicles, no commercial signage` |
| 人臉太清楚（紀實圖） | `no clear faces, back angle or silhouette only` |

## 技法四：Prompt 結構選擇（敘事 vs JSON）

> 同一張圖可以用兩種寫法，選對的就好。

**A. 敘事版**（段落式自然語言）— 適合大多數情況
- 講主體 → 講光線 → 講材質 → 講氛圍，像寫景物速寫
- 優點：AI 理解情緒，畫面有連貫氛圍
- 缺點：細節容易被忽略
- 用法：本模板庫所有現有例子都是敘事版

**B. JSON 結構版** — 適合元素多、要每項精確控制
- 拆成欄位寫，例如：`主題 / 場景 / 照明 / 風格 / 細節 / 技術 / 品質`
- 優點：每項清楚不漏；品質標籤可做獨立陣列（如 `[傑作, 極品, 非常詳細, 8K]`）
- 缺點：AI 可能損失情緒連貫性，生出來偏「規格說明書」
- 用法：複雜場面（多神明 + 多元素）、要精確控制每個器物時

**廟宇圖的結構選擇參考：**

| 圖類 | 建議結構 |
|------|---------|
| 神明正像、法相 | A 敘事（情緒優先） |
| 廟宇空間、紀實 | A 敘事（氛圍優先） |
| 供品靜物特寫 | A 或 B 都可 |
| 複雜場面（多神明 + 多元素 + 信眾） | B 結構化（細節優先） |
| 節慶老海報 | A 敘事 + 強復古品質標籤 |

**一個 JSON 結構骨架（供參考，不是必填）：**
```
{
  "主題": "...",
  "場景": "...",
  "照明": "...",
  "材質": "...",
  "構圖": "...",
  "風格": ["...", "..."],
  "細節": ["...", "..."],
  "技術": ["數位單眼 + 85mm 鏡頭"],
  "品質": ["傑作", "極品", "非常詳細", "8K"]
}
```

## 技法五：多層次結構化通用模板（要寫一次能反覆套用的 prompt 時用）

> 同一個模板，套不同神明、不同活動、不同場景都能跑 — 這個技法教你怎麼設計這種「通用模板」。

**5 層結構（缺一不可）：**

1. **任務句**（一句話）
   - `请为【XX】生成一张「YY 风格」的 ZZ 海报。`
   - 用 `【】` 作為變數槽位，套用時替換
   - 廟宇套用：`请为【XX 神明】生成一张「廟宇紀實風格」的香供養封面图。`

2. **條件分支**（如果...則...）
   - `如果我提供了參考圖：以參考圖為主，保留 [核心特徵]，沿用 [主色調]`
   - `如果我沒提供參考圖：根據【XX】自動生成 [屬性]，自動搭配 [配色]`
   - 廟宇套用：神像有官方法相要不要參考、廟宇空間有沒有實拍照可垫圖

3. **整體風格定調**（一段話，不是條列）
   - 講「這不是 X，也不是 Y，而是 Z」— 用反例排除幫 AI 對齊
   - 廟宇套用：`這不是普通商業海報，也不是觀光介紹圖，而是融合「神明法相 + 廟宇空間 + 信眾虔誠氛圍」的紀實感封面。`

4. **畫面要求**（條列具體要素）
   - 構圖、光線、材質、元素、版式
   - 用 `-` 列點，每點是一個獨立可評估的視覺指令

5. **配色原則 + 風格關鍵詞 + 末段反例排除**
   - 配色：講原則不講具體色（讓主題自決定）
   - 關鍵詞：3-8 個風格短語，用「、」分隔
   - **末段反例**（中文段落式，不同於技法三英文標籤）：`不要做成 X，不要 Y，不要 Z，不要 W`
   - 廟宇套用末段：`不要做成觀光宣傳照，不要過度修飾失去年代感，不要西方臉孔，不要恐怖威嚴的神情`

**何時用技法五 vs 技法二（精準大氣描述）？**

| 情境 | 用哪個 |
|------|-------|
| 一張圖、一次性、有強烈情緒 | 技法二（少說多準） |
| 同類圖要反覆生（每月活動海報、每篇文章配圖、12 神明系列） | **技法五**（通用模板） |
| 客製化每張、不需重用 | 技法二 |
| 要交給其他人/AI 反覆套用 | **技法五** |

**通用模板適合明心的場景：**
- 月度香供養活動封面（同結構、換神明/日期/廟）
- 神明系列文章配圖（媽祖／觀音／地藏／關公...同風格定調）
- 「神明創作指南」對應的視覺模板（每個神明一份指南配一個視覺模板）
- 活動 EDM / LINE@ 圖（每月同調性）

## 技法六：極簡公式 prompt（主題定調 + 概念槽位）

> 一句話 prompt 的極致版本 — **「文化關鍵詞 + 哲學概念」就能生對風格的圖**。
> 來源：寶玉（@dotey）的宋朝工筆畫 prompt — 短到不可思議，但效果精準。

**公式骨架：**
```
Paint a [文化/風格關鍵詞] painting that represents the artistic conception of "[哲學概念]". Add text and explanations.
```

**為什麼有效？**
- AI 已內化「Song Dynasty gongbi」「Ming Dynasty woodblock」這類**文化符號**的視覺語言
- 「artistic conception of X」（意境）是中式美學的核心概念，AI 會自動配對畫面
- 不寫構圖、不寫光線 — 讓 AI 用文化內建知識自由發揮，往往比硬指定更好

**明心廟宇套用版：**

| 神明 | 套用後 prompt |
|------|--------------|
| 媽祖 | `Paint a Song Dynasty gongbi painting that represents the artistic conception of "母親的慈悲與守護，海上明燈". Add text and explanations.` |
| 觀音 | `...the conception of "尋聲救苦,千手千眼,聞聲化現".` |
| 地藏 | `...the conception of "地獄不空,誓不成佛,大願堅固".` |
| 關公 | `...the conception of "義薄雲天,赤膽忠魂".` |
| 土地公 | `...the conception of "守護一方,有求必應的鄰家阿伯".` |

**可替換的「文化關鍵詞」清單（廟宇可用）：**
- `Song Dynasty gongbi painting`（宋朝工筆畫）— 最適神明正像
- `Ming Dynasty woodblock print`（明朝木刻版畫）— 適節慶海報
- `Tang Dynasty dunhuang mural`（唐朝敦煌壁畫）— 適觀音、佛教神明
- `Qing Dynasty paper cutting`（清朝剪紙）— 適社群封面、節慶
- `Taiwanese folk temple poster`（台灣廟宇海報）— 適活動宣傳
- `Min-nan ink wash`（閩南水墨）— 適廟宇空間紀實

**何時用技法六 vs 技法二/技法五？**
| 情境 | 用哪個 |
|------|-------|
| 信任 AI 的文化知識，極簡指令求驚喜 | **技法六**（極簡公式） |
| 要明確控制光線/構圖/材質 | 技法二（精準大氣描述） |
| 要做能反覆套用的活動模板 | 技法五（多層次結構化） |

## 技法七：中式 infographic 海報結構（儀式說明圖、神明文化教學圖）

> 對應明心場景：**香供養儀式說明圖、神明文化教學圖、活動流程說明海報**。
> 直接搬「中式營養海報」結構就能套。

**6 個版面元素（缺一不可）：**

1. **左上 headline 區**
   - 雙行中文標題：第一行黑色主標 + 第二行**大號暖紅色**副標（強對比）
   - 下方灰色 slogan（一句話定調）

2. **主視覺中心**
   - 真實質感的核心物件（神明法相 / 香爐 / 供品堆疊）
   - 商業攝影感、自然光、清晰焦點
   - 周圍可疊綠葉/花朵作新鮮感點綴

3. **右側圓形 callout 串**（4-5 個垂直排列）
   - 紅色或紅橙漸層圓圈，內含字母/圖標
   - 用紅色弧線（curved leader line）連接到主視覺
   - 每個 callout 配中文標題 + 解釋文字

4. **左側文字 callout**（2 個）
   - 紅色文字標題 + 細紅引線指向主視覺
   - 下方小灰字補充說明

5. **底部圓角營養表 / 數據條**
   - 白底 + 細灰分隔線
   - 左端紅色圓角標籤塊（含表標題）
   - 6 列數據（標題灰、數值深）
   - 中央小灰字註腳

6. **整體配色原則**
   - 留白主導（淺米白/灰白背景）
   - 紅色為**重點與引導**（headline / callout / leader line）
   - 灰色為**輔助文字**
   - 主視覺保留真實色彩

**明心套用：「[神明名] 香供養儀式說明圖」**

| 元素 | 套用版本 |
|------|---------|
| Headline | 黑「[神明名]」+ 紅「香供養儀式」+ slogan「[神明特質一句話]」 |
| 主視覺 | 神明法相 + 香爐 + 供品堆疊 |
| 右側 5 圓圈 | 擲杯請示 / 準備供品 / 家中誦念 / 廟中儀式 / 回傳供品照 |
| 左側 2 callout | 「神明特質」/「適合祈求」 |
| 底部數據條 | 時間 / 地點 / 報名期限 / 結單日 / 供品內容 / 註：神明點頭才辦 |
| 配色 | 傳統紅金 + 米白留白 |

**為什麼這個結構對明心特別有用？**
- 香供養儀式有 **5 段固定步驟**（v2.3 標準儀式說明書）— callout 串剛好對應
- 神明特質需要視覺化展示 — 主視覺 + 文字 callout 對應
- 活動報名訊息需要清楚展示 — 底部數據條對應

## 例子展示（看看別人怎麼想，不是讓你照抄）

以下例子的目的是讓你**感受如何組合描述詞**，每次創作都應該根據當下的文章情緒重新寫。

---

**例：媽祖封面圖（文章情緒：溫暖、像阿嬤）**
```
工筆彩繪，台灣廟宇民俗美學
媽祖婆端坐神龕，鳳冠霞帔，雙手安放膝上，面容慈祥帶著笑意
暖黃燭光從正面低角度打來，臉部光線柔和
木雕金漆神座，龍柱隱約在兩側
中景對稱，神明佔畫面 60%，下方留空
慈祥親切，像阿嬤在等你回家那種溫度
no text, no western features, no fierce expression
9:16
```

**例：供桌靜物（活動宣傳，情緒：有儀式感的溫暖）**
```
台灣廟宇靜物，新中式極簡
銅香爐居中，青煙裊裊，左右各一束白色百合和橙黃金菊
暖金逆光，青煙在光中化為金色
鑄銅霧面質感，花瓣絲絨感，木供桌深棕
中央構圖，下半供桌，上半米白留空
有儀式感的溫暖，神聖而不沉重
no text, no people, no plastic containers
1:1
```

**例：廟宇走廊（文章配圖，情緒：寧靜、有歲月感）**
```
水墨淡彩，台灣廟宇紀實
廟宇側廊，紅燈籠一路延伸至遠方，一位老信眾背影走在廊中
晨光從廊柱間隙斜入，地磚有光暈倒影
紅磚、石柱質感，燈籠絲絨感
前景燈籠虛化，遠景信眾為主體
靜謐，歲月感，不孤獨
no clear faces, no modern elements
16:9
```

**例：照見系禪意（情緒：冥想、呼吸感）**
```
極簡禪意水墨，東方美學
一根燃香，青煙緩緩上升，置於畫面正中偏下
```
